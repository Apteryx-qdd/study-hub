9隐函数二阶导与切线

y″ 的套路：先用和上面一样的方法求出一阶 y′ 的表达式 → 再把 y′ 表达式代回去（这是关键一步，很多人只求了 y′ 就停）→ 用原方程化简，得到只含 x、y 的干净结果。

10(a) 9x² + y² = 9

18x + 2y y′ = 0  ⇒  y′ = −9x/y
y″ = −9 · (y − x y′)/y² = −9( y + 9x²/y )/y² = −9(y² + 9x²)/y³

用原方程 9x² + y² = 9 化简分子：

答案：y″ = −81/y³

10(b) √x + √y = 1

1/(2√x) + y′/(2√y) = 0  ⇒  y′ = −√y/√x
y″ = −[ (y′/(2√y))·x−1/2 − √y · ½x−3/2 ] = −[ y′/(2√(xy)) − √y/(2x3/2) ]

代入 y′ = −√y/√x，第一项变成 −1/(2x)：

y″ = 1/(2x) + √y/(2x3/2) = [ √x + (1 − √x) ] / (2x3/2) = 1/(2x3/2)
答案：y″ = 1/(2x3/2)。
验算捷径：由 √y = 1 − √x 得 y = (1 − √x)²，直接求导：y′ = 1 − x−1/2，y″ = ½x−3/2 ✓（两条路都对，考试时用验算那条更快）。

11. 切线：x² + y² = (2x² + 2y² − x)² at (0, ½)

先验点在曲线上：左边 = 0 + ¼ = ¼；右边 = (0 + ½ − 0)² = ¼ ✓。隐函数求导：

2x + 2y y′ = 2(2x² + 2y² − x)(4x + 4y y′ − 1)

代入 (x, y) = (0, ½)：2x² + 2y² − x = ½，4x + 4y y′ − 1 = 2y′ − 1，2y y′ = y′。

y′ = 2 · ½ · (2y′ − 1) = 2y′ − 1  ⇒  y′ = 1
答案：y − ½ = 1·(x − 0)，即 y = x + ½（或 2x − 2y + 1 = 0）。
坑：这类“高次曲线”代入点之后会得到关于 y′ 的一次方程 —— 但**必须先把所有数值代进去再解**，否则会得到一个乱七八糟的式子。

12. Bessel 函数 J(x)：J′(0) 与 J″(0)

P12. y = J(x) satisfies x y″ + y′ + xy = 0 for all x, and J(0) = 1.

(a) 直接令 x = 0：

0·J″(0) + J′(0) + 0·J(0) = 0  ⇒  J′(0) = 0

(b) 把整个微分方程再对 x 求导（这就是“对方程做隐函数求导”）：

(y″ + x y‴) + y″ + (y + x y′) = 0  ⇒  x y‴ + 2y″ + y + x y′ = 0

再令 x = 0，并用 J(0) = 1、J′(0) = 0：

0 + 2J″(0) + 1 + 0 = 0  ⇒  J″(0) = −½
答案：J′(0) = 0，J″(0) = −1/2。
顺带记住：把 x = 0 代进方程能“消掉”含 x 的项，是这类题唯一的技巧；求 n 阶值就把方程求导 n−1 次再代 x = 0。
