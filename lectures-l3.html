4L3 · 行空间、基、维数、秩

起点同一组向量的两种堆法

给定 v₁,…,vk ∈ ℝⁿ，可以堆成行，也可以堆成列：

行堆叠：A 的每一行就是一个向量（A 是 k×n）　　列堆叠：B = [v₁ v₂ ⋯ vk]（B 是 n×k）
  • 行图 → 引出 行空间 与 秩；
  • 列图 → 引出求基的第二种方法（列方法）；
  • 两者“暗中是一回事”：给出的基大小相同（都等于秩）。

定义行空间与“行变换不改变行空间”

定义：row(A) = span{A 的各行}（是 ℝⁿ 的子空间，n = 列数）。
关键事实：若 B 与 A 行等价（row equivalent），则 row(B) = row(A)。

证明思路：行变换使 B 的每一行都是 A 的行的线性组合 ⇒ row(B) ⊆ row(A)；运算可逆，反过来也成立 ⇒ row(A) ⊆ row(B)。

直觉：化简过程中“消掉的”信息其实都是原来各行的组合，所以张成的集合没变；化到阶梯形后，非零行就是“去掉冗余后剩下的东西”。

例：A = [1 2 3; 2 4 6] → [1 2 3; 0 0 0]，所以 row(A) = span{(1,2,3)}，是 ℝ³ 中过原点的一条直线（维数 1）。

定义基（basis）· 维数（dimension）· 秩（rank）

基：集合 {b₁,…,bk} 若①张成 S 且②线性无关，就称为 S 的一组基。
记忆：基 = 极小张成集 = 极大线性无关组。

维数 dim(S)：任意一组基中向量的个数（下面用“基定理”保证这个数不依赖于选哪组基）。

秩 rank(A) = dim row(A)（L4 还会证明它同时等于 dim col(A)）。

怎么算：把 A 化成阶梯形，数非零行的个数。

例：rank[1 2; 2 4] = 1，rank[1 2; 3 4] = 2，rank[0 0; 0 0] = 0，dim{0} = 0（约定），dim ℝⁿ = n

定理基定理：任意两组基大小相同

Basis Theorem：同一空间 S 的任意两组基所含向量个数相同。因此“维数”是良定义的。

证明思路（考试常考“说出思路”）：设 B = {u₁,…,ur}，C = {v₁,…,vs} 都是基，反设 r < s。因为 B 张成 S，可把每个 vi 写成 vi = Σj aijuj。

若有 c₁v₁ + ⋯ + csvs = 0，代入并整理得关于 c 的齐次方程组：Σi ciaij = 0（j = 1,…,r）。这是 r 个方程、s 个未知数且 r < s，必有非零解；于是 C 线性相关，矛盾。故 r ≥ s；对称地 s ≥ r，所以 r = s。

直觉版本：在 ℝⁿ 里，任意 n+1 个向量必相关，所以基不可能“更小”或“更大”。

定理坐标的唯一性

定理：若 {v₁,…,vk} 是 S 的一组基，则每个 v ∈ S 都唯一地写成 v = c₁v₁ + ⋯ + ckvk。

证明：设两种写法，相减得 (c₁−d₁)v₁ + ⋯ + (ck−dk)vk = 0；由线性无关，所有系数为 0，故 ci = di。

这些系数称为 v 关于基 B 的坐标，记作坐标向量 [v]B = (c₁,…,ck)。

小结论：关于标准基 E = {e₁,e₂,e₃} 的坐标向量就是向量本身：[v]E = v。

方法行方法与列方法（同一空间，两组不同的基）

行方法列方法
怎么堆向量作为 A 的行向量作为 A 的列
求什么row(A) 的基span{v₁,…,vk}（= col(A)）的基
基是谁化简后矩阵的非零行主元列所对应的原矩阵的列
为什么行变换不改变行空间行变换不改变列之间的相关关系

列方法例题：u = (1,2,3), v = (2,1,0), w = (0,3,6)，把它们按列堆成矩阵再化简：

  [ 1   2   0 ]                 [ 1   2   0 ]                 [ 1   0   2 ]
  [ 2   1   3 ]   R₂−2R₁, R₃−3R₁ [ 0  −3   3 ]   R₂÷(−3), R₃+2R₂ [ 0   1  −1 ]
  [ 3   0   6 ]                 [ 0  −6   6 ]                 [ 0   0   0 ]

所以 {(1,2,3), (2,1,0)} 是 span(u,v,w) 的一组基；第三列是多余的（w = 2u − v）。行方法得到的是 {(1,2,3), (0,1,2)}——不同的基，但都是 2 个，这就是基定理。

最容易踩的坑：列方法中，基向量必须回到原矩阵 A 去取那几列，不能用化简后的列（行变换会改变列空间）。
