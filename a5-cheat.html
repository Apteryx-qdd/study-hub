三类问题的判别句

递增 / 递减f′ 的符号f′ > 0 ⇒ 递增；f′ < 0 ⇒ 递减（区间按临界点切）
局部最大 / 最小f′ 在临界点两侧的符号变化+→− 为局部最大；−→+ 为局部最小；不变则非极值
凹向上 / 向下f″ 的符号f″ > 0 凹向上；f″ < 0 凹向下
拐点f″ 变号（且该点在定义域内）凹凸性改变即为拐点，不要求 f″ 存在
