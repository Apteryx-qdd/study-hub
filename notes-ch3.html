3第 3 章 量子理论、原子轨道与电子排布

3.1 光：波与粒子

  • 波参数：波长 λ（m）、频率 ν（Hz = s⁻¹）、波数 ν̃ = 1/λ（cm⁻¹）；c = λν，c = 2.998×10⁸ m/s。
  • 电磁波谱按波长从短到长：γ 射线 < X 射线 < 紫外 UV < 可见（400–700 nm）< 红外 IR < 微波 < 无线电。频率与能量顺序相反。
  • 可见光中紫光波长最短、能量最高；红光波长最长、能量最低。
  • 干涉：同相位 → 相长（constructive）；反相位 → 相消（destructive）。
  • 双缝实验说明光有波动性。

3.2 光电效应（光有粒子性）

实验事实：① 低于某一阈值频率 ν₀，再强的光也打不出电子；② 高于阈值时，打出电子的数目与光强成正比；③ 打出电子的动能只与频率有关、与光强无关。

爱因斯坦方程

Ephoton = hν = KEmax + W　　（W = 功函数 work function = hν₀）
  • h = 6.626×10⁻³⁴ J·s
  • 阈值频率 ν₀ = W/h；阈值波长 λ₀ = hc/W
  • 每秒打出的电子数 ∝ 光强（每秒入射光子数）；每个光子的能量只由 ν 决定。
  • 推论：若 hν < W，无论光多强都无电子逸出（经典波动论无法解释，故必须引入光子）。

变式（HW4 第 5 题，光电子能谱 PES）：用已知波长/频率的 UV 打电子，测其动能反推电离能：

IE = hν − KE

3.3 Bohr 氢原子模型

三条假设：① 电子只在特定圆轨道（定态）上运动，不辐射能量；② 轨道半径与能量由量子数 n 决定，n = 1, 2, 3…；③ 电子在能级间跃迁时才吸收/放出光子，光子能量 = 能级差。

能级公式（氢及类氢离子，Z = 核电荷）

En = −(2.18×10⁻¹⁸ J) × Z²/n² = −13.6 × Z²/n² (eV) = −1312 × Z²/n² (kJ/mol)
  • n = 1 为基态 ground state（最稳定、能量最低、半径最小）；n > 1 为激发态 excited state。
  • 能量为负表示电子被核束缚；n → ∞ 时 E → 0（自由电子）。束缚态能量 < 自由电子能量。
  • 半径 r ∝ n²/Z（Z 越大、n 越小，电子被拉得越紧）。

跃迁与光谱

ΔE = E_高 − E_低 = hν = hc/λ
  • 发射 emission：高 → 低，放出光子；吸收 absorption：低 → 高，吸收光子（同一条谱线位置相同）。
  • Rydberg 方程（经验式，与 Bohr 结果一致）：
1/λ = RH × Z² × (1/n₁² − 1/n₂²)，　RH = 1.09737316×10⁷ m⁻¹，n₂ > n₁
  • 系列：n₁ = 1 Lyman（UV）；n₁ = 2 Balmer（可见光，Hα 656 nm、Hβ 486 nm、Hγ 434 nm）；n₁ = 3 Paschen（IR）。
  • 判断"哪次跃迁放出能量更大"：看 |ΔE| ∝ |1/n₁² − 1/n₂²|，能级间隔随 n 增大而变密（n=2→1 最大）。

例：Balmer 系 n = 5 → 2 的波长：1/λ = 1.097×10⁷ × (1/4 − 1/25) = 2.304×10⁶ m⁻¹ → λ = 434 nm。

3.4 de Broglie 波粒二象性

λ = h / (mu) = h / p　（m 单位 kg，u 单位 m/s）
  • 电子等微观粒子也有波动性；宏观物体波长小到不可观测（棒球 0.142 kg、42 m/s → λ ≈ 1.1×10⁻³⁴ m）。
  • 电子（9.1×10⁻³¹ kg、4×10⁶ m/s）→ λ ≈ 2×10⁻¹⁰ m = 0.2 nm，与原子的尺度（0.5–4 Å）相当 → 可观测。
  • 电子衍射实验（与 X 射线衍射图样类似）直接证明电子有波动性。
  • 电子经电压 V 加速（HW3 第 4 题）：KE = eV → u = √(2eV/m) → λ = h/(mu)。V = 5.00×10³ V 时 λ ≈ 17 pm。

3.5 不确定原理

Δx · Δp ≥ h/(4π)，　Δp = m·Δu
  • 位置与动量（速度）不能同时精确确定；这不是仪器问题，是原理性限制。
  • 电子：Δu 为 20% × 5×10⁶ m/s 时，Δx ≈ 5.8×10⁻¹¹ m，与原子半径同量级 → 原子内电子的位置无法精确定义，Bohr 的"确定轨道"不成立。
  • 棒球：Δp 极小 → Δx ≈ 10⁻²⁹ m → 宏观物体位置可精确确定（量子效应可忽略）。

3.6 驻波与一维势箱（particle in a box）

  • 电子在原子中稳定存在 ↔ 形成驻波：轨道周长必须是波长的整数倍，2πr = nλ（n = 1, 2, 3…）→ 能量只能取分立值 → 能量量子化。
  • 一维势箱（长度 L，电子只能在 0 ≤ x ≤ L 内）：
En = n²h² / (8mL²)，　n = 1, 2, 3…
ψn(x) = √(2/L) · sin(nπx/L)
概率 P = ∫ ψ² dx（在某区间找到电子的概率）
  • 节点 nodes = n − 1；n 越大能量越高、节面越多。
  • 基态 n=1 时概率密度最大在箱子中央（x = L/2）。
  • 跃迁：ΔE = E_2 − E_1 = 3h²/(8mL²)，对应光子 λ = hc/ΔE。
  • 例：L = 1.00×10² pm → ΔE ≈ 1.81×10⁻¹⁷ J，λ ≈ 11.0 nm（X 射线区）。
  • 题目给"0 到 30 pm 之间的概率百分比"：算 ∫₀^30 ψ²dx ÷ ∫₀^150 ψ²dx（或直接对归一化波函数积分）。

3.7 Schrödinger 方程与"轨道"

  • 解 Schrödinger 方程得到波函数 ψ（wavefunction）；ψ 本身没有直接物理意义，ψ² 表示电子出现的概率密度（electron density）。
  • 描述一个原子轨道只需要 3 个量子数（n, l, ml）；第 4 个 ms 描述电子自旋。
  • orbital（轨道）≠ orbit（玻尔轨道）：orbital 是概率分布的"云"，不是固定路径。

3.8 四个量子数（必背表）

量子数符号含义允许值备注
主量子数n电子层、轨道大小、主要能量1, 2, 3…（正整数）n 越大越大越远，同 n 为同一 shell
角量子数l轨道形状、亚层0 ~ (n−1)l = 0,1,2,3 → s, p, d, f
磁量子数ml空间取向、亚层内轨道数−l ~ +l（共 2l+1 个）p 有 3 个、d 有 5 个、f 有 7 个
自旋量子数ms电子自旋方向+½ 或 −½同一轨道最多 2 个电子且自旋相反

容量

  • 一个轨道最多 2 个电子（Pauli）。
  • 亚层容量 = 2(2l+1)：s=2、p=6、d=10、f=14。
  • 第 n 层容量 = 2n²：n=1→2、n=2→8、n=3→18、n=4→32。
  • 给定 (n, l)：2(2l+1) 个电子；给定 (n, l, ml)：2 个；给定 (n, l, ml, ms)：1 个。

量子数合法性判断（HW3 第 1 题套路）：逐条查 l < n、|ml| ≤ l、ms = ±½。例：(2, 2, 0, ½) 中 l = 2 ≥ n = 2 → l 非法。

3.9 轨道形状与能级

  • s：球形（1s < 2s < 3s 依次变大）；p：哑铃形，3 个取向 p_x、p_y、p_z；d：5 个；f：7 个。
  • 单电子体系（H、He⁺、Li²⁺）：能量只由 n 决定，同 n 的 s/p/d 简并。
  • 多电子体系：能量由 n 和 l 共同决定，出现能级分裂（电子间排斥 + 屏蔽）→ 顺序：
1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d < 6p < 7s < 5f < 6d < 7p
  • 记忆法：(n + l) 越小越先填；相同 (n + l) 时 n 小者先填。4s 先于 3d 填充，但失电子时先失 4s（因为 4s 能量在成键后反而更高）。

3.10 电子排布三原则

原则内容
Pauli 不相容同一原子中不能有 4 个量子数完全相同的两个电子（同一轨道最多 2 个且自旋相反）
Aufbau 构造原理电子从能量最低的轨道开始填（按上面的顺序）
Hund 规则简并轨道（如 3 个 p）上先各占 1 个、自旋平行，再配对

书写：full（1s²2s²2p⁶3s²3p⁶4s¹…）与 noble-gas notation（[Ar]4s¹）。镧系/锕系用 [Xe]4f…。

3.11 离子的电子排布

  • 主族：先写原子排布，再按电荷加减电子（加在最高能级，减从最高能级减）。Na → Na⁺：[Ne]；Cl → Cl⁻：[Ar]。
  • d 区过渡金属：先失去最外层 ns 电子，再失 (n−1)d。
  • Fe: [Ar]4s²3d⁶ → Fe²⁺: [Ar]3d⁶；Fe³⁺: [Ar]3d⁵
  • Cr³⁺: [Ar]3d³；Mn³⁺: [Ar]3d⁴；Zn²⁺: [Ar]3d¹⁰；Sc³⁺/Ti⁴⁺/V⁵⁺ 都退到 [Ar]。
  • 注意：Fe³⁺ 的 3d⁵ 是半满 → 特别稳定（这也是 Fe³⁺ 常见的原因之一）。

3.12 磁性（顺磁/反磁）

  • paramagnetic 顺磁：有未成对电子 → 被外磁场吸引（未成对电子越多，吸引越强）。
  • diamagnetic 反磁：所有电子成对 → 被外磁场微弱排斥。
  • 判断：先画轨道图数未成对电子。电子数为奇数 → 一定顺磁；电子数为偶数 → 不一定反磁（如 O₂ 有 2 个未成对电子，是顺磁的）。
