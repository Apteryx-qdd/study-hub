A附录 A　Lewis 结构、VSEPR、杂化与 MO（HW5–HW6 考查范围）

这部分不在 Lecture 1–4 的 PPT 里，但 HW5、HW6 全考它。Lecture 4 的末尾已经预告了 Ch.5/6 的内容，所以一并整理，方便你把后面几周的课跟前面接起来。

A.1 画 Lewis 结构的五步

  1. 数总价电子数（含离子电荷：阴离子加、阳离子减）。
  2. 确定中心原子（电负性最小、或题目指定；H 和 F 永远在末端）。
  3. 单键连骨架（用掉 2 个电子/键）。
  4. 剩余电子先给末端原子补满八隅体，再给中心原子。
  5. 中心原子不满八隅体 → 把末端孤对电子改成双键/三键。

A.2 形式电荷 formal charge

FC = 价电子数 −（孤对电子数 + ½ 成键电子数）
  • 各原子 FC 之和 = 物种总电荷（检验手段）。
  • 最稳定的共振式：FC 尽量接近 0，负 FC 落在电负性大的原子上，正 FC 落在电负性小的原子上。
  • 例：NO₃⁻ 三个等价共振式，每个 N 上 +1、两个 O 上 −1（N 上孤对 → 总 −1）。

A.4 共振 resonance

  • 同一分子有多个只差电子分布的 Lewis 式 → 真实结构是共振杂化体，键级介于各共振式之间。
  • 例：NO 的 N–O 键长 115 pm，介于双键（120 pm）与三键（106 pm）之间 → 有双键/三键两种共振式的贡献。
  • 判断"哪个共振式更重要"：FC 接近 0、负电荷在电负性大原子上、不违背八隅体者更重要。
  • 例：NO₂ 有未成对电子 → 两个分子二聚成 N₂O₄ 使电子全部配对（这也是 N₂O₄ 易解离回 NO₂ 的原因）。

A.5 键的极性与偶极矩

  • 电负性 electronegativity：原子在化学键中吸引电子的能力。趋势：同周期从左到右增大，同族从上到下减小（F 最大 4.0，Cs/Fr 最小）。
  • 键型判断：ΔEN < 0.4 非极性共价；0.4–1.7 极性共价；> 1.7 离子性为主（经验判据）。
  • 偶极矩 μ = Q × r（C·m）；1 D = 3.336×10⁻³⁰ C·m。
  • 百分离子性 = μ(实验) / μ(假设完全离子) × 100%，其中 μ(完全离子) = e × d（e = 1.602×10⁻¹⁹ C）。
  • 例（HW5-3）：BrF，μ = 1.42 D、d = 1.76 Å → μionic = 1.602×10⁻¹⁹ × 1.76×10⁻¹⁰ = 2.82×10⁻²⁹ C·m；μexp = 1.42×3.336×10⁻³⁰ = 4.74×10⁻³⁰ C·m → ≈ 16.8% 离子性。
  • 分子极性 = 各键偶极矩的矢量和：CO₂ 直线、两个 C=O 抵消 → 非极性；H₂O 弯曲 → 极性。

A.7 分子极性判断

  1. 先看有没有极性键（ΔEN ≠ 0）。
  2. 再看几何是否对称：对称 → 键矩抵消 → 非极性（CO₂、BF₃、CCl₄、XeF₄、SF₆）。
  3. 不对称 → 极性（H₂O、NH₃、SO₂、NBr₃、OCS）。
  4. 有孤对电子几乎一定极性（除 XeF₂ 这类直线对称的）。

A.8 分子间作用力与沸点

强度顺序：离子–偶极 > 氢键 > 偶极–偶极 > 色散力 LDF。

  • 色散力：所有分子都有，随电子数/摩尔质量/极化率增大而增强（I₂ > Br₂ > Cl₂ > F₂）。
  • 偶极–偶极：极性分子之间。
  • 氢键：H 直接连在 N、O、F 上时才有（HF、H₂O、NH₃、醇、羧酸）。
  • 沸点比较模板：先看离子化合物（最高）→ 再看氢键 → 再看偶极 → 最后比 LDF。
  • 例（HW6-4）：RbF（离子）> CH₃OH（氢键）> CH₃Br（偶极）> CO₂（非极性，LDF）；即 CO₂ < CH₃Br < CH₃OH < RbF。
  • 例（HW6-3）：Br₂ 与 ICl 等电子、摩尔质量相近，但 ICl 有偶极矩 → 偶极–偶极作用 > Br₂ 的纯色散力 → ICl 熔点更高（27.2 ℃ vs −7.2 ℃）。

A.9 价键理论 VB 与杂化

  • 共价键 = 两个原子各出一个自旋相反的电子，原子轨道重叠形成。
  • 杂化 hybridization：中心原子的价层轨道混合成等价的杂化轨道，以减小斥力、解释实测键角。
电子域数杂化键角例
2sp180°BeCl₂、C₂H₂（每个 C）
3sp²120°BF₃、SO₃、C₂H₄（每个 C）
4sp³109.5°CH₄、NH₃、H₂O
5sp³d90°/120°PCl₅
6sp³d²90°SF₆
  • σ 键：头碰头重叠（可绕键轴旋转）；π 键：肩并肩重叠（不能旋转，导致顺反异构）。
  • 单键 = 1σ；双键 = 1σ + 1π；三键 = 1σ + 2π。
  • 例（HW6-7）：AlCl₃ 中 Al 为 sp²（平面三角），接受 Cl⁻ 后变 AlCl₄⁻，Al 变 sp³（四面体）。
  • 例（HW6-5）：基态 P 3s²3p³ → 3 个未成对 → 形成 3 个键；S 3s²3p⁴ → 2 个未成对 → 形成 2 个键。
  • 例（HW6-6）：BeCl₂（sp，直线 180°）与 Br₂ 可用 VB 解释；SF₆（90°/180°、12 电子）必须靠 sp³d² 扩展八隅体，简单 VB/八隅体理论无法解释，这正是 VB 的局限。

A.10 轨道重叠判断 σ / π / 不成键

以 x 轴为核间轴：

组合结果理由
1s + 1sσ头碰头，轴对称
1s + 2pxσ沿轴头碰头
1s + 2sσ头碰头（能量不同但可重叠）
2px + 2pxσ沿轴端对端
3py + 3pyπ平行侧面重叠
2px + 2py不成键相互垂直，净重叠为零

A.11 分子轨道理论 MO

  • 原子轨道线性组合成成键轨道（σ、π，能量低）与反键轨道（σ*、π*，能量高，带 *）。电子按 Aufbau、Pauli、Hund 填入 MO。
  • 键级 bond order = (成键电子数 − 反键电子数) / 2；键级越大 → 键越短、越强。
  • 键级为 0 → 分子不存在（如 He₂）。
  • 磁性：MO 图中有未成对电子 → 顺磁。O₂ 的 MO 图有两个未成对电子在 π∗ 上 → 顺磁，这是 MO 理论最漂亮的成功（Lewis 结构预测不出来）。

能级顺序（第二周期）

  • Li₂ ~ N₂（12–14 电子以内）：σ2s < σ∗2s < π2p < σ2p < π∗2p < σ∗2p
  • O₂、F₂、Ne₂：σ2s < σ∗2s < σ2p < π2p < π∗2p < σ∗2p
关键差异：N₂ 及以前 σ2p 高于 π2p；O₂ 及以后 σ2p 低于 π2p。
