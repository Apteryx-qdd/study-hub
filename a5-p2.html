2闭区间上的绝对最值：EVT 三步法

P2. Find the absolute maximum and absolute minimum values of f on the given interval.
模板（每题 3 行）
① 求 f′(x)，解 f′ = 0 得临界点，只保留落在区间内的（区间内还要留意 f′ 不存在点）；
② 把「临界点 + 两个端点」的函数值全部算出；
③ 比大小：最大的那个是绝对最大，最小的是绝对最小，并写出取到的位置。

(a) f(t) = t√(4 − t²)，[−1, 2]

定义域要求 4 − t² ≥ 0，即 [−2, 2]；区间 [−1,2] 含在内，f 连续 ⇒ EVT 适用。

f′(t) = √(4 − t²) + t · (−t)/√(4 − t²) = (4 − 2t²)/√(4 − t²)

f′ = 0 ⇔ t² = 2 ⇔ t = ±√2，其中只有 t = √2 落在 [−1,2] 内。

t−1（端点）√2（临界点）2（端点）
f(t)−1·√3 = −√3 ≈ −1.732√2·√2 = 20
答案：绝对最大 f(√2) = 2；绝对最小 f(−1) = −√3 ≈ −1.732。

(b) f(x) = x/(x² + 4)，[0, 3]

f′(x) = [(x² + 4) − x·2x] / (x² + 4)² = (4 − x²)/(x² + 4)²

f′ = 0 ⇔ x = ±2，区间内只有 x = 2。分母恒正，所以 f′ 的符号只由 4 − x² 决定。

x0（端点）2（临界点）3（端点）
f(x)02/8 = 1/43/13 ≈ 0.231
答案：绝对最大 f(2) = 1/4；绝对最小 f(0) = 0。
坑：0.231 与 0.25 很接近，不能靠肉眼比——化成 1/4 = 13/52 与 3/13 = 12/52 才敢下结论。

(c) f(t) = 2cos t + sin 2t，[0, π/2]

f′(t) = −2sin t + 2cos 2t = 0  ⇔  cos 2t = sin t

用 cos 2t = 1 − 2sin²t，令 s = sin t：

1 − 2s² = s  ⇒  2s² + s − 1 = 0  ⇒  (2s − 1)(s + 1) = 0  ⇒  s = 1/2 或 s = −1

在 [0, π/2] 上 sin t ≥ 0，s = −1 舍去，得 t = π/6。

t0（端点）π/6（临界点）π/2（端点）
f(t)2·1 + 0 = 22(√3/2) + sin(π/3) = √3 + √3/2 = 3√3/2 ≈ 2.5980 + sin π = 0
答案：绝对最大 f(π/6) = 3√3/2 ≈ 2.598；绝对最小 f(π/2) = 0。
坑：解 cos 2t = sin t 时用“倍角 → 单角”化简，再解二次方程；只写 t = π/6 而漏掉 s = −1 的讨论会被扣步骤分。
