4第 4 章 有效核电荷与周期趋势

4.1 周期表的结构（英文术语要认得）

  • 周期 period（行）＝ 电子层 n；族 group（列）。
  • 主族 main group / representative elements：1A–8A（s 区 + p 区）。
  • 具体族名：1A 碱金属 alkali metals；2A 碱土金属 alkaline earth metals；6A 氧族 chalcogens；7A 卤素 halogens；8A 稀有气体 noble gases。
  • 过渡金属 transition metals：3B–2B（d 区，第 3–12 族）；2B（Zn 族）d 亚层全满，有时称 post-transition。
  • 镧系 lanthanides / 锕系 actinides：f 区。
  • 按价电子所在亚层分区：s 区（1、2 族 + He）、p 区（13–18 族）、d 区（3–12 族）、f 区。
  • 价电子 valence electrons = 最外层 ns + np（主族）；核心电子 core electrons = 内层。

4.2 有效核电荷 Zeff

  • 多电子原子中，电子同时受核吸引与其他电子排斥 → 内层电子屏蔽 shielding 掉一部分核电荷。
  • 定义：
Zeff = Z − σ　（Z = 质子数，σ = 屏蔽常数）
  • 趋势：同周期从左到右 Zeff 增大（核电荷增加、屏蔽不变）；同族从上到下 Zeff 变化很小（Z 与 σ 同步增加）。
  • 例（第二周期）：Li 1.28 → Be 1.91 → B 2.42 → C 3.14 → N 3.83 → O 4.45 → F 5.10。

Slater 规则（求 σ）

  1. 排成组：(1s)(2s,2p)(3s,3p)(3d)(4s,4p)(4d)(4f)…
  2. 右边（更高 n）的电子贡献 0。
  3. 同组电子每个贡献 0.35（1s 组为 0.30）。
  4. 对 ns/np 电子：n−1 层每个 0.85；n−2 及更内层每个 1.00。
  5. 对 nd/nf 电子：所有在它左边的电子组每个 1.00。

例：Br 的 3d 电子（[Ar]3d¹⁰4s²4p⁵）

σ = 1.00×(18) + 0.35×(9) = 21.15 → Zeff = 35 − 21.15 = 13.85

（18 = 1s²2s²2p⁶3s²3p⁶；9 = 3d 上另外 9 个电子）

4.3 原子半径

  • 定义：金属半径 = 相邻同种金属原子核间距的一半；共价半径 = 相邻同种原子成键核间距的一半。
  • 趋势：同周期从左到右减小（Zeff 增大，把电子拉得更紧）；同族从上到下增大（n 增大，层数增加）。
  • 离子比较：同周期阳离子半径 < 原子半径；阴离子半径 > 原子半径。

4.4 电离能 IE

  • 定义：气态原子失去一个电子所需的最小能量（kJ/mol）。Na(g) → Na⁺(g) + e⁻，IE₁ = 495.8 kJ/mol。
  • 趋势：同周期从左到右增大（Zeff↑、半径↓）；同族从上到下减小（半径↑、屏蔽↑）。
  • 反常（必考）：
  • Be > B、Mg > Al：Be/Mg 是 ns² 全满，B/Al 要失去 np 电子（能量更高、更易失）。
  • N > O、P > S：N/P 是半满 p³，O/S 多一个成对电子，电子间排斥使其更易失去。
  • 逐级电离能：IE₁ < IE₂ < IE₃…；当内层开始被剥离时出现巨大跳跃。
  • 例：Na IE₁ = 496、IE₂ = 4562 kJ/mol → 跳跃在 IE₁/IE₂ 之间 → Na 只有 1 个价电子。
  • 判断价电子数：找最大跳跃出现在 IE_k 与 IE_{k+1} 之间 → 有 k 个价电子（据此定位族）。
  • 例（Na vs Mg）：IE₁：Na < Mg（Mg Zeff 大）；IE₂：Na > Mg（Na⁺ 已是 [Ne] 全满，再失去要破坏内层）。

4.5 电子亲和能 EA

  • 定义：气态原子接受一个电子时放出的能量的相反数（即 EA = −ΔE）。Cl(g) + e⁻ → Cl⁻(g)，EA = 349 kJ/mol。
  • 符号约定要小心：放出能量 → EA 为正；需要吸收能量 → EA 为负。
  • 趋势：同周期从左到右 EA 一般增大（Zeff↑，更容易接受电子）；同族从上到下一般减小。
  • 反常：Be、N（2s² 全满、2p³ 半满，加电子要破坏稳定性，EA 很小甚至为负）；EA₂ 总是负（第二个电子要克服负离子排斥）：
  • O(g) + e⁻ → O⁻(g)，EA₁ = +141 kJ/mol
  • O⁻(g) + e⁻ → O²⁻(g)，EA₂ = −741 kJ/mol
  • 比较时注意：EA 越大 = 越容易得电子 = 非金属性越强（Cl > F 在某些数据里，因为 F 半径太小、电子排斥大）。

4.6 金属性与离子半径

  • 金属性 metallic character：同周期从左到右减弱，同族从上到下增强（越易失电子）。金属 → 类金属 metalloids（B、Si、Ge、As、Sb、Te）→ 非金属。
  • 离子半径：阳离子 < 其原子（失去电子、电子排斥减小、有时整层消失）；阴离子 > 其原子（电子增多、排斥增大）。
  • 等电子系列 isoelectronic series：电子数相同、核电荷不同 → Z 越大，半径越小。
  • 例：N³⁻ > O²⁻ > F⁻ > Na⁺ > Mg²⁺（都是 10 电子，Z 从 7 到 12）。
  • 主族常见离子电荷：1A +1；2A +2；3A +3（Al³⁺）；5A −3；6A −2；7A −1；Ag⁺、Zn²⁺、Cd²⁺ 固定。
