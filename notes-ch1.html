1第 1 章 测量、单位与有效数字

1.1 科学方法的四个词（判断题高频）

术语定义判据
Law 定律对一致自然现象的口头或数学描述只描述"是什么/怎么变"，不解释原因
Hypothesis 假说对现象提出的可检验解释被实验支持后才可能升级为理论
Experiment 实验有目的地验证假说的操作——
Theory 理论假说 + 大量支持性实验可被新实验修正，但不是"猜测"

判例：能量不能创生也不能消灭 → law（热力学第一定律）；"吃维生素的人活得更久" → hypothesis（待检验，且是相关性不是因果）。

1.4 导出单位与密度

  • 力：N = kg·m·s⁻²；能量：J = N·m = kg·m²·s⁻²；功率：W = J/s；压强：Pa = N/m² = kg·m⁻¹·s⁻²；电荷：C = A·s。
  • 密度 density：d = m / V，常用 g/cm³（= g/mL）或 kg/m³；1 g/cm³ = 1000 kg/m³。
  • 由定义式"倒推单位"是考试套路：J 的推导 = kg·(m/s)² = kg·m²·s⁻²。

1.5 温度换算（三个刻度）

  • K = ℃ + 273.15（绝对温标，0 K = 绝对零度 = −273.15 ℃，理论上不可达）
  • ℃ = (℉ − 32) × 5/9
  • ℉ = (9/5) × ℃ + 32
  • 温差：ΔT(℃) = ΔT(K) ≠ ΔT(℉)；1 ℃ 的"一度"比 1 ℉ 的"一度"大 1.8 倍。
  • 换算题的有效数字：先按精确数处理 273.15、5/9、9/5，最终结果按原始测定值的有效数字（HW1 第 6 题就是考这个）。

1.6 有效数字（本章失分最多）

数位规则（5 条）

  1. 所有非零数字都有效：2467.1 → 5 位。
  2. 夹在非零数字之间的 0 有效：600.001 → 6 位。
  3. 第一个非零数字左边的 0 无效（只定位小数点）：0.001 → 1 位。
  4. 第一个非零数字右边的 0 有效：0.00100 → 3 位。
  5. 不含小数点的整数，末尾的 0 含义不明：200 可能是 1、2 或 3 位 → 用科学计数法 2.00×10²（3 位）或加小数点 400.（3 位）来消除歧义。

运算规则

运算规则例
加减结果按小数点后位数最少的（对齐位数）14.98 + 2.7340×10⁴ + 84.7593 → 最低位是"个位"，得 2.744×10⁴
乘除结果按有效数字位数最少的5.63×10² × 7.4×10³ = 4.2×10⁶
混合先乘除（定有效数字），再加减（定小数位），中间不四舍五入多步计算保留 1 位多余数字到最后再舍入
精确数无限位有效数字，不限制结果（1 in = 2.54 cm，1 kg = 1000 g，计数）3 × 2.5 g = 7.5 g

舍入：一般"四舍六入五成双"或教材的"五入"，同一份作业里保持一致；指数形式的答案要先规范化成 a×10ⁿ（1 ≤ a < 10）再数有效数字。

1.7 准确度与精密度

  • 精密度 precision：同一对象多次测量彼此接近的程度（重复性好，与真值无关）。
  • 准确度 accuracy：测量值与真值的接近程度。
  • 四种组合：精密但不准（系统误差，可校正）；准但不精密（随机误差大）；既准又精密（最好）；都不行。
  • 判断句："精密"不能推出"准确"，"准确"也不能推出"精密"（后者在单次测量时尤其要注意）。

1.8 物质的分类与性质

  • 状态：solid / liquid / gas（固液气）。
  • 纯物质 pure substance：element（元素，如 Fe、O₂）或 compound（化合物，如 CO₂、NaHCO₃），有固定组成。
  • 混合物 mixture：homogeneous（均相，组成均匀，如盐水、空气）vs heterogeneous（非均相，如沙水、油水）。
  • 物理性质：不改变物质身份即可观察（颜色、密度、熔点、导电性）；化学性质：需发生化学变化才表现（可燃性、与酸反应）。
  • 广延性质 extensive：与物质的量有关（质量、体积、长度）；强度性质 intensive：与量无关（密度、温度、熔点、电导率）。
  • 分离手段：蒸馏（沸点差）、过滤（溶解度/粒径）、色谱、萃取——依据的是物理性质差异。
