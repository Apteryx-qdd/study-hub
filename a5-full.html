1图形判读：绝对极值 / 局部极值 / 都不是

P1. For each of the numbers a, b, c, d, e, r, s, and t, state whether the function whose graph is shown has an absolute maximum or minimum, a local maximum or minimum, or neither a maximum nor a minimum.

先把图读成一句话

曲线从 a（左端点，较高）下降，到 b 后水平直到 d，再上升，在 e 到达全图最高点，随后下沉到 r（谷底），再升到 s（第二个峰，比 e 低），然后急剧下降，在 t 处穿过 x 轴，最后停在轴下方那个实心点（全图最低点）。

判定表

点绝对？局部？理由
a—局部最大左端点，向右立即下降，故 f(a) 大于附近的值；但 f(e) > f(a)，所以不是绝对最大。
b—局部最小左侧递减到 b，右侧在 [b,d] 上恒等于 f(b)，故附近 f(x) ≥ f(b)。注意它不是局部最大：左边紧邻处 f(x) > f(b)。
c—既是局部最大又是局部最小c 在水平段内部，附近 f(x) = f(c) 恒成立，f(c) ≤ f(x) 与 f(c) ≥ f(x) 同时满足（非严格极值）。
d—局部最小左侧水平、右侧递增，附近 f(x) ≥ f(d)。
e绝对最大局部最大全图最高点。
r—局部最小两峰之间的谷底；但它高于右端点，故不是绝对最小。
s—局部最大峰，但 f(s) < f(e)，不是绝对最大。
t—都不是曲线在 t 处单调下降穿过 x 轴（f(t) = 0），两侧都在减小，没有极值。
关键结论：绝对最小值出现在 t 右侧的右端点（那个实心点），它不属于 a…t 任何一个字母。所以本题里“绝对最小”在标注点中无人认领，答“none of the labelled points”才完整。
考场易错：① 端点能不能算局部极值 —— 本题按教材惯例：只要 f(a) ≥ 附近所有 f(x)，端点 a 就是局部最大；② 水平段上的点容易被判成“什么都不是”，其实按定义它同时是（非严格）局部最大和最小；③ 忘了先找“最低/最高”再谈绝对 —— 绝对性要和全图比，不是和邻居比。

2闭区间上的绝对最值：EVT 三步法

P2. Find the absolute maximum and absolute minimum values of f on the given interval.
模板（每题 3 行）
① 求 f′(x)，解 f′ = 0 得临界点，只保留落在区间内的（区间内还要留意 f′ 不存在点）；
② 把「临界点 + 两个端点」的函数值全部算出；
③ 比大小：最大的那个是绝对最大，最小的是绝对最小，并写出取到的位置。

(a) f(t) = t√(4 − t²)，[−1, 2]

定义域要求 4 − t² ≥ 0，即 [−2, 2]；区间 [−1,2] 含在内，f 连续 ⇒ EVT 适用。

f′(t) = √(4 − t²) + t · (−t)/√(4 − t²) = (4 − 2t²)/√(4 − t²)

f′ = 0 ⇔ t² = 2 ⇔ t = ±√2，其中只有 t = √2 落在 [−1,2] 内。

t−1（端点）√2（临界点）2（端点）
f(t)−1·√3 = −√3 ≈ −1.732√2·√2 = 20
答案：绝对最大 f(√2) = 2；绝对最小 f(−1) = −√3 ≈ −1.732。

(b) f(x) = x/(x² + 4)，[0, 3]

f′(x) = [(x² + 4) − x·2x] / (x² + 4)² = (4 − x²)/(x² + 4)²

f′ = 0 ⇔ x = ±2，区间内只有 x = 2。分母恒正，所以 f′ 的符号只由 4 − x² 决定。

x0（端点）2（临界点）3（端点）
f(x)02/8 = 1/43/13 ≈ 0.231
答案：绝对最大 f(2) = 1/4；绝对最小 f(0) = 0。
坑：0.231 与 0.25 很接近，不能靠肉眼比——化成 1/4 = 13/52 与 3/13 = 12/52 才敢下结论。

(c) f(t) = 2cos t + sin 2t，[0, π/2]

f′(t) = −2sin t + 2cos 2t = 0  ⇔  cos 2t = sin t

用 cos 2t = 1 − 2sin²t，令 s = sin t：

1 − 2s² = s  ⇒  2s² + s − 1 = 0  ⇒  (2s − 1)(s + 1) = 0  ⇒  s = 1/2 或 s = −1

在 [0, π/2] 上 sin t ≥ 0，s = −1 舍去，得 t = π/6。

t0（端点）π/6（临界点）π/2（端点）
f(t)2·1 + 0 = 22(√3/2) + sin(π/3) = √3 + √3/2 = 3√3/2 ≈ 2.5980 + sin π = 0
答案：绝对最大 f(π/6) = 3√3/2 ≈ 2.598；绝对最小 f(π/2) = 0。
坑：解 cos 2t = sin t 时用“倍角 → 单角”化简，再解二次方程；只写 t = π/6 而漏掉 s = −1 的讨论会被扣步骤分。

3含参数最值：aᵃbᵇ/(a+b)ᵃ⁺ᵇ

P3. If a and b are positive numbers, find the maximum value of f(x) = xa(1 − x)b, 0 ≤ x ≤ 1.
f′(x) = a xa−1(1 − x)b − b xa(1 − x)b−1 = xa−1(1 − x)b−1 · [ a(1 − x) − bx ]

因为 a, b > 0 且 0 < x < 1，前两个因子都为正，故

f′(x) = 0  ⇔  a − (a + b)x = 0  ⇔  x = a/(a + b)

端点值 f(0) = 0、f(1) = 0，而内部 f > 0，所以内部唯一的临界点就是最大值点。代入：

f(a/(a+b)) = (a/(a+b))a · (b/(a+b))b = aa bb / (a+b)a+b
答案：最大值 = aabb/(a+b)a+b，在 x = a/(a+b) 处取到。
为什么这个结果值得记住
它是「加权几何平均」的原型：取 a = b = 1 时得 f = x(1−x) 的最大值 1/4，x = 1/2 —— 与二次函数的顶点一致，可以拿来验算参数公式。取 a = 2, b = 1 时最大值为 2²·1/(3³) = 4/27，位置 x = 2/3。

4证明题：严格单调 ⇒ 没有局部极值

P4. Prove that f(x) = x101 + x51 + x + 1 has neither a local maximum nor a local minimum.
f′(x) = 101x100 + 51x50 + 1

对任意实数 x，偶数次幂非负：x100 ≥ 0、x50 ≥ 0，于是

f′(x) ≥ 0 + 0 + 1 = 1 > 0  （对所有 x）

f′ 恒正且不为 0 ⇒ f 在 (−∞, +∞) 上严格递增。严格单调函数在任一点两侧的函数值都朝同一方向变化，不可能“先升后降”或“先降后升”，因此既无局部最大也无局部最小。∎

答题要点：结论必须落到「严格单调 ⇒ 无局部极值」这句话上；只写 “f′ > 0” 而不解释为什么因此无极值，会丢结论分。

5单调区间与局部极值（f′ 符号表）

P5. For (a) f(x) = sin x + cos x, 0 ≤ x ≤ 2π；(b) G(x) = 5x2/3 − 2x5/3：
(1) 求增减区间；(2) 求局部最大/最小值；(3) 求凹凸区间与拐点（见下一节）。
符号表模板
① f′ = 0 的根 + f′ 不存在的点 → 全部列成临界点；
② 用临界点把定义域切段，每段取一个测试点判 f′ 符号；
③ 由「+ → −」判局部最大，「− → +」判局部最小，并把函数值算出来。

(a) f(x) = sin x + cos x，[0, 2π]

f′(x) = cos x − sin x = 0  ⇔  tan x = 1  ⇔  x = π/4, 5π/4
区间(0, π/4)(π/4, 5π/4)(5π/4, 2π)
f′ 符号+−+
f递增 ↗递减 ↘递增 ↗

于是：增区间 [0, π/4] 与 [5π/4, 2π]；减区间 [π/4, 5π/4]。

局部最大 f(π/4) = √2/2 + √2/2 = √2；   局部最小 f(5π/4) = −√2/2 − √2/2 = −√2

(b) G(x) = 5x2/3 − 2x5/3（定义域：全体实数）

G′(x) = (10/3)x−1/3 − (10/3)x2/3 = (10/3) x−1/3(1 − x)

临界点有两个：x = 1（G′ = 0）与 x = 0（G′ 不存在 —— 这就是最容易漏的那个）。

区间x−1/31 − xG′G
(−∞, 0)−+−递减 ↘
(0, 1)+++递增 ↗
(1, +∞)+−−递减 ↘
G(0) = 0（局部最小）   G(1) = 5 − 2 = 3（局部最大）
(a) 增 [0, π/4] ∪ [5π/4, 2π]，减 [π/4, 5π/4]；局部最大 √2（x = π/4），局部最小 −√2（x = 5π/4）。
(b) 减 (−∞, 0)，增 (0, 1)，减 (1, +∞)；局部最小 G(0) = 0，局部最大 G(1) = 3。
坑：x2/3 这类分数幂，x = 0 处导数不存在但函数有极值，必须把“f′ 不存在的点”也当临界点列进表；只解 f′ = 0 会漏掉 (0,0) 这个极小点。

6凹凸性与拐点（f″ 符号表）

5(a) 续：f(x) = sin x + cos x

f″(x) = −sin x − cos x = −f(x)

所以 f″ = 0 恰好发生在 f = 0 处：√2 sin(x + π/4) = 0 ⇒ x = 3π/4, 7π/4。

区间(0, 3π/4)(3π/4, 7π/4)(7π/4, 2π)
f″ 符号−+−
凹凸凹向下 ∪→∩凹向上 ∪凹向下 ∩

凹凸性在 3π/4 与 7π/4 两处改变 ⇒ 两个拐点：(3π/4, 0) 和 (7π/4, 0)。

5(b) 续：G(x) = 5x2/3 − 2x5/3

G″(x) = (10/3)[ (−1/3)x−4/3(1 − x) − x−1/3 ] = (10/9) x−4/3(−1 − 2x)

G″ = 0 于 x = −1/2；x = 0 处 G″ 不存在。因为 x−4/3 > 0（x ≠ 0），G″ 的符号只由 −(1 + 2x) 决定：

区间(−∞, −1/2)(−1/2, 0)(0, +∞)
G″ 符号+−−
凹凸凹向上 ∪凹向下 ∩凹向下 ∩

凹凸只在 x = −1/2 处改变，那一点的函数值：

G(−1/2) = 5(1/4)1/3 − 2(−1/2)5/3 = 5·2−2/3 + 2·2−5/3 = 5·2−2/3 + 2−2/3 = 6·2−2/3 ≈ 3.78
(b) 凹性：凹向上 (−∞, −1/2)，凹向下 (−1/2, 0) ∪ (0, +∞)；唯一拐点 (−1/2, 6/22/3) ≈ (−0.5, 3.78)。x = 0 不是拐点 —— 虽然 G″(0) 不存在，但两侧都凹向下。

6. g(x) = x|x| 在 (0,0) 有拐点，但 g″(0) 不存在

g(x) = x² (x ≥ 0)；g(x) = −x² (x < 0)
g′(x) = 2x (x > 0)，g′(x) = −2x (x < 0)  ⇒  g′(x) = 2|x|，g′(0) = 0

于是 g″(x) = 2（x > 0）、−2（x < 0）。在 0 处用定义：

limh→0⁺ [g′(h) − g′(0)]/h = lim 2h/h = 2  ，  limh→0⁻ 2(−h)/h = −2

左右不相等 ⇒ g″(0) 不存在。但 x < 0 时 g″ = −2 < 0（凹向下）、x > 0 时 g″ = 2 > 0（凹向上），凹凸性在 0 处改变，且 g(0) = 0，故 (0,0) 是拐点。∎

要点：拐点只看“凹凸性是否改变”，不要求 g″ 在该点存在（也不要求 g′(0) = 0）。这题就是反例。

7. 三阶导判别法

P7. Suppose f″ is continuous and f′(c) = f″(c) = 0, but f‴(c) > 0. Does f have a local maximum or minimum at c? Does f have a point of inflection at c?

f‴ = (f″)′，f‴(c) > 0 ⇒ f″ 在 c 处严格递增；又 f″(c) = 0，于是 c 左侧 f″ < 0、右侧 f″ > 0。

  • f″ < 0 在左 ⇒ f′ 递减到 f′(c) = 0；f″ > 0 在右 ⇒ f′ 递增离开 0。所以 c 两侧都有 f′(x) > 0，f 在 c 两侧都在上升。
  • 因此在 c 处既没有局部最大也没有局部最小。
  • 但凹凸性由“下”变“上”，所以 c 是拐点。
答案：c 处无极值；c 是拐点（左凹下、右凹上）。
记忆：f′ = f″ = 0 且 f‴ ≠ 0 —— 极值看最低阶非零导数是不是偶数阶（f′ 的一阶非零是 f″… 这题 f″ 也 = 0，最低非零是 f‴ 的三次阶，奇数阶 ⇒ 拐点）。

8隐函数求导：dy/dx

四步：① 两边对 x 求导（把 y 看成 y(x)，遇到 y 就用链式法则乘 y′）；② 把含 y′ 的项移到一边、其余移到另一边；③ 提出 y′；④ 约分。别忘了把 y′ 全部收集干净，不能只抓一半。

9(a) tan(x/y) = x + y

sec²(x/y) · (y − x y′)/y² = 1 + y′

记 S = sec²(x/y)，两边乘 y² 整理：

S(y − x y′) = y²(1 + y′)  ⇒  Sy − Sx y′ = y² + y² y′  ⇒  y′(y² + Sx) = Sy − y²
答案：dy/dx = [ y sec²(x/y) − y² ] / [ y² + x sec²(x/y) ]

9(b) √(x + y) = 1 + x²y²

(1 + y′)/(2√(x + y)) = 2xy² + 2x²y y′

两边乘 2√(x+y)，把 y′ 的项集中：

1 + y′ = 4xy²√(x+y) + 4x²y√(x+y) y′
y′[4x²y√(x+y) − 1] = 1 − 4xy²√(x+y)
答案：dy/dx = [ 1 − 4xy²√(x + y) ] / [ 4x²y√(x + y) − 1 ]

9隐函数二阶导与切线

y″ 的套路：先用和上面一样的方法求出一阶 y′ 的表达式 → 再把 y′ 表达式代回去（这是关键一步，很多人只求了 y′ 就停）→ 用原方程化简，得到只含 x、y 的干净结果。

10(a) 9x² + y² = 9

18x + 2y y′ = 0  ⇒  y′ = −9x/y
y″ = −9 · (y − x y′)/y² = −9( y + 9x²/y )/y² = −9(y² + 9x²)/y³

用原方程 9x² + y² = 9 化简分子：

答案：y″ = −81/y³

10(b) √x + √y = 1

1/(2√x) + y′/(2√y) = 0  ⇒  y′ = −√y/√x
y″ = −[ (y′/(2√y))·x−1/2 − √y · ½x−3/2 ] = −[ y′/(2√(xy)) − √y/(2x3/2) ]

代入 y′ = −√y/√x，第一项变成 −1/(2x)：

y″ = 1/(2x) + √y/(2x3/2) = [ √x + (1 − √x) ] / (2x3/2) = 1/(2x3/2)
答案：y″ = 1/(2x3/2)。
验算捷径：由 √y = 1 − √x 得 y = (1 − √x)²，直接求导：y′ = 1 − x−1/2，y″ = ½x−3/2 ✓（两条路都对，考试时用验算那条更快）。

11. 切线：x² + y² = (2x² + 2y² − x)² at (0, ½)

先验点在曲线上：左边 = 0 + ¼ = ¼；右边 = (0 + ½ − 0)² = ¼ ✓。隐函数求导：

2x + 2y y′ = 2(2x² + 2y² − x)(4x + 4y y′ − 1)

代入 (x, y) = (0, ½)：2x² + 2y² − x = ½，4x + 4y y′ − 1 = 2y′ − 1，2y y′ = y′。

y′ = 2 · ½ · (2y′ − 1) = 2y′ − 1  ⇒  y′ = 1
答案：y − ½ = 1·(x − 0)，即 y = x + ½（或 2x − 2y + 1 = 0）。
坑：这类“高次曲线”代入点之后会得到关于 y′ 的一次方程 —— 但**必须先把所有数值代进去再解**，否则会得到一个乱七八糟的式子。

12. Bessel 函数 J(x)：J′(0) 与 J″(0)

P12. y = J(x) satisfies x y″ + y′ + xy = 0 for all x, and J(0) = 1.

(a) 直接令 x = 0：

0·J″(0) + J′(0) + 0·J(0) = 0  ⇒  J′(0) = 0

(b) 把整个微分方程再对 x 求导（这就是“对方程做隐函数求导”）：

(y″ + x y‴) + y″ + (y + x y′) = 0  ⇒  x y‴ + 2y″ + y + x y′ = 0

再令 x = 0，并用 J(0) = 1、J′(0) = 0：

0 + 2J″(0) + 1 + 0 = 0  ⇒  J″(0) = −½
答案：J′(0) = 0，J″(0) = −1/2。
顺带记住：把 x = 0 代进方程能“消掉”含 x 的项，是这类题唯一的技巧；求 n 阶值就把方程求导 n−1 次再代 x = 0。

10取对数求导与 arcsec 的导数

什么时候取对数：底和指数都含 x（如 (sin x)ln x、xx），或连乘连除一大堆因子。步骤：ln y = 指数 × ln 底 → 两边求导得 y′/y → 乘回 y。

13(a) y = (sin x)ln x

ln y = ln x · ln(sin x)
y′/y = (1/x)·ln(sin x) + ln x · (cos x/sin x) = ln(sin x)/x + ln x · cot x
答案：y′ = (sin x)ln x [ ln(sin x)/x + ln x · cot x ]

13(b) y = (ln x)cos x

ln y = cos x · ln(ln x)
y′/y = −sin x · ln(ln x) + cos x · [1/ln x] · [1/x]
答案：y′ = (ln x)cos x [ −sin x · ln(ln x) + cos x/(x ln x) ]
坑：对 ln(ln x) 求导时才是 1/(x ln x)（两层链式）；只写 1/ln x 或 1/x 都错。

14. 证明 (sec−1x)′ = 1/(|x|√(x² − 1))，|x| > 1

定义：y = sec−1x ⇔ sec y = x，且 y ∈ [0, π/2) ∪ (π/2, π]。两边对 x 求导：

sec y tan y · dy/dx = 1  ⇒  dy/dx = 1/(sec y tan y) = 1/(x tan y)

由 1 + tan²y = sec²y = x² 得 tan y = ±√(x² − 1)，符号由 y 的范围决定：

x 的范围y 的范围tan ydy/dx
x > 1[0, π/2)+√(x² − 1)1/(x√(x² − 1))
x < −1(π/2, π]−√(x² − 1)−1/(x√(x² − 1)) = 1/(|x|√(x² − 1))

两种情形合并：x tan y = |x|√(x² − 1)。因此

d/dx (sec−1x) = 1/(x tan y) = 1/( |x| √(x² − 1) )，|x| > 1 ∎
要点：绝对值来自 y 的取值范围（x < 0 时 tan y < 0），不是硬加的。写证明时必须把“为什么是 |x|”讲清楚，这是本题的采分点。

12十个高频失分点

  1. 漏端点：闭区间最值必须把 a、b 两端的值算进去 —— 2(a) 的最小值恰好就在端点 t = −1。
  2. 漏 f′ 不存在的临界点：5(b) 的 x = 0、8(a) 的 x = 5 都是这种情况。
  3. 只解出根不判符号：题目问“增区间”，必须给出符号表，不能只写 f′ = 0 的根。
  4. 把“极值点”和“极值”搞混：问局部最大值时要答函数值（如 √2），位置另附（x = π/4）。
  5. 拐点写成 x 值：拐点是点，要写成 (3π/4, 0) 这种坐标形式。
  6. 以为拐点必须 f″ = 0：g(x) = x|x| 的拐点处 f″ 根本不存在（第 6 题就是为了纠正这一点）。
  7. y″ 求出后没代回 y′：10(a)、(b) 的 y″ 里不允许残留 y′。
  8. ln(ln x) 求导漏一层：结果是 1/(x ln x)，不是 1/ln x。
  9. arcsec 的绝对值理由不足：|x| 是由 tan y 的符号推出来的，必须写出 x < −1 的情形讨论。
  10. 比大小靠小数：1/4 与 3/13 这种要化成同分母再比，别用 ≈0.25 与 ≈0.231 下结论。
