6第 6 章 分子形状、极性与分子间作用力

Lecture 7 的前半段（7.1–7.3）。这一章回答三个问题：分子长什么样（VSEPR）、有没有极性（矢量和）、分子之间靠什么粘在一起（IMF）。

6.1 画 Lewis 结构的五步

  1. 数总价电子（离子：阴离子加、阳离子减）。
  2. 定中心原子（电负性最小、或题目指定；H 与 F 永远在末端）。
  3. 单键连骨架（每键用 2 个电子）。
  4. 剩余电子先补满末端原子，再给中心原子。
  5. 中心原子不满八隅体 → 把末端孤对改成双键/三键。

6.2 形式电荷 formal charge

FC = 价电子数 −（孤对电子数 + ½ 成键电子数）
  • 所有原子 FC 之和 = 物种总电荷（检验手段）。
  • 最稳定的共振式：FC 尽量接近 0；负 FC 落在电负性大的原子上。

6.3 八隅体例外

类型例子说明
缺电子BeH₂、BeCl₂（4 e）、BF₃（6 e）中心原子不满 8
奇电子NO、NO₂必有未成对电子，顺磁
扩展八隅体PCl₅（10 e）、SF₆（12 e）、SO₃、ClO₄⁻第三周期起可用 d 轨道

6.4 共振 resonance

  • 多个只差电子分布的 Lewis 式 → 真实结构是共振杂化体，键级介于两者之间。
  • 判断"哪个更重要"：FC 接近 0 > 负电荷在电负性大的原子 > 不违背八隅体。
  • 苯（C₆H₆）两个共振式，六个 C–C 键完全等价 → 键级 1.5。

键角为什么变小：斥力 孤对–孤对 > 孤对–成键 > 成键–成键，所以 NH₃（107°）< CH₄（109.5°），H₂O（104.5°）更小。三角双锥中孤对优先占赤道位。

6.6 极性 = 键矩的矢量和

  1. 先看有没有极性键（ΔEN ≠ 0）。
  2. 再看几何对称性：对称 → 键矩抵消 → 非极性（BF₃、CCl₄、PCl₅、XeF₄、SF₆）。
  3. 不对称 → 极性（H₂O、NH₃、SO₂、CHCl₃）；有孤对几乎一定极性。
  • 例：BF₃ 的 B–F 键是极性的，但分子是非极性（120° 对称抵消）；CCl₄ 键极性、分子非极性；PCl₅ 非极性。
  • 偶极矩可区分异构体：顺式二氯乙烯 polar，反式 nonpolar（这也是它们沸点不同的原因）。

偶极矩与百分离子性

μ = Q × r，　1 D = 3.336×10⁻³⁰ C·m
百分离子性 = μ(实验) / μ(完全离子) × 100%，　μ(完全离子) = e × d

例（HW5-3）：BrF，μ = 1.42 D、d = 1.76 Å → μionic = 1.602×10⁻¹⁹ × 1.76×10⁻¹⁰ = 2.82×10⁻²⁹ C·m，μexp = 4.74×10⁻³⁰ C·m → 16.8% 离子性。

6.7 分子间作用力（IMF）

分子间作用力是相邻分子之间的吸引，远比化学键弱，但决定沸点、熔点、溶解度。

类型存在条件强度例
色散力 LDF（dispersion）所有分子都有；来自瞬时偶极随电子数/摩尔质量/极化率增大而增强F₂ < Cl₂ < Br₂ < I₂
偶极–偶极极性分子之间取决于偶极矩大小HCl、CH₃COCH₃
氢键H 直接连 N、O、F 时最强（约 10–40 kJ/mol）H₂O、NH₃、HF、醇、羧酸
离子–偶极离子 + 极性溶剂——Na⁺(aq)、水合

要点

  • 色散力依赖"电子有多容易被扰动"（极化率）：分子越大、电子越多，瞬时偶极越大，沸点越高。卤素常温下的状态（F₂、Cl₂ 气体 → Br₂ 液体 → I₂ 固体）就是这个规律。
  • 氢键的判据是结构，不是"有没有 H"：CH₄、H₂S、HCl 都没有氢键。
  • 强度顺序：离子–偶极 > 氢键 > 偶极–偶极 > 色散力；但所有分子都有色散力，答题时别漏。
