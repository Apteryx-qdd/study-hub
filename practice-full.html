第 1 题（10 分）一根金属棒

某金属棒为圆柱体，测得半径 0.500 cm、长 3.60 cm、质量 20.15 g。

(a) 计算该金属的密度（保留正确有效数字）。　（3 分）

(b) 已知下列密度：Al 2.70、Ti 4.54、Fe 7.87、Zn 7.14 g/cm³。判断这是什么金属。　（2 分）

(c) 该棒中含多少个原子？（用你判断出的金属，M 取 65.38 g/mol）　（3 分）

(d) 把该金属与同周期的 Cu、以及上一周期的 Mg 比较原子半径，由大到小排序，并用有效核电荷 Zeff 解释。　（2 分）

(c) 该光子能否电离基态氢原子（IE = 13.6 eV）？能否电离基态氦原子（IE = 24.6 eV）？为什么 He 的 IE 比 H 大近一倍？（1 分）

2详解

第 1 题

(a) V = πr²h = π × (0.500)² × 3.60 = 2.827 cm³；d = m/V = 20.15 / 2.827 = 7.13 g/cm³（3 位有效数字，由 20.15 与 3.60 中最少的 3 位决定）。

(b) 7.13 与 Zn 的 7.14 一致 → 锌 Zn。（Al 2.70、Ti 4.54 差得远；Fe 7.87 也偏高。）

(c) n = 20.15 / 65.38 = 0.3082 mol；N = 0.3082 × 6.022×10²³ = 1.86×10²³ 个原子。

(d) 半径：Cu < Zn < Mg（Cu 128 pm、Zn 134 pm、Mg 160 pm）。同周期内 Zeff 增大 → 半径减小，所以 Cu 与 Zn 都很小（Zn 略大，因为 3d¹⁰ 全满后屏蔽略增）。Mg 虽在上一周期（n = 3），却是三者中最大的：进入第一过渡系后多出 10 个 3d 电子，它们屏蔽能力差、而核电荷增加了 10，导致"周期变大、半径反而缩小"——K(227)、Ca(197) 比 Mg 大，但从 Sc 开始就掉到 Mg 以下了。

第 2 题

(a) E = hc/λ = (6.626×10⁻³⁴ × 2.998×10⁸) / (121.6×10⁻⁹) = 1.63×10⁻¹⁸ J；换算 eV：1.63×10⁻¹⁸ / 1.602×10⁻¹⁹ ≈ 10.2 eV。

(b) W = hν − KE = 1.63×10⁻¹⁸ − 3.20×10⁻¹⁹ = 1.31×10⁻¹⁸ J（≈ 8.2 eV）；

ν₀ = W/h = 1.31×10⁻¹⁸ / 6.626×10⁻³⁴ = 1.98×10¹⁵ Hz。

(c) λ₀ = hc/W = 1.986×10⁻²⁵ / 1.31×10⁻¹⁸ = 1.5×10⁻⁷ m = 151 nm。

(d) 250 nm 的光子能量 E = hc/λ = 7.95×10⁻¹⁹ J < W，低于阈值 → 打不出电子（无论光多强）。

第 3 题

(a) 1/λ = RH(1/2² − 1/3²) = 1.097×10⁷ × 0.1389 = 1.524×10⁶ m⁻¹ → λ = 656 nm，红色（Balmer 系的 Hα 线）。

(b) E = hc/λ = 1.986×10⁻²⁵ / 6.56×10⁻⁷ = 3.03×10⁻¹⁹ J ≈ 1.89 eV。

(c) p = √(2mE) = √(2 × 9.109×10⁻³¹ × 3.03×10⁻¹⁹) = 7.43×10⁻²⁵ kg·m/s；

λ = h/p = 6.626×10⁻³⁴ / 7.43×10⁻²⁵ = 8.9×10⁻¹⁰ m ≈ 0.89 nm。

(d) 棒球的 λ = h/(mu) ≈ 1.1×10⁻³⁴ m，比原子核还小十几个数量级，没有任何仪器能分辨，所以宏观物体的波动性观测不到。

第 4 题

(a) 1s²2s²2p⁶3s²3p⁶3d⁵4s¹，即 [Ar]3d⁵4s¹ → Cr（Z = 24）。

(b) 按 Aufbau 应为 4s²3d⁴；把 4s 的一个电子挪到 3d，得到半满的 3d⁵，交换能更大、体系更稳定。

(c) 3d⁵ 有 5 个单电子、4s¹ 有 1 个 → 6 个未成对电子，顺磁（磁矩最大的一类原子之一）。

(d) Cr³⁺：[Ar]3d³。Cr 有 6 个价电子（3d⁵4s¹），失去 3 个后剩 3 个 3d 电子；IE₄ 要从内层 3p 拔电子，能量陡增 → IE₁~IE₃ 平缓、IE₄ 出现巨大跳跃，正好对应"3 个价电子"。

第 5 题

(a) 半径：Si < Mg < Na < K（同周期左→右减小：Na > Mg > Si；K 多一层，最大）。

(b) IE₁：Na < Al < Mg < Si。整体左→右增大，但 Mg（3s² 全满）> Al（3p¹ 易失），这是第二周期的经典反常。

(c) 离子半径：Mg²⁺ < Na⁺ < F⁻ < O²⁻ < N³⁻。五者都是 10 电子等电子体，核电荷越大（Mg 12 > Na 11 > F 9 > O 8 > N 7）半径越小。

(d) EA₁：O < S < F < Cl（教材值 O 141、S 200、F 328、Cl 349 kJ/mol）。同族上→下略增（半径大、电子排斥小），同周期左→右增大；F 因半径过小、电子间排斥强而低于 Cl。

第 6 题

(a) Ca₃(PO₄)₂ = calcium phosphate；N₂O₅ = dinitrogen pentoxide；CuSO₄·5H₂O = copper(II) sulfate pentahydrate；HClO₃ = chloric acid。

(b) M = 3×40.08 + 2×(30.97 + 4×16.00) = 120.24 + 189.94 = 310.2 g/mol；

%P = (2 × 30.97) / 310.2 × 100% = 20.0%。

(c) 价电子：5 + 4×6 + 3 = 32。P 居中，4 个 P–O 单键（8 e），每个 O 补 3 对孤对（24 e），P 上无孤对 → P 周围 8 e，各 O 8 e。

形式电荷：P 有 4 个键 → FC = 5 − (0 + 4) = +1；每个 O 带 3 对孤对 → FC = 6 − (6 + 1) = −1；总和 −3 ✓。

电子域 = 4 → sp³，正四面体，键角 109.5°。（更好的写法是让一个 P=O 双键把 FC 降到 0，但那就是扩展八隅体了。）

第 8 题

(a) O₂ 有 12 个价电子：σ2s² σ∗2s² σ2p² π2p⁴ π∗2p²；

键级 = (8 − 4)/2 = 2。

(b) π∗2p 上有 2 个未成对电子（分占两个简并轨道）→ 顺磁。这是 Lewis 结构（O=O，全部成对）预测不出来的。

(c) N₂ 有 10 个价电子：σ2s² σ∗2s² π2p⁴ σ2p² → 键级 3。键级越大键越短越强：N₂ 键长（109.8 pm）< O₂（120.7 pm），键能 N₂（945）> O₂（498 kJ/mol）。

(d) O₂⁺ 有 11 个价电子（从 π∗ 拿走 1 个）→ 键级 2.5，1 个未成对 → 顺磁；O₂⁻ 有 13 个 → 键级 1.5，1 个未成对 → 顺磁。

第 9 题

(a) n(C) = n(CO₂) = 1.137/44.01 = 0.02583 mol → m(C) = 0.3103 g；

n(H) = 2 × n(H₂O) = 2 × 0.4654/18.02 = 0.05166 mol → m(H) = 0.0521 g；

m(O) = 0.5000 − 0.3103 − 0.0521 = 0.1376 g。

(b) n(O) = 0.1376/16.00 = 0.00860 mol；

C : H : O = 0.02583 : 0.05166 : 0.00860 = 3.00 : 6.01 : 1 → C₃H₆O（M = 58.08）。

(c) n = 58.08 / 58.08 = 1 → 分子式就是 C₃H₆O。

(d) 丙酮：CH₃–C(=O)–CH₃，中心羰基碳有 3 个电子域（2 个 C–C、1 个 C=O）→ sp²、平面三角（120°）；C=O 使分子不对称、有净偶极矩 → 极性分子（还带来较强的偶极–偶极作用，沸点 56 ℃，远高于同分子量的丙烷 −42 ℃）。

第 10 题

(a) En = −2.18×10⁻¹⁸ Z²/n²，He⁺ 的 Z = 2：

ΔE = 2.18×10⁻¹⁸ × 4 × (1/1² − 1/2²) = 2.18×10⁻¹⁸ × 4 × 0.75 = 6.54×10⁻¹⁸ J ≈ 40.8 eV。

(b) KE = hν − W = 40.8 − 2.14 = 38.7 eV（≈ 6.19×10⁻¹⁸ J）。

(c) 40.8 eV > 13.6 eV → 能电离基态氢；40.8 eV > 24.6 eV → 也能电离基态氦。He 的 IE 约为 H 的两倍，因为核电荷从 +1 增到 +2（Zeff 翻倍），1s 电子被拉得更紧。

本套最容易丢分的 8 处

  1. 第 1(a) 忘了 π 的位数不影响结果，但有效数字由 0.500 与 3.60 的 3 位决定。
  2. 第 2(b) 把 hν 与 KE 相减时忘记统一到 J 或 eV。
  3. 第 3(c) 直接用光子能量当电子动能算 λ，忘记 p = √(2mE)。
  4. 第 4(c) 只数 3d⁵ 的 5 个，漏掉 4s¹ 的 1 个。
  5. 第 5(b) 把 Al 排在 Mg 前面（Mg > Al 是全满 vs 3p¹ 的反常）。
  6. 第 6(c) 形式电荷算成 −4 或 0（P 是 +1、每个 O 是 −1，总和 −3）。
  7. 第 7 表里把 NH₃ 的几何写成"四面体"（那是电子域几何，分子几何是三角锥）。
  8. 第 8 题答"O₂ 反磁"（π∗ 上有 2 个未成对电子，是顺磁；键级 2 与顺磁不矛盾）。
