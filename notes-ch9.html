9第 8–9 章 化学计量与水溶液中的反应

Lecture 8 末尾（8.3–8.4）与 Lecture 9 全部（9.1–9.6）。这一章是"算"的主战场：配平 → 找限量试剂 → 算产率 → 换算浓度 → 判断反应类型 → 写净离子方程。

9.1 化学方程式与配平

  • 系数代表摩尔比，不是质量比；配平后两边原子数与电荷数都要守恒。
  • 常见反应类型：combination（化合）、decomposition（分解）、combustion（燃烧）、displacement（置换）、metathesis / double replacement（复分解）、disproportionation（歧化）。

9.2 限量试剂与产率

  • 限量试剂 limiting reactant：最先被消耗完的反应物，决定产量。
  • 判断方法：把每种反应物的 n 都除以它的系数，商最小的是限量试剂。
  • 过量试剂剩余量 = 初始量 − 已反应量。
  • 理论产量按限量试剂算；实际产量由实验给出。
百分产率 %yield = (实际产量 / 理论产量) × 100%

例（Worked Example 8.7，Alka-Seltzer）：3NaHCO₃ + H₃C₆H₅O₇ → 3CO₂ + 3H₂O + Na₃C₆H₅O₇；1.700 g NaHCO₃（84.01）与 1.000 g 柠檬酸（192.12）。n(NaHCO₃) = 0.02023 mol，n(酸) = 0.005205 mol；按系数比 NaHCO₃ 需要 3×0.005205 = 0.01562 mol < 0.02023 → 柠檬酸是限量试剂，NaHCO₃ 过量 0.00461 mol ≈ 0.387 g，CO₂ 产量 3×0.005205×44.01 ≈ 0.687 g。

9.3 溶液的浓度

M = n(溶质) / V(溶液，L)　　（mol/L，注意分母是溶液体积不是溶剂体积）
稀释：M₁V₁ = M₂V₂（稀释前后溶质的物质的量不变）
  • 用 mL 时可直接写 M_c × mL_c = M_d × mL_d。
  • 系列稀释 serial dilution：多次等倍数稀释，浓度按倍率连乘。
  • 溶液化学计量：V × M → mol → 用系数比 → 目标物的 mol → 再转回 V 或 m。

9.4 电解质与沉淀反应

  • 溶液 = 溶剂（量最多）+ 溶质；电解质溶后导电（解离或电离），非电解质不导电（如蔗糖）。
  • 强电解质：可溶离子化合物、强酸、强碱（完全解离）；弱电解质：弱酸弱碱（部分电离，以分子为主）。
  • 必背 7 个强酸：HCl、HBr、HI、HNO₃、H₂SO₄、HClO₄、HClO₃。
  • 常见强碱：LiOH、NaOH、KOH、RbOH、CsOH、Ca(OH)₂、Sr(OH)₂、Ba(OH)₂。

溶解度规则（Table 9.2 / 9.3）

通常可溶例外
碱金属（Li⁺、Na⁺、K⁺…）与 NH₄⁺ 的盐几乎没有

三种方程式

  1. 分子方程：全部写化学式。
  2. 完全离子方程：强电解质拆成离子，沉淀/弱电解质/气体保留分子式。
  3. 净离子方程：删去两边相同的旁观离子 spectator ions，只留真正参与反应的物种。
例：Na₂SO₄(aq) + Ba(OH)₂(aq) → 2NaOH(aq) + BaSO₄(s)
净离子：Ba²⁺(aq) + SO₄²⁻(aq) → BaSO₄(s)

9.5 酸碱反应

  • Arrhenius：酸在水中产生 H⁺，碱产生 OH⁻。
  • Brønsted：酸 = 质子给体，碱 = 质子受体；H⁺ 与 H₃O⁺ 指同一物种。
  • 一元酸 monoprotic / 多元酸 polyprotic：H₂SO₄ 第一步强、第二步很弱（逐级电离）。
  • 中和：酸 + 碱 → 水 + 盐；绝大多数净离子式就是
H⁺(aq) + OH⁻(aq) → H₂O(l)

9.6 氧化还原反应

  • 氧化 = 失电子（氧化数升高）；还原 = 得电子（氧化数降低）；两者同时发生。
  • 还原剂被氧化，氧化剂被还原（口诀：升失氧、降得还）。

氧化数规则

  1. 单质的氧化数 = 0。
  2. 同种物种各原子氧化数之和 = 该物种的电荷。
  3. 单原子离子的氧化数 = 离子电荷。
  4. 常见固定值：F = −1；O = −2（过氧化物中 −1）；H = +1（金属氢化物中 −1）；1A = +1、2A = +2。

活性顺序 activity series：按"越靠上越易被氧化"排列（Li > K > Ba > Ca > Na > Mg > Al > Zn > Fe > Ni > Sn > Pb > H₂ > Cu > Hg > Ag > Au）。上面的金属能把下面金属的离子置换出来；反方向不反应。

半反应法配平

  1. 拆成氧化、还原两个半反应；
  2. 各自配平原子（O 用 H₂O、H 用 H⁺）；
  3. 各自配平电荷（加 e⁻）；
  4. 两边乘系数使电子数相等；
  5. 相加，约去电子，检查原子与电荷。

例：Cr + Ni²⁺ → Cr³⁺ + Ni → 2×{Cr → Cr³⁺ + 3e⁻} + 3×{Ni²⁺ + 2e⁻ → Ni} → 2Cr + 3Ni²⁺ → 2Cr³⁺ + 3Ni。

其他 redox 类型：化合（N₂ + 3H₂ → 2NH₃）、分解（2NaH → 2Na + H₂）、置换、歧化（同一元素既升又降，如 H₂O₂ 中 O 为 −1）、燃烧。

9.7 pH

pH = −log[H₃O⁺]，　[H₃O⁺] = 10^(−pH)
  • 25 ℃ 纯水：[H₃O⁺] = 1.0×10⁻⁷ M → pH = 7.00（中性）；pH 无量纲。
  • 例：3.5×10⁻⁴ M → pH = 3.46；2×10⁻⁷ M → pH = 6.70。

9.8 重量分析与滴定

  • 重量分析 gravimetric analysis：靠称沉淀质量反推被测组分（要求反应完全、接近 100% 产率）。例：AgCl 沉淀 → %Cl = (m(AgCl)/M(AgCl) × M(Cl)) / m(样品) × 100%。
  • 滴定 titration：用已知浓度的标准溶液（buret）滴定待测液，当量点 equivalence point 由指示剂变色（endpoint）指示。
  • NaOH 溶液需用 KHP（邻苯二甲酸氢钾，一元酸）标定，因为 NaOH 会吸收 CO₂ 变质。
  • 计算骨架：n(酸) × 系数比 = n(碱) → 由 M、V 互算。

9.9 HW7 答案对照（化学计量 + 氧化还原配平）

HW7 正好落在本章：判断题考配平/限量/经验式/产率的概念，选择题考"谁是氧化剂"与配平系数，大题是限量试剂与产率。

判断题（1–7）

题答案理由
1F配平要求原子守恒，不要求分子数相等（N₂ + 3H₂ → 2NH₃ 就是 4 → 2）
2F限量试剂是 n/系数 最小的那个，与质量大小无关
3T经验式 = 最简整数比
4T不同化合物可以共用经验式（CH₂O：甲醛、乙酸、葡萄糖）
5F反过来才对：每个化合物只有一个经验式，但一个经验式可对应多个化合物
6T分子式 = (经验式)ₙ，n 为正整数
7T%yield = 实际/理论 × 100%

大题要点

  • 戊烷燃烧：n(CO₂) = 825/44.01 = 18.7 mol，与 5.0 mol C₅H₁₂ 的比值只有 3.75 < 5 → C₅H₁₂ 过量、O₂ 限量；n(H₂O) = 18.7 × 6/5 = 22.5 mol → 405 g。
  • Li₃N：n(Li) = 1.77 mol、n(N₂) = 1.20 mol，Li 只能消耗 0.295 mol N₂ → Li 限量；理论产量 = 1.77/6 × 2 × 34.83 = 20.6 g，产率 = 5.89/20.6 = 28.6%。
  • (NH₄)₂SO₄：属化合（酸碱中和）；1.00×10⁵ kg ÷ 132.14 g/mol = 7.57×10⁵ mol → NH₃ 需 1.51×10⁶ mol ≈ 2.58×10⁴ kg。
  • NO + O₂：n(NO) = 0.886 mol、n(O₂) = 0.503 mol；0.886 mol NO 只需 0.443 mol O₂ → O₂ 过量、NO 限量；n(NO₂) = 0.886 mol。
