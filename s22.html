2§2.2 直接法：高斯消元（本节是全场核心）

工具增广矩阵与初等行变换

只记录系数与常数项：方程组 → 增广矩阵 [A | b]。三种方程运算翻译成三种初等行变换：

  R_i ↔ R_j            交换两行
  R_i ← k·R_i          k ≠ 0
  R_i ← R_i + k·R_j    把另一行的倍数加过来

行变换把方程组变成等价方程组（解集不变）。

定义REF / RREF / 主元 / 自由变量

行阶梯形 REF：① 全零行在最下面；② 每个非零行的第一个非零元（叫主元 pivot）严格位于上一行主元的右侧。
简化行阶梯形 RREF：在 REF 基础上再加 ③ 每个主元都是 1；④ 主元所在列的其它元素全是 0。

主元列 = 含主元的那些列；其余列叫自由列，对应的变量叫自由变量（free variable）。

定理三个必背判据

判据 1（相容性）：方程组相容 ⇔ RREF 中没有形如 [0 ⋯ 0 | c]（c ≠ 0）的行。
判据 2（唯一解）：相容 且 没有自由变量（每列都是主元列）。
判据 3（无穷多解）：相容 且 有自由变量。

记忆：先看相容（有没有矛盾行），再看自由变量（有没有多余列）。

常见错：看到“有自由变量”就说“有无穷多解”。错！若同时出现 [0 ⋯ 0 | c]，那是无解，自由变量不影响结论。

例题完整消元（唯一解）

解 x + y + z = 6，2x − y + z = 3，x + 2y − z = 2。

  [ 1   1   1 |   6 ]
  [ 2  −1   1 |   3 ]
  [ 1   2  −1 |   2 ]

  R2 ← R2 − 2R1,   R3 ← R3 − R1
  [ 1   1   1 |   6 ]
  [ 0  −3  −1 |  −9 ]
  [ 0   1  −2 |  −4 ]

  R2 <-> R3
  [ 1   1   1 |   6 ]
  [ 0   1  −2 |  −4 ]
  [ 0  −3  −1 |  −9 ]

  R3 ← R3 + 3R2
  [ 1   1   1 |   6 ]
  [ 0   1  −2 |  −4 ]
  [ 0   0  −7 | −21 ]      <-- REF 完成

回代：−7z = −21 ⇒ z = 3；y − 2(3) = −4 ⇒ y = 2；x + 2 + 3 = 6 ⇒ x = 1。解 (1, 2, 3)。

三个主元、三列全是主元列 ⇒ 唯一解，与计算一致。

例题无解 与 无穷多解（两种典型长相）

(a) 无解：x + y = 2，2x + 2y = 5。

  [ 1  1 | 2 ]  R2−2R1  [ 1  1 |  2 ]
  [ 2  2 | 5 ]  ──────→ [ 0  0 |  1 ]   ← 0 = 1，矛盾 ⇒ 无解

(b) 无穷多解：x + 2y − z = 1，2x + 4y − 2z = 2。

  [ 1  2  −1 | 1 ]  R2−2R1  [ 1  2  −1 | 1 ]
  [ 2  4  −2 | 2 ]  ──────→ [ 0  0   0 | 0 ]   ← 整行 0，相容

只剩一个方程：x = 1 − 2y + z。令 y = s，z = t（两个自由变量）：

(x, y, z) = (1, 0, 0) + s(−2, 1, 0) + t(1, 0, 1)，s, t ∈ ℝ

这是“一个特解 + 齐次通解”的标准写法。

专题齐次方程组 Ax = 0

齐次方程组一定有解（零解），所以只需区分：

Ax = 0 只有零解 ⇔ 没有自由变量（每列都是主元列）；
Ax = 0 有非零解 ⇔ 有自由变量（列数 > 主元个数）。

快速判断：若 A 是 m×n 且 m < n（方程比未知数少），则齐次方程组必有无穷多非零解。

解的结构（常考一句话）：Ax = b 的通解 = 一个特解 + Ax = 0 的通解。

高频含参数讨论（大题常客）

例：k 取何值时，方程组 x + y = 1，kx + ky = 3 无解 / 有无穷多解？

  [ 1  1 | 1 ]  R2−kR1  [ 1  1 |   1   ]
  [ k  k | 3 ]  ──────→ [ 0  0 | 3 − k ]
  • k ≠ 3：末行是 0 = 3 − k ≠ 0 ⇒ 无解；
  • k = 3：末行全 0，剩下 x + y = 1 ⇒ 无穷多解（x = 1 − t, y = t）；
  • 本题不可能唯一解（第二行是第一行的倍数，两直线永远平行或重合）。
套路：把含参数的项留在最后一行，写出“末行 = (0 ⋯ 0 | 表达式)”，再讨论表达式 = 0 / ≠ 0。分类要互斥且完备。
