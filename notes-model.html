12十类题型模板

模板 1：有效数字与单位换算

写"给定值 → 换算因子 → 结果"，每步标单位，最后一次性定有效数字。

模板 2：同位素丰度反解

设丰度 x 与 1−x，列 Σ(m_i·x_i) = 平均质量，解一次方程；检验 x ∈ (0,1)。

模板 3：光子能量 / 光电效应 / 光谱

先算 E = hc/λ，再用 ΔE = E_光子 与能级差联立；注意 J 与 kJ/mol 的换算。

模板 4：量子数合法性 / 容量

逐项检查 n ≥ 1、0 ≤ l ≤ n−1、|ml| ≤ l、ms = ±½；容量用 2(2l+1) 与 2n²。

模板 5：电子排布 + 磁性

Aufbau 填 → noble-gas 简式 → 画轨道图 → 数未成对 → 判顺/反磁；离子先失最外层。

模板 6：趋势排序（半径/IE/EA/离子半径）

定位周期表 → 同周期用 Zeff、同族用 n → 检查反常（2A/3A、5A/6A、全满/半满）→ 等电子系列按 Z 排。

模板 7：结构四连（Lewis → VSEPR → 杂化 → 极性）

画 Lewis → 数电子域 → 定几何与键角 → 定杂化（sp/sp²/sp³/…）→ 看对称性判极性 → 注明 σ/π 数目。

模板 8：MO 键级与磁性

写出价电子数 → 按正确能级顺序填 → 数成键/反键 → BO = (N_b − N_a)/2 → 看未成对电子判磁性。

模板 9：水溶液计算（限量试剂 / 浓度 / 滴定）

配平 → 全部换算成 mol → 除以系数比找限量 → 目标物 mol → 转质量或体积；浓度题用 M = n/V 与 M₁V₁ = M₂V₂。

模板 10：氧化还原配平

拆半反应 → 配原子（H₂O/H⁺）→ 配电荷（e⁻）→ 电子数通分 → 相加 → 查原子与电荷。
