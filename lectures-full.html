0四讲主线：一条线串起来

这四讲不是四块独立内容，而是同一件事不断“升维”：解方程 → 把方程写成矩阵 → 用消元读出结构。

线性方程组→ 等价变形（不改变解集）→ 增广矩阵 [A|b]→ 初等行变换 / 行阶梯形→ Ax = b（列的组合）→ span / 线性无关→ 行空间·基·维数·秩→ 子空间 + 秩定理→ 矩阵代数（乘法·转置）

一句话概括每一讲

  • L1：高斯消元 = 用三种可逆的方程运算，把方程组变形成三角形，再从下往上回代。
  • L2：解 Ax=b 等价于问「b 能不能写成 A 的列向量的线性组合」，系数 (x₁,…,xₙ) 就是答案；而线性无关问的是「有没有多余的向量」。
  • L3：把向量按行堆成矩阵 → 行空间；行变换不改变行空间 → 于是阶梯形的非零行就是一组基，其个数 = 维数 = 秩。
  • L4：行空间、列空间、零空间都是子空间；rank(A) + nullity(A) = n；最后把矩阵当成一种“数”，研究它的加法、乘法、转置。

2L1 · 线性方程组与高斯消元

定义线性方程与线性方程组

线性方程（n 个未知量）指可以写成

a₁x₁ + a₂x₂ + ⋯ + anxn = b，其中 a₁,…,an, b 都是常数

关键特征：每个变量只出现一次幂，并且只被常数相乘。所以下列都不是线性的：

xy（变量相乘）x²（幂次≠1）1/x（倒数）sin x（非线性函数）√x

线性方程组：m 个方程、n 个未知量；解是一个有序数组 (s₁,…,sn)，它同时满足每一个方程；所有解构成解集。

核心三种解的情形与“相容”

任何线性方程组只有三种可能：

  1. 唯一解（unique）：R² 中两直线交于一点；
  2. 无穷多解（infinitely many）：两直线重合；
  3. 无解（no solution）：两直线平行且不重合。

相容 consistent = 至少有一个解；不相容 inconsistent = 无解。

R² 中：相交 ⇒ 唯一解　|　重合 ⇒ 无穷多解　|　平行不重合 ⇒ 无解

方法等价方程组与三种方程运算

两个方程组等价（equivalent）⇔ 解集完全相同。我们不必直接解原方程组，而是把它变成更简单但等价的方程组。允许的三种运算：

  1. 交换两个方程；
  2. 用一个非零常数乘某个方程；
  3. 把一个方程的倍数加到另一个方程上。
为什么可以这样做？三种运算都是可逆的（能原路退回去），所以既不会丢解，也不会增解——解集不变。
注意：这里的“可逆”指运算本身可逆，跟“求矩阵的逆 A−1”是两件事（求逆见文末附录 A）。

例（L1 幻灯片）：x − y = 1, x + y = 3 ⟺ x − y = 1, y = 1。后者容易，直接回代得 x = 2, y = 1。

方法回代 back substitution

当方程组呈三角形（最后一个方程只含最后的变量）时，从下往上逐个解出：

  1. 先解最后一个方程，得到最后一个变量；
  2. 把已知值代回上一个方程；
  3. 重复，直到所有变量都求出。
例：x − y + z = 2，y + 3z = 5，5z = 10 ⟹ z = 2 → y = −1 → x = −1

对象增广矩阵、矩阵、向量

反复抄写变量太麻烦，于是只记录系数与常数项（竖线左边是系数矩阵 A，右边是 b）：

  x − y − z = 2            [ 1  −1  −1 |  2 ]
  3x − 3y + 2z = 16   ⟹    [ 3  −3   2 | 16 ]
  2x −  y +  z = 9         [ 2  −1   1 |  9 ]
  • 矩阵：数的矩形排列；m 行 n 列 ⟹ m×n 矩阵；第 i 行第 j 列的元素记 aij。
  • 向量：有序数组（n×1 为列向量，1×n 为行向量）。
  • 矩阵记号不是新问题，只是一种更紧凑的存储方式；最终可以写成 Ax = b。

方法初等行变换与行阶梯形（REF）

三种方程运算翻译成矩阵语言，就是三种初等行变换：

方程运算矩阵记号备注
交换两式Ri ↔ Rj可逆
乘非零常数Ri ← k Ri要求 k ≠ 0
加另一式的倍数Ri ← Ri + k Rj可逆（再减回去）
行阶梯形（row echelon form, REF）满足：
① 全零行必须放在最下面；
② 每个非零行的第一个非零元，必须严格位于上一行第一个非零元的右侧。
（阶梯形不要求主元是 1，也不要求主元上方为 0；这些是 RREF 的额外要求。）

主元 pivot：用来消去其下方元素的那个首非零元。策略是：找主元 → 用它把下面清成 0 → 换到下一列 → 重复。

算法高斯消元四步 + 完整例题

  1. 写出增广矩阵 [A | b]；
  2. 用初等行变换化成行阶梯形；
  3. 把阶梯形翻译回方程组；
  4. 回代求解。

例：解 2y + 3z = 8，2x + 3y + z = 5，x − y − 2z = −5。（逐步竖写，箭头右边是这一步执行的行变换。）

  [ 0   2   3 |   8 ]                            第 1 列全是 0 开头，先换个"好主元"
  [ 2   3   1 |   5 ]        R₁ ↔ R₃
  [ 1  −1  −2 |  −5 ]

  [ 1  −1  −2 |  −5 ]        R₂ ← R₂ − 2R₁     用主元 1 把下面清 0
  [ 0   5   5 |  15 ]        R₃ 已经是 0，不用动
  [ 0   2   3 |   8 ]

  [ 1  −1  −2 |  −5 ]        R₂ ← (1/5)·R₂     主元化成 1，方便计算
  [ 0   1   1 |   3 ]
  [ 0   2   3 |   8 ]

  [ 1  −1  −2 |  −5 ]        R₃ ← R₃ − 2R₂     第二列也清 0 → 行阶梯形
  [ 0   1   1 |   3 ]
  [ 0   0   1 |   2 ]

回代：z = 2 → y + 2 = 3 ⇒ y = 1 → x − 1 − 4 = −5 ⇒ x = 0。所以解是 (x, y, z) = (0, 1, 2)。

小结本讲必须会做的事

  • 判断一个方程是不是线性的；
  • 说出“解一个方程组”是什么意思，以及三种解的个数情形；
  • 写出增广矩阵，做初等行变换，化成 REF，再回代；
  • 理解“等价变换不改变解集”是整章的方法论地基。

3L2 · 张成集与线性无关

核心视角把 Ax = b 看成“列的组合”

把 A 按列拆开：A = [a₁ a₂ ⋯ an]，则

Ax = x₁a₁ + x₂a₂ + ⋯ + xnan = b

于是“解方程组”= 问：取什么系数，能让 A 的各列组合出 b？

定理（相容性的列形式）：以 [A | b] 为增广矩阵的方程组相容 ⇔ b 是 A 的列向量的线性组合 ⇔ b ∈ span{a₁,…,an}。

几何含义：唯一解 ⇒ b 落在 span 中且表示方式唯一；无穷多解 ⇒ b 在 span 中但表示方式不唯一；无解 ⇒ b 根本不在 span 中。

定义线性组合与张成

线性组合：给定 v₁,…,vk，形如 c₁v₁ + c₂v₂ + ⋯ + ckvk 的表达式（ci ∈ ℝ）。

张成 span(S) = 所有线性组合构成的集合：

span{v₁,…,vk} = { c₁v₁ + ⋯ + ckvk : c₁,…,ck ∈ ℝ }

若 span(S) = ℝⁿ，则称 S 是 ℝⁿ 的张成集（spanning set）：这些向量足够多，可以“搭出”空间中每个向量。

四种组合（同一个式子，不同的系数限制）：

类型形式系数限制得到
线性组合 linearΣ θixiθi ∈ ℝ子空间 span{xi}
锥组合 conicΣ θixiθi ≥ 0凸锥
仿射组合 affineΣ θixiΣθi = 1仿射空间
凸组合 convexΣ θixiθi ≥ 0 且 Σθi = 1凸集

几何span 长什么样

  • 一个非零向量 → 过原点的直线；零向量 → 只有 {0}。
  • 两个不平行的向量（ℝ² 中）→ 整个平面（ℝ²）；平行则退化为一条直线。
  • ℝ³ 中 u = (1,0,3), v = (−1,1,−3) 不平行 ⟹ span{u,v} 是过原点的平面；由 x = s−t, y = t, z = 3s−3t 消去 s,t 得 z = 3x。
  • 标准单位向量 e₁,…,en（第 i 个位置为 1，其余为 0）满足 x = x₁e₁ + ⋯ + xnen，故 span{e₁,…,en} = ℝⁿ。

定义线性相关 / 线性无关

线性相关（dependent）：存在不全为零的 c₁,…,ck 使 c₁v₁ + ⋯ + ckvk = 0。
线性无关（independent）：c₁v₁ + ⋯ + ckvk = 0 只有平凡解 c₁ = ⋯ = ck = 0。

两种说法等价：相关 ⇔ 至少有一个向量可以写成其余向量的线性组合（“有多余信息”）。

证明思路：若 v₁ = c₂v₂ + ⋯ + cmvm，则 v₁ − c₂v₂ − ⋯ − cmvm = 0 是非平凡组合；反之若有 c₁ ≠ 0，两边除以 c₁ 解出 v₁。

两个向量的速判：相关 ⇔ 一个是另一个的标量倍（如 v = −2u ⟹ 2u + v = 0）。

判定矩阵视角：Ac = 0

把 v₁,…,vm 放进矩阵的列：A = [v₁ v₂ ⋯ vm]，则

c₁v₁ + ⋯ + cmvm = 0　⟺　Ac = 0（齐次方程组）
判定定理：v₁,…,vm 线性无关 ⇔ Ac = 0 只有零解 ⇔ A 化成阶梯形后每一列都是主元列（没有自由变量）。

操作四步：① 把向量按列排成 A；② 解齐次方程组 Ac = 0；③ 对 A 做行化简；④ 看有没有自由变量——无自由变量 ⇒ 无关；有自由变量 ⇒ 相关。

例：v₁ = (1,1,0), v₂ = (0,1,1), v₃ = (1,0,1)。解 c₁ + c₃ = 0, c₁ + c₂ = 0, c₂ + c₃ = 0，行化简后得 c₃ = c₂ = c₁ = 0 ⇒ 线性无关。

数量上限：ℝⁿ 中超过 n 个向量一定线性相关（如 ℝ² 中不可能有 3 个无关向量，因为 (1,1) = (1,0) + (0,1)）。

联系span 与无关：一对互补的问题

  • span 问：这些向量够不够生成整个空间？（“能不能覆盖”）
  • 线性无关 问：这些向量里有没有多余的？（“能不能精简”）
  • 既 span ℝ³ 又线性无关的例子：{e₁, e₂, e₃} —— 这正是标准基特别重要的原因，也直接引出下一讲的“基”。

4L3 · 行空间、基、维数、秩

起点同一组向量的两种堆法

给定 v₁,…,vk ∈ ℝⁿ，可以堆成行，也可以堆成列：

行堆叠：A 的每一行就是一个向量（A 是 k×n）　　列堆叠：B = [v₁ v₂ ⋯ vk]（B 是 n×k）
  • 行图 → 引出 行空间 与 秩；
  • 列图 → 引出求基的第二种方法（列方法）；
  • 两者“暗中是一回事”：给出的基大小相同（都等于秩）。

定义行空间与“行变换不改变行空间”

定义：row(A) = span{A 的各行}（是 ℝⁿ 的子空间，n = 列数）。
关键事实：若 B 与 A 行等价（row equivalent），则 row(B) = row(A)。

证明思路：行变换使 B 的每一行都是 A 的行的线性组合 ⇒ row(B) ⊆ row(A)；运算可逆，反过来也成立 ⇒ row(A) ⊆ row(B)。

直觉：化简过程中“消掉的”信息其实都是原来各行的组合，所以张成的集合没变；化到阶梯形后，非零行就是“去掉冗余后剩下的东西”。

例：A = [1 2 3; 2 4 6] → [1 2 3; 0 0 0]，所以 row(A) = span{(1,2,3)}，是 ℝ³ 中过原点的一条直线（维数 1）。

定义基（basis）· 维数（dimension）· 秩（rank）

基：集合 {b₁,…,bk} 若①张成 S 且②线性无关，就称为 S 的一组基。
记忆：基 = 极小张成集 = 极大线性无关组。

维数 dim(S)：任意一组基中向量的个数（下面用“基定理”保证这个数不依赖于选哪组基）。

秩 rank(A) = dim row(A)（L4 还会证明它同时等于 dim col(A)）。

怎么算：把 A 化成阶梯形，数非零行的个数。

例：rank[1 2; 2 4] = 1，rank[1 2; 3 4] = 2，rank[0 0; 0 0] = 0，dim{0} = 0（约定），dim ℝⁿ = n

定理基定理：任意两组基大小相同

Basis Theorem：同一空间 S 的任意两组基所含向量个数相同。因此“维数”是良定义的。

证明思路（考试常考“说出思路”）：设 B = {u₁,…,ur}，C = {v₁,…,vs} 都是基，反设 r < s。因为 B 张成 S，可把每个 vi 写成 vi = Σj aijuj。

若有 c₁v₁ + ⋯ + csvs = 0，代入并整理得关于 c 的齐次方程组：Σi ciaij = 0（j = 1,…,r）。这是 r 个方程、s 个未知数且 r < s，必有非零解；于是 C 线性相关，矛盾。故 r ≥ s；对称地 s ≥ r，所以 r = s。

直觉版本：在 ℝⁿ 里，任意 n+1 个向量必相关，所以基不可能“更小”或“更大”。

定理坐标的唯一性

定理：若 {v₁,…,vk} 是 S 的一组基，则每个 v ∈ S 都唯一地写成 v = c₁v₁ + ⋯ + ckvk。

证明：设两种写法，相减得 (c₁−d₁)v₁ + ⋯ + (ck−dk)vk = 0；由线性无关，所有系数为 0，故 ci = di。

这些系数称为 v 关于基 B 的坐标，记作坐标向量 [v]B = (c₁,…,ck)。

小结论：关于标准基 E = {e₁,e₂,e₃} 的坐标向量就是向量本身：[v]E = v。

方法行方法与列方法（同一空间，两组不同的基）

行方法列方法
怎么堆向量作为 A 的行向量作为 A 的列
求什么row(A) 的基span{v₁,…,vk}（= col(A)）的基
基是谁化简后矩阵的非零行主元列所对应的原矩阵的列
为什么行变换不改变行空间行变换不改变列之间的相关关系

列方法例题：u = (1,2,3), v = (2,1,0), w = (0,3,6)，把它们按列堆成矩阵再化简：

  [ 1   2   0 ]                 [ 1   2   0 ]                 [ 1   0   2 ]
  [ 2   1   3 ]   R₂−2R₁, R₃−3R₁ [ 0  −3   3 ]   R₂÷(−3), R₃+2R₂ [ 0   1  −1 ]
  [ 3   0   6 ]                 [ 0  −6   6 ]                 [ 0   0   0 ]

所以 {(1,2,3), (2,1,0)} 是 span(u,v,w) 的一组基；第三列是多余的（w = 2u − v）。行方法得到的是 {(1,2,3), (0,1,2)}——不同的基，但都是 2 个，这就是基定理。

最容易踩的坑：列方法中，基向量必须回到原矩阵 A 去取那几列，不能用化简后的列（行变换会改变列空间）。

5L4 · 子空间与矩阵运算

定义子空间（subspace）

S ⊆ ℝⁿ 是子空间，当且仅当：
① 0 ∈ S；② 对加法封闭：u, v ∈ S ⇒ u + v ∈ S；③ 对数乘封闭：u ∈ S, c ∈ ℝ ⇒ cu ∈ S。

等价条件：S 对一切线性组合封闭（c₁u₁ + ⋯ + ckuk ∈ S）。

定理：span(v₁,…,vk) 一定是子空间。（验证：0 = 0v₁+⋯+0vk；两组组合相加仍是组合；乘常数仍是组合。）

是子空间的例子：ℝ³ 中过原点的直线与平面；S = {(x,y,z) : x = 3y, z = −2y} = span{(3,1,−2)}。

不是子空间的例子：S = {(x, x²)}（抛物线）。含 0 满足，但对加法不封闭：(1,1) + (2,4) = (3,5)，而 5 ≠ 3²。举一个反例就足以否定。

定义矩阵的三个子空间

设 A 是 m×n 矩阵（m 行 n 列）：

子空间定义所在空间维数
行空间 row(A)A 的各行的张成ℝⁿrank(A)
列空间 col(A)A 的各列的张成 = {Ax : x ∈ ℝⁿ}ℝᵐrank(A)
零空间 null(A){x ∈ ℝⁿ : Ax = 0}（齐次方程组的解集）ℝⁿnullity(A)

重要等价：b ∈ col(A) ⇔ 方程组 Ax = b 相容。（因为 Ax 恰好是 A 的列的组合。）

零空间为什么是子空间：A0 = 0；A(u+v) = Au + Av = 0；A(cu) = cAu = 0。

方法求三组基的标准流程

  1. 把 A 化成 RREF（简化行阶梯形）；
  2. rank(A) = 非零行的个数 = 主元个数；
  3. row(A) 的基 = RREF 的非零行；
  4. col(A) 的基 = 主元列所对应的、原矩阵 A 的列；
  5. null(A) 的基：把主元变量用自由变量表示，每个自由变量取一次参数，得到一组基向量；nullity = 自由变量的个数。

贯穿全章的例题：A 是 4×5 矩阵，它的 RREF 为（竖线只是分隔，主元在第 1、2、4 列）：

  R = [ 1   0   1   0  −1 ]
      [ 0   1   2   0   3 ]
      [ 0   0   0   1   4 ]
      [ 0   0   0   0   0 ]
  • rank(A) = 3；dim row(A) = dim col(A) = 3。
  • row(A) 的基：{(1,0,1,0,−1), (0,1,2,0,3), (0,0,0,1,4)}。
  • col(A) 的基：A 的第 1、2、4 列。
  • 零空间：x₁ = −s + t，x₂ = −2s − 3t，x₃ = s，x₄ = −4t，x₅ = t，所以基为 {(−1,−2,1,0,0), (1,−3,0,−4,1)}，nullity = 2。
  • 验证秩定理：3 + 2 = 5 = 列数 ✓

定理行空间与列空间维数相等；秩定理

定理：对任意 m×n 矩阵 A，dim row(A) = dim col(A) = rank(A)；且 rank(AT) = rank(A)。
证明思路：设 RREF 为 R，有 r 个主元 1。row(A) = row(R) ⇒ dim row(A) = r；R 的 r 个主元列是 ℝᵐ 中的 e₁,…,er，其余列都是它们的组合，且 A 与 R 的列具有相同的相关关系 ⇒ dim col(A) = dim col(R) = r。
秩定理（Rank Theorem）：若 A 是 m×n 矩阵，则
rank(A) + nullity(A) = n（列数）

证明：RREF 中 r 个主元变量、n − r 个自由变量；nullity 等于自由变量的个数，故 nullity = n − r = n − rank(A)。

用法：只需要 nullity 时不必真的解 Ax = 0。例：4×4 矩阵 N 已有 2 个非零行 ⇒ rank = 2 ⇒ nullity = 4 − 2 = 2。

运算矩阵加法与数乘

  • 相等：维数相同 + 对应元素相同（维数不同一律不相等）。
  • 加法：(A+B)ij = aij + bij，要求同维数；否则无定义。
  • 数乘：(kA)ij = k·aij。
  • 减法：A − B = A + (−B)；零矩阵 O：A + O = A，A − A = O。

性质（与实数一致）：交换律、结合律、分配律 k(A+B) = kA + kB、(k+ℓ)A = kA + ℓA、k(ℓA) = (kℓ)A、1A = A。

特殊矩阵：方阵（行数=列数）、对角矩阵（非对角元全 0）、单位矩阵 In（主对角线全 1）。

运算矩阵乘法

维数规则：(m×n)·(n×r) = m×r，即“左边列数 = 右边行数”才能相乘；结果行数跟左边、列数跟右边。
cij = Σk=1..n aikbkj = A 的第 i 行 · B 的第 j 列（点积）

例：A = [1 3 2; 0 −1 1]（2×3），B = [4 −1; 1 2; 3 0]（3×2），则 AB 为 2×2，其中 c₁₁ = 1·4 + 3·1 + 2·3 = 13，等等。

三种等价视角（考试爱考“解释含义”）

  • 列组合：AB = [Ab₁ ⋯ Abr]，AB 的每一列都是 A 的列的组合。
  • 行组合：AB 的每一行都是 B 的行的组合。
  • 外积之和：A = [a₁ ⋯ an]，B 按行拆，则 AB = a₁B₁ + ⋯ + anBn（每个 akBk 是 m×r 的外积）。

单位向量的作用：Aej = A 的第 j 列；eiTA = A 的第 i 行。

性质：结合律 A(BC) = (AB)C；左右分配律；k(AB) = (kA)B = A(kB)；ImA = A = AIn。

差异矩阵与实数的三点不同

  1. 不可交换：一般 AB ≠ BA（反例：A = [2 4; −1 −2]，B = [1 0; 1 1]）。
  2. 没有消去律：AB = AC 推不出 B = C。
  3. A² = O 不代表 A = O：A = [2 4; −1 −2] 满足 A² = O。

因此平方展开要小心：

(A+B)² = A² + AB + BA + B²　（只有当 AB = BA 时才化简为 A² + 2AB + B²）

幂：A⁰ = I，ArAs = Ar+s，(Ar)s = Ars。
周期性例子：B = [0 −1; 1 0] 满足 B² = −I，B³ = −B，B⁴ = I，所以幂以 4 为周期。

运算转置与对称矩阵

(AT)ij = aji（m×n → n×m，行列互换）

性质：(AT)T = A；(A+B)T = AT + BT；(kA)T = kAT；

乘积转置法则（顺序反转）：(AB)T = BTAT；推广 (A₁A₂⋯Ak)T = AkT⋯A₁T；(Ar)T = (AT)r。

对称矩阵：AT = A（等价于 aij = aji，关于主对角线镜像对称；对角元任意）。

构造对称矩阵：(a) A 为方阵时 A + AT 对称；(b) 对任意矩阵 A，AAT 与 ATA 都对称（即使 A 不是方阵）。

点积：u·v = u₁v₁ + ⋯ + unvn = uTv（行向量乘列向量，得到 1×1）。

问题等价条件怎么算 / 怎么判
Ax = b 相容？b ∈ col(A)（b 是 A 的列的组合）化 [A|b]；出现 [0 ⋯ 0 | c≠0] 行 ⇒ 不相容
解唯一？相容 且 无自由变量（每列都是主元列）rank(A) = n（未知数个数）
有无穷多解？相容 且 有自由变量rank(A) < n，且相容
v₁,…,vm 无关？Ac = 0 只有零解列堆叠后无自由变量；m ≤ n
是否张成 ℝⁿ？col(A) = ℝⁿrank(A) = n（对方阵即满秩）
是不是子空间？含 0 + 对加法、数乘封闭过原点的直线/平面、span、row/col/null 都是
row(A) 的基RREF 的非零行个数 = rank(A)，位于 ℝⁿ
col(A) 的基主元列对应的原矩阵的列个数 = rank(A)，位于 ℝᵐ
null(A) 的基自由变量取参数得到的解向量个数 = nullity = n − rank(A)

五个“数字”之间的关系（必背）

设 A 为 m×n，r = rank(A)，则
• row(A) ⊆ ℝⁿ，dim = r　　• col(A) ⊆ ℝᵐ，dim = r
• null(A) ⊆ ℝⁿ，dim = n − r　　• r + (n − r) = n
• r ≤ min(m, n)；r = n ⇒ 列无关；r = m ⇒ col(A) = ℝᵐ（行满秩 ⇒ 必相容）

7十个最容易丢分的点

1. 行变换只保行空间，不保列空间。所以求 col(A) 的基时，主元列确定“编号”，但向量必须回到原矩阵 A 里取。
2. 秩定理里是 n（列数），不是行数。rank + nullity = 列数。
3. 堆法不能混。求 row(A) 用行堆叠（按行化简看非零行）；求 span{vᵢ}（= col）用列堆叠 + 主元列。
4. AB ≠ BA。写 (A+B)² 时不要漏掉 AB 与 BA 两个不同的项。
5. 没有消去律。AB = AC 或 A² = O 都不能推出“约掉 A”。
6. 相容性先判，再谈解的数量。[0 ⋯ 0 | c]（c ≠ 0）出现 ⇒ 无解；此时即便有自由变量也不是“无穷多解”。
7. 主元可以是任意非零数。REF 不要求主元为 1；RREF 才要求主元为 1 且其所在列其余元素为 0。
8. ℝⁿ 中 m > n 个向量一定相关。所以“3 个向量在 ℝ² 中无关”这种选项永远错。
9. Ax = b 的解集一般不是子空间（除非 b = 0）。只有齐次方程组 Ax = 0 的解集（= null(A)）才是子空间。
10. 乘积转置要反序：(AB)T = BTAT，不是 ATBT。

8自测题（先遮住答案）

建议：先独立做，再展开核对；做错的题在旁边标上对应讲次，最后回到第 2–5 节重看。

A. L1：方程组与消元

1. 下列哪些是线性方程？(a) 3x − 4y = 7　(b) xy + z = 1　(c) x² + y = 3　(d) 2x + 3y = 7　(e) sin x + y = 0
答案
只有 (a)、(d)。(b) 变量相乘，(c) 二次，(e) 非线性函数。
2. 解方程组 2x − y = 3，x + 3y = 5。
答案
由第二式 x = 5 − 3y，代入第一式：2(5−3y) − y = 3 ⇒ 10 − 7y = 3 ⇒ y = 1，x = 2。验证：4−1=3 ✓，2+3=5 ✓。解 (x,y) = (2,1)，是两直线交点，唯一解。
3. 增广矩阵化为 [1 2 3 | 4; 0 0 1 | 2; 0 0 0 | 0]。问：相容吗？有唯一解吗？
答案
相容（没有 [0 0 0 | c≠0] 行）。主元在第 1、3 列，第 2 列是自由变量列 ⇒ 有无穷多解。
4. 判断相容性：x + 2y = 3，2x + 4y = 7。
答案
第二行减 2 倍第一行得 [0 0 | 1]，即 0 = 1 ⇒ 不相容（无解）。几何上两条平行直线。

B. L2：张成与线性无关

5. (5, −2, 3) 是否是 (1,0,3) 与 (1,−1,−3) 的线性组合？
答案
要解 x(1,0,3) + y(1,−1,−3) = (5,−2,3)：x + y = 5，−y = −2，3x − 3y = 3 ⇒ y = 2，x = 3，第三式 9 − 6 = 3 ✓。是，且 (5,−2,3) = 3(1,0,3) + 2(1,−1,−3)。
6. (2, 3, 4) 是否是 (1,0,3) 与 (1,−1,−3) 的线性组合？
答案
x + y = 2，−y = 3，3x − 3y = 4 ⇒ y = −3，x = 5，但 3·5 − 3·(−3) = 24 ≠ 4。不是（方程组不相容）。
7. 判断 u = (1,2), v = (−2,−4) 是否线性无关。
答案
v = −2u ⇒ 2u + v = 0 是非平凡组合 ⇒ 线性相关。两个向量相关 ⇔ 互为标量倍。
8. 判断 (1,1,0), (0,1,1), (1,0,1) 是否线性无关。
答案
设 c₁(1,1,0) + c₂(0,1,1) + c₃(1,0,1) = 0，得 c₁ + c₃ = 0，c₁ + c₂ = 0，c₂ + c₃ = 0。解得 c₁ = c₂ = c₃ = 0 ⇒ 线性无关（也可看行列式 = 2 ≠ 0）。
9. ℝ³ 中能否有 4 个线性无关的向量？为什么？
答案
不能。ℝⁿ 中任意 > n 个向量必线性相关：把 4 个向量按列堆成 3×4 矩阵，齐次方程组有 4 个未知数、rank ≤ 3，必有自由变量 ⇒ 存在非零解。

C. L3：基、维数、秩

10. 求 A = [1 2; 3 4] 的 rank，并给出 row(A) 的一组基。
答案
化成 [1 2; 0 −2]（R2 − 3R1），两个非零行 ⇒ rank(A) = 2。row(A) 的基可取 {(1,2), (3,4)}，或阶梯形的 {(1,2), (0,−2)}。
11. 求 A = 4×5 矩阵（RREF 主元在第 1、2、4 列）的 rank、dim row、dim col、nullity。
答案
rank = 3，dim row(A) = 3，dim col(A) = 3，自由变量 = 2（第 3、5 列）⇒ nullity = 2。检验 3 + 2 = 5 ✓。
12. 求 null(A) 的一组基，其中 A = [1 2 3; 2 4 6]。
答案
RREF = [1 2 3; 0 0 0]，rank = 1，nullity = 3 − 1 = 2。x₁ = −2s − 3t，x₂ = s，x₃ = t ⇒ 基 {(−2,1,0), (−3,0,1)}。
13. 若 A 是 3×3 且 Ax = 0 只有零解，求 rank(A) 与 nullity(A)。
答案
nullity = 0（只有零解，零空间只有 {0}）⇒ rank = 3 − 0 = 3，即 A 满秩、三列都线性无关。
14. span{(1,0,3), (−1,1,−3)} 是 ℝ³ 中的什么？写出它的方程。
答案
两向量不平行 ⇒ 过原点的平面。由 (x,y,z) = s(1,0,3) + t(−1,1,−3) 得 y = t，x = s − t，z = 3s − 3t = 3(s−t) = 3x，即平面 z = 3x（或 3x − z = 0）。

D. L4：子空间与矩阵运算

15. S = {(x,y) : y = x²} 是 ℝ² 的子空间吗？
答案
不是。虽然 (0,0) ∈ S，但 (1,1) + (2,4) = (3,5)，而 5 ≠ 3²，对加法不封闭。
16. S = {(x,y,z) : x + y + z = 0} 是子空间吗？维数是多少？
答案
是。它是齐次方程的解集（一个过原点的平面）：0 满足；两个解之和、解的倍数仍满足。维数 2，基如 {(1,−1,0), (1,0,−1)}。
17. 计算 AB 与 BA，其中 A = [1 2; 3 4]，B = [0 1; 1 0]。
答案
AB = [1·0+2·1, 1·1+2·0; 3·0+4·1, 3·1+4·0] = [2 1; 4 3]；BA = [0·1+1·3, 0·2+1·4; 1·1+0·3, 1·2+0·4] = [3 4; 1 2]。AB ≠ BA。
18. A 是 2×3，B 是 4×3。AB、BA 分别能否定义？
答案
AB 需 3 = 4，不行；BA 需 3 = 2，也不行。两者都无定义。
19. 举一个 A ≠ O 但 A² = O 的 2×2 矩阵，并说明它推翻了哪条“常识”。
答案
A = [2 4; −1 −2]，则 A² = [4−4, 8−8; −2+2, −4+4] = O。它说明矩阵里 A² = O 推不出 A = O（也不能“约去” A）。
20. 设 A 为 3×4，证明 AAT 是对称矩阵，并说出它的维数。
答案
(AAT)T = (AT)TAT = AAT，故对称。A 是 3×4 ⇒ AT 是 4×3 ⇒ AAT 是 3×3。
21. 若 rank(A) = rank([A|b]) = 2，A 是 3×4 的矩阵，问方程组 Ax = b 解的情况。
答案
相容（rank 未因加入 b 而增大）。n = 4，自由变量 = 4 − 2 = 2 > 0 ⇒ 无穷多解。
22. 设 v₁, v₂, v₃ 线性无关，判断 w₁ = v₁ + v₂, w₂ = v₂ + v₃, w₃ = v₁ + v₃ 是否线性无关。
答案
无关。设 c₁w₁ + c₂w₂ + c₃w₃ = 0，整理得 (c₁+c₃)v₁ + (c₁+c₂)v₂ + (c₂+c₃)v₃ = 0。由 v 无关得 c₁+c₃ = c₁+c₂ = c₂+c₃ = 0，解得 c₁ = c₂ = c₃ = 0。

A附录 · 补充：怎么求逆矩阵 A−1

这一节不在这四讲讲义里（L1–L4 没讲逆矩阵），但它是“高斯消元 → 行变换”最直接的应用，考试或后续课程几乎必用，所以补充在这里。

第 0 步先把概念说清

定义：设 A 是方阵（n×n）。若存在同阶方阵 B 使得
AB = BA = In，
则称 A 可逆（invertible / nonsingular），B 就是 A 的逆矩阵，记作 A−1。
  • 只有方阵才谈“逆”（m×n 且 m ≠ n 时不存在 A−1）。
  • 逆是唯一的：若 B、C 都是逆，则 B = BI = B(AC) = (BA)C = IC = C。
  • “可逆”和文件里行变换的“可逆”是两回事：后者说“运算能退回去”，前者说“矩阵存在逆”。两者有联系（都是可逆的），但定义不同。

方法一通用方法：对 [A | I] 做行变换（Gauss–Jordan）

核心操作：把单位矩阵 I 拼在 A 右边，得到 n×2n 的增广矩阵 [A | I]，然后只用行变换把左边化成 I：
[ A | I ]　──行变换──→　[ I | A−1 ]
右边自动变成 A−1。

具体步骤（和化 RREF 完全一样，只是要一路化到左边是 I）：

  1. 写出 [A | I]（左边 A，右边同阶单位阵）；
  2. 第 1 列：把 (1,1) 位置做成主元 1（必要时换行），用它把同列其它位置全清成 0；
  3. 对第 2、3、… 列重复：先把下一个主元做成 1，再把这一列上下都清 0；
  4. 左边成为 I 后，右边就是 A−1；
  5. 验算：随便乘一列，检查 AA−1 = I。
为什么这样能行？每一次行变换相当于在左边乘一个初等矩阵 E。若用 Ek⋯E2E1 把 A 变成 I，即 (Ek⋯E1)A = I，那么括号里的矩阵按定义就是 A−1；而它作用在右边的 I 上，正好得到 A−1。所以“左边 A→I 的过程”会同步把“右边 I→A−1”。

等价理解：求 A−1 的第 j 列，就是解方程组 Ax = ej。把所有 j 一次解完、共用同一套行变换，就是 [A | I] → [I | A−1]。

例题求 A = [[1,2,3],[0,1,4],[5,6,0]] 的逆

  [ A | I ]                     操作

  [ 1   2   3 |  1   0   0 ]
  [ 0   1   4 |  0   1   0 ]
  [ 5   6   0 |  0   0   1 ]

  [ 1   2   3 |  1   0   0 ]   R3 ← R3 − 5R1        第 1 列下方清 0
  [ 0   1   4 |  0   1   0 ]
  [ 0  −4 −15 | −5   0   1 ]

  [ 1   0  −5 |  1  −2   0 ]   R1 ← R1 − 2R2        第 2 列上方清 0
  [ 0   1   4 |  0   1   0 ]
  [ 0  −4 −15 | −5   0   1 ]

  [ 1   0  −5 |  1  −2   0 ]   R3 ← R3 + 4R2        第 2 列下方清 0
  [ 0   1   4 |  0   1   0 ]
  [ 0   0   1 | −5   4   1 ]   ← 已出现主元 1

  [ 1   0   0 | −24  18  5 ]   R1 ← R1 + 5R3        第 3 列上方清 0
  [ 0   1   4 |   0   1  0 ]
  [ 0   0   1 |  −5   4  1 ]

  [ 1   0   0 | −24  18   5 ]  R2 ← R2 − 4R3        左边 = I，完成
  [ 0   1   0 |  20 −15  −4 ]
  [ 0   0   1 |  −5   4   1 ]
A−1 = [[−24, 18, 5], [20, −15, −4], [−5, 4, 1]]

验算：用 A 的每一行去乘 A−1 的各列，应当得到 I。

  • 第 1 行 × 第 1 列：1(−24) + 2(20) + 3(−5) = −24 + 40 − 15 = 1 ✓
  • 第 1 行 × 第 2 列：1(18) + 2(−15) + 3(4) = 18 − 30 + 12 = 0 ✓
  • 第 1 行 × 第 3 列：1(5) + 2(−4) + 3(1) = 5 − 8 + 3 = 0 ✓
  • 第 2 行 × 第 2 列：0(18) + 1(−15) + 4(4) = −15 + 16 = 1 ✓
  • 第 3 行 × 第 1 列：5(−24) + 6(20) + 0(−5) = −120 + 120 = 0 ✓
  • 第 3 行 × 第 3 列：5(5) + 6(−4) + 0(1) = 25 − 24 = 1 ✓

其余位置同样为 0（对角线为 1），所以结果正确。

方法二2×2 的公式法（最快）

若 ad − bc ≠ 0，则
[[a, b], [c, d]]−1 = 1/(ad − bc) · [[d, −b], [−c, a]]
口诀：主对角互换、副对角变号、整体除以 (ad − bc)。

例：[[4,7],[2,6]]，ad − bc = 24 − 14 = 10，所以逆 = (1/10)[[6,−7],[−2,4]] = [[0.6,−0.7],[−0.2,0.4]]。

例：[[2,1],[5,3]]，ad − bc = 6 − 5 = 1，所以逆 = [[3,−1],[−5,2]]。

3×3 及以上没有这种“一眼写出”的公式；学了行列式以后可以用 A−1 = adj(A)/det(A)，但计算量通常比行变换大，考试还是推荐 [A | I]。

什么时候没有逆行变换卡住的时候

如果化 [A | I] 的过程中，左边出现了整行全 0（主元做不满 n 个），那就说明 A 不可逆——此时左边永远变不成 I，右边也不会是答案。

  A = [ 1   2 ]      [ A | I ] = [ 1  2 | 1  0 ]   R2←R2−2R1   [ 1  2 |  1  0 ]
      [ 2   4 ]                  [ 2  4 | 0  1 ]   ────────→   [ 0  0 | −2  1 ]

左边第 2 行全 0，右边却是 (−2, 1) ≠ 0，无解 ⇒ A 不可逆（singular）。这也解释了“为什么第 2 行本来就是第 1 行的 2 倍”。

一串等价条件（把四讲内容串起来，务必记住）：对 n×n 矩阵 A，下列命题全部等价：

  • A 可逆（A−1 存在）；
  • rank(A) = n（满秩，n 个主元）；
  • A 的 n 个列线性无关（L2）；
  • null(A) = {0}，即 nullity(A) = 0（L4）；
  • Ax = 0 只有零解；
  • 对任意 b，Ax = b 有唯一解 x = A−1b。

（等学了行列式，还可以加上 det(A) ≠ 0。）

用处用逆矩阵解方程组

若 A 可逆，Ax = b 的解直接是 x = A−1b。例：解 2x + y = 3，5x + 3y = 1。上面已求得 [[2,1],[5,3]]−1 = [[3,−1],[−5,2]]，于是

x = [[3,−1],[−5,2]]·[3;1] = [9−1; −15+2] = [8; −13]

验证：2·8 + (−13) = 3 ✓；5·8 + 3(−13) = 40 − 39 = 1 ✓。

但当 b 只有一组时不要真的求逆：直接对 [A | b] 做高斯消元更快；求逆适合“同一个 A、很多个不同的 b”的情形（求一次 A−1，之后每次只做一次矩阵乘法）。

易错求逆时的 5 个坑

  1. 不能做列变换。[A | I] 里只能用行变换；用列变换会破坏左右两半的对应关系。
  2. 不能只化到阶梯形就停。必须是左边 = I（主元为 1，且主元所在列其余全 0），所以要做到底（RREF 级别）。
  3. (A + B)−1 ≠ A−1 + B−1。加法没有这种公式。
  4. 乘积要反序：(AB)−1 = B−1A−1（和转置一样“反序”）；另外 (AT)−1 = (A−1)T、(kA)−1 = (1/k)A−1（k ≠ 0）。
  5. 非方阵没有逆；方阵也可能没有逆（见上一节），先判断再动手。

练习4 题（先做，再展开）

1. 求 [[3, 1],[2, 1]] 的逆。
答案
ad − bc = 3·1 − 1·2 = 1 ⇒ 逆 = [[1, −1], [−2, 3]]。验算：3·1 + 1·(−2) = 1，3·(−1) + 1·3 = 0 ✓
2. 用 [A | I] 求 [[1, 2],[3, 4]] 的逆。
答案
[1 2 | 1 0; 3 4 | 0 1] → R2−3R1 → [1 2 | 1 0; 0 −2 | −3 1] → R2÷(−2) → [1 2 | 1 0; 0 1 | 3/2 −1/2] → R1−2R2 → [1 0 | −2 1; 0 1 | 3/2 −1/2]。所以逆 = [[−2, 1], [3/2, −1/2]]（与 1/(ad−bc) 公式一致：ad−bc = −2）。
3. 判断 [[1, 2, 3],[2, 4, 6],[1, 1, 1]] 是否可逆，并说明理由。
答案
不可逆。第 2 行 = 2×第 1 行，做 R2 − 2R1 会出现整行 0 ⇒ 主元不足 3 个 ⇒ rank ≤ 2 < 3，不满秩，所以没有逆（也可由 nullity ≥ 1 说明 Ax=0 有非零解）。
4. 已知 A、B 都可逆，化简 (A BT)−1。
答案
(ABT)−1 = (BT)−1A−1 = (B−1)TA−1。注意顺序要反过来。
