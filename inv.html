A附录 · 补充：怎么求逆矩阵 A−1

这一节不在这四讲讲义里（L1–L4 没讲逆矩阵），但它是“高斯消元 → 行变换”最直接的应用，考试或后续课程几乎必用，所以补充在这里。

第 0 步先把概念说清

定义：设 A 是方阵（n×n）。若存在同阶方阵 B 使得
AB = BA = In，
则称 A 可逆（invertible / nonsingular），B 就是 A 的逆矩阵，记作 A−1。
  • 只有方阵才谈“逆”（m×n 且 m ≠ n 时不存在 A−1）。
  • 逆是唯一的：若 B、C 都是逆，则 B = BI = B(AC) = (BA)C = IC = C。
  • “可逆”和文件里行变换的“可逆”是两回事：后者说“运算能退回去”，前者说“矩阵存在逆”。两者有联系（都是可逆的），但定义不同。

方法一通用方法：对 [A | I] 做行变换（Gauss–Jordan）

核心操作：把单位矩阵 I 拼在 A 右边，得到 n×2n 的增广矩阵 [A | I]，然后只用行变换把左边化成 I：
[ A | I ]　──行变换──→　[ I | A−1 ]
右边自动变成 A−1。

具体步骤（和化 RREF 完全一样，只是要一路化到左边是 I）：

  1. 写出 [A | I]（左边 A，右边同阶单位阵）；
  2. 第 1 列：把 (1,1) 位置做成主元 1（必要时换行），用它把同列其它位置全清成 0；
  3. 对第 2、3、… 列重复：先把下一个主元做成 1，再把这一列上下都清 0；
  4. 左边成为 I 后，右边就是 A−1；
  5. 验算：随便乘一列，检查 AA−1 = I。
为什么这样能行？每一次行变换相当于在左边乘一个初等矩阵 E。若用 Ek⋯E2E1 把 A 变成 I，即 (Ek⋯E1)A = I，那么括号里的矩阵按定义就是 A−1；而它作用在右边的 I 上，正好得到 A−1。所以“左边 A→I 的过程”会同步把“右边 I→A−1”。

等价理解：求 A−1 的第 j 列，就是解方程组 Ax = ej。把所有 j 一次解完、共用同一套行变换，就是 [A | I] → [I | A−1]。

例题求 A = [[1,2,3],[0,1,4],[5,6,0]] 的逆

  [ A | I ]                     操作

  [ 1   2   3 |  1   0   0 ]
  [ 0   1   4 |  0   1   0 ]
  [ 5   6   0 |  0   0   1 ]

  [ 1   2   3 |  1   0   0 ]   R3 ← R3 − 5R1        第 1 列下方清 0
  [ 0   1   4 |  0   1   0 ]
  [ 0  −4 −15 | −5   0   1 ]

  [ 1   0  −5 |  1  −2   0 ]   R1 ← R1 − 2R2        第 2 列上方清 0
  [ 0   1   4 |  0   1   0 ]
  [ 0  −4 −15 | −5   0   1 ]

  [ 1   0  −5 |  1  −2   0 ]   R3 ← R3 + 4R2        第 2 列下方清 0
  [ 0   1   4 |  0   1   0 ]
  [ 0   0   1 | −5   4   1 ]   ← 已出现主元 1

  [ 1   0   0 | −24  18  5 ]   R1 ← R1 + 5R3        第 3 列上方清 0
  [ 0   1   4 |   0   1  0 ]
  [ 0   0   1 |  −5   4  1 ]

  [ 1   0   0 | −24  18   5 ]  R2 ← R2 − 4R3        左边 = I，完成
  [ 0   1   0 |  20 −15  −4 ]
  [ 0   0   1 |  −5   4   1 ]
A−1 = [[−24, 18, 5], [20, −15, −4], [−5, 4, 1]]

验算：用 A 的每一行去乘 A−1 的各列，应当得到 I。

  • 第 1 行 × 第 1 列：1(−24) + 2(20) + 3(−5) = −24 + 40 − 15 = 1 ✓
  • 第 1 行 × 第 2 列：1(18) + 2(−15) + 3(4) = 18 − 30 + 12 = 0 ✓
  • 第 1 行 × 第 3 列：1(5) + 2(−4) + 3(1) = 5 − 8 + 3 = 0 ✓
  • 第 2 行 × 第 2 列：0(18) + 1(−15) + 4(4) = −15 + 16 = 1 ✓
  • 第 3 行 × 第 1 列：5(−24) + 6(20) + 0(−5) = −120 + 120 = 0 ✓
  • 第 3 行 × 第 3 列：5(5) + 6(−4) + 0(1) = 25 − 24 = 1 ✓

其余位置同样为 0（对角线为 1），所以结果正确。

方法二2×2 的公式法（最快）

若 ad − bc ≠ 0，则
[[a, b], [c, d]]−1 = 1/(ad − bc) · [[d, −b], [−c, a]]
口诀：主对角互换、副对角变号、整体除以 (ad − bc)。

例：[[4,7],[2,6]]，ad − bc = 24 − 14 = 10，所以逆 = (1/10)[[6,−7],[−2,4]] = [[0.6,−0.7],[−0.2,0.4]]。

例：[[2,1],[5,3]]，ad − bc = 6 − 5 = 1，所以逆 = [[3,−1],[−5,2]]。

3×3 及以上没有这种“一眼写出”的公式；学了行列式以后可以用 A−1 = adj(A)/det(A)，但计算量通常比行变换大，考试还是推荐 [A | I]。

什么时候没有逆行变换卡住的时候

如果化 [A | I] 的过程中，左边出现了整行全 0（主元做不满 n 个），那就说明 A 不可逆——此时左边永远变不成 I，右边也不会是答案。

  A = [ 1   2 ]      [ A | I ] = [ 1  2 | 1  0 ]   R2←R2−2R1   [ 1  2 |  1  0 ]
      [ 2   4 ]                  [ 2  4 | 0  1 ]   ────────→   [ 0  0 | −2  1 ]

左边第 2 行全 0，右边却是 (−2, 1) ≠ 0，无解 ⇒ A 不可逆（singular）。这也解释了“为什么第 2 行本来就是第 1 行的 2 倍”。

一串等价条件（把四讲内容串起来，务必记住）：对 n×n 矩阵 A，下列命题全部等价：

  • A 可逆（A−1 存在）；
  • rank(A) = n（满秩，n 个主元）；
  • A 的 n 个列线性无关（L2）；
  • null(A) = {0}，即 nullity(A) = 0（L4）；
  • Ax = 0 只有零解；
  • 对任意 b，Ax = b 有唯一解 x = A−1b。

（等学了行列式，还可以加上 det(A) ≠ 0。）

用处用逆矩阵解方程组

若 A 可逆，Ax = b 的解直接是 x = A−1b。例：解 2x + y = 3，5x + 3y = 1。上面已求得 [[2,1],[5,3]]−1 = [[3,−1],[−5,2]]，于是

x = [[3,−1],[−5,2]]·[3;1] = [9−1; −15+2] = [8; −13]

验证：2·8 + (−13) = 3 ✓；5·8 + 3(−13) = 40 − 39 = 1 ✓。

但当 b 只有一组时不要真的求逆：直接对 [A | b] 做高斯消元更快；求逆适合“同一个 A、很多个不同的 b”的情形（求一次 A−1，之后每次只做一次矩阵乘法）。

易错求逆时的 5 个坑

  1. 不能做列变换。[A | I] 里只能用行变换；用列变换会破坏左右两半的对应关系。
  2. 不能只化到阶梯形就停。必须是左边 = I（主元为 1，且主元所在列其余全 0），所以要做到底（RREF 级别）。
  3. (A + B)−1 ≠ A−1 + B−1。加法没有这种公式。
  4. 乘积要反序：(AB)−1 = B−1A−1（和转置一样“反序”）；另外 (AT)−1 = (A−1)T、(kA)−1 = (1/k)A−1（k ≠ 0）。
  5. 非方阵没有逆；方阵也可能没有逆（见上一节），先判断再动手。

练习4 题（先做，再展开）

1. 求 [[3, 1],[2, 1]] 的逆。
答案
ad − bc = 3·1 − 1·2 = 1 ⇒ 逆 = [[1, −1], [−2, 3]]。验算：3·1 + 1·(−2) = 1，3·(−1) + 1·3 = 0 ✓
2. 用 [A | I] 求 [[1, 2],[3, 4]] 的逆。
答案
[1 2 | 1 0; 3 4 | 0 1] → R2−3R1 → [1 2 | 1 0; 0 −2 | −3 1] → R2÷(−2) → [1 2 | 1 0; 0 1 | 3/2 −1/2] → R1−2R2 → [1 0 | −2 1; 0 1 | 3/2 −1/2]。所以逆 = [[−2, 1], [3/2, −1/2]]（与 1/(ad−bc) 公式一致：ad−bc = −2）。
3. 判断 [[1, 2, 3],[2, 4, 6],[1, 1, 1]] 是否可逆，并说明理由。
答案
不可逆。第 2 行 = 2×第 1 行，做 R2 − 2R1 会出现整行 0 ⇒ 主元不足 3 个 ⇒ rank ≤ 2 < 3，不满秩，所以没有逆（也可由 nullity ≥ 1 说明 Ax=0 有非零解）。
4. 已知 A、B 都可逆，化简 (A BT)−1。
答案
(ABT)−1 = (BT)−1A−1 = (B−1)TA−1。注意顺序要反过来。
