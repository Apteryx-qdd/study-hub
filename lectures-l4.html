5L4 · 子空间与矩阵运算

定义子空间（subspace）

S ⊆ ℝⁿ 是子空间，当且仅当：
① 0 ∈ S；② 对加法封闭：u, v ∈ S ⇒ u + v ∈ S；③ 对数乘封闭：u ∈ S, c ∈ ℝ ⇒ cu ∈ S。

等价条件：S 对一切线性组合封闭（c₁u₁ + ⋯ + ckuk ∈ S）。

定理：span(v₁,…,vk) 一定是子空间。（验证：0 = 0v₁+⋯+0vk；两组组合相加仍是组合；乘常数仍是组合。）

是子空间的例子：ℝ³ 中过原点的直线与平面；S = {(x,y,z) : x = 3y, z = −2y} = span{(3,1,−2)}。

不是子空间的例子：S = {(x, x²)}（抛物线）。含 0 满足，但对加法不封闭：(1,1) + (2,4) = (3,5)，而 5 ≠ 3²。举一个反例就足以否定。

定义矩阵的三个子空间

设 A 是 m×n 矩阵（m 行 n 列）：

子空间定义所在空间维数
行空间 row(A)A 的各行的张成ℝⁿrank(A)
列空间 col(A)A 的各列的张成 = {Ax : x ∈ ℝⁿ}ℝᵐrank(A)
零空间 null(A){x ∈ ℝⁿ : Ax = 0}（齐次方程组的解集）ℝⁿnullity(A)

重要等价：b ∈ col(A) ⇔ 方程组 Ax = b 相容。（因为 Ax 恰好是 A 的列的组合。）

零空间为什么是子空间：A0 = 0；A(u+v) = Au + Av = 0；A(cu) = cAu = 0。

方法求三组基的标准流程

  1. 把 A 化成 RREF（简化行阶梯形）；
  2. rank(A) = 非零行的个数 = 主元个数；
  3. row(A) 的基 = RREF 的非零行；
  4. col(A) 的基 = 主元列所对应的、原矩阵 A 的列；
  5. null(A) 的基：把主元变量用自由变量表示，每个自由变量取一次参数，得到一组基向量；nullity = 自由变量的个数。

贯穿全章的例题：A 是 4×5 矩阵，它的 RREF 为（竖线只是分隔，主元在第 1、2、4 列）：

  R = [ 1   0   1   0  −1 ]
      [ 0   1   2   0   3 ]
      [ 0   0   0   1   4 ]
      [ 0   0   0   0   0 ]
  • rank(A) = 3；dim row(A) = dim col(A) = 3。
  • row(A) 的基：{(1,0,1,0,−1), (0,1,2,0,3), (0,0,0,1,4)}。
  • col(A) 的基：A 的第 1、2、4 列。
  • 零空间：x₁ = −s + t，x₂ = −2s − 3t，x₃ = s，x₄ = −4t，x₅ = t，所以基为 {(−1,−2,1,0,0), (1,−3,0,−4,1)}，nullity = 2。
  • 验证秩定理：3 + 2 = 5 = 列数 ✓

定理行空间与列空间维数相等；秩定理

定理：对任意 m×n 矩阵 A，dim row(A) = dim col(A) = rank(A)；且 rank(AT) = rank(A)。
证明思路：设 RREF 为 R，有 r 个主元 1。row(A) = row(R) ⇒ dim row(A) = r；R 的 r 个主元列是 ℝᵐ 中的 e₁,…,er，其余列都是它们的组合，且 A 与 R 的列具有相同的相关关系 ⇒ dim col(A) = dim col(R) = r。
秩定理（Rank Theorem）：若 A 是 m×n 矩阵，则
rank(A) + nullity(A) = n（列数）

证明：RREF 中 r 个主元变量、n − r 个自由变量；nullity 等于自由变量的个数，故 nullity = n − r = n − rank(A)。

用法：只需要 nullity 时不必真的解 Ax = 0。例：4×4 矩阵 N 已有 2 个非零行 ⇒ rank = 2 ⇒ nullity = 4 − 2 = 2。

运算矩阵加法与数乘

  • 相等：维数相同 + 对应元素相同（维数不同一律不相等）。
  • 加法：(A+B)ij = aij + bij，要求同维数；否则无定义。
  • 数乘：(kA)ij = k·aij。
  • 减法：A − B = A + (−B)；零矩阵 O：A + O = A，A − A = O。

性质（与实数一致）：交换律、结合律、分配律 k(A+B) = kA + kB、(k+ℓ)A = kA + ℓA、k(ℓA) = (kℓ)A、1A = A。

特殊矩阵：方阵（行数=列数）、对角矩阵（非对角元全 0）、单位矩阵 In（主对角线全 1）。

运算矩阵乘法

维数规则：(m×n)·(n×r) = m×r，即“左边列数 = 右边行数”才能相乘；结果行数跟左边、列数跟右边。
cij = Σk=1..n aikbkj = A 的第 i 行 · B 的第 j 列（点积）

例：A = [1 3 2; 0 −1 1]（2×3），B = [4 −1; 1 2; 3 0]（3×2），则 AB 为 2×2，其中 c₁₁ = 1·4 + 3·1 + 2·3 = 13，等等。

三种等价视角（考试爱考“解释含义”）

  • 列组合：AB = [Ab₁ ⋯ Abr]，AB 的每一列都是 A 的列的组合。
  • 行组合：AB 的每一行都是 B 的行的组合。
  • 外积之和：A = [a₁ ⋯ an]，B 按行拆，则 AB = a₁B₁ + ⋯ + anBn（每个 akBk 是 m×r 的外积）。

单位向量的作用：Aej = A 的第 j 列；eiTA = A 的第 i 行。

性质：结合律 A(BC) = (AB)C；左右分配律；k(AB) = (kA)B = A(kB)；ImA = A = AIn。

差异矩阵与实数的三点不同

  1. 不可交换：一般 AB ≠ BA（反例：A = [2 4; −1 −2]，B = [1 0; 1 1]）。
  2. 没有消去律：AB = AC 推不出 B = C。
  3. A² = O 不代表 A = O：A = [2 4; −1 −2] 满足 A² = O。

因此平方展开要小心：

(A+B)² = A² + AB + BA + B²　（只有当 AB = BA 时才化简为 A² + 2AB + B²）

幂：A⁰ = I，ArAs = Ar+s，(Ar)s = Ars。
周期性例子：B = [0 −1; 1 0] 满足 B² = −I，B³ = −B，B⁴ = I，所以幂以 4 为周期。

运算转置与对称矩阵

(AT)ij = aji（m×n → n×m，行列互换）

性质：(AT)T = A；(A+B)T = AT + BT；(kA)T = kAT；

乘积转置法则（顺序反转）：(AB)T = BTAT；推广 (A₁A₂⋯Ak)T = AkT⋯A₁T；(Ar)T = (AT)r。

对称矩阵：AT = A（等价于 aij = aji，关于主对角线镜像对称；对角元任意）。

构造对称矩阵：(a) A 为方阵时 A + AT 对称；(b) 对任意矩阵 A，AAT 与 ATA 都对称（即使 A 不是方阵）。

点积：u·v = u₁v₁ + ⋯ + unvn = uTv（行向量乘列向量，得到 1×1）。
