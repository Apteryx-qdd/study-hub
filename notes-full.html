1第 1 章 测量、单位与有效数字

1.1 科学方法的四个词（判断题高频）

术语定义判据
Law 定律对一致自然现象的口头或数学描述只描述"是什么/怎么变"，不解释原因
Hypothesis 假说对现象提出的可检验解释被实验支持后才可能升级为理论

1.4 导出单位与密度

  • 力：N = kg·m·s⁻²；能量：J = N·m = kg·m²·s⁻²；功率：W = J/s；压强：Pa = N/m² = kg·m⁻¹·s⁻²；电荷：C = A·s。

1.5 温度换算（三个刻度）

  • K = ℃ + 273.15（绝对温标，0 K = 绝对零度 = −273.15 ℃，理论上不可达）
  • ℃ = (℉ − 32) × 5/9
  • ℉ = (9/5) × ℃ + 32
  • 温差：ΔT(℃) = ΔT(K) ≠ ΔT(℉)；1 ℃ 的"一度"比 1 ℉ 的"一度"大 1.8 倍。
  • 换算题的有效数字：先按精确数处理 273.15、5/9、9/5，最终结果按原始测定值的有效数字（HW1 第 6 题就是考这个）。

1.6 有效数字（本章失分最多）

数位规则（5 条）

  1. 所有非零数字都有效：2467.1 → 5 位。
  2. 夹在非零数字之间的 0 有效：600.001 → 6 位。
  3. 第一个非零数字左边的 0 无效（只定位小数点）：0.001 → 1 位。
  4. 第一个非零数字右边的 0 有效：0.00100 → 3 位。
  5. 不含小数点的整数，末尾的 0 含义不明：200 可能是 1、2 或 3 位 → 用科学计数法 2.00×10²（3 位）或加小数点 400.（3 位）来消除歧义。

1.7 准确度与精密度

  • 精密度 precision：同一对象多次测量彼此接近的程度（重复性好，与真值无关）。
  • 准确度 accuracy：测量值与真值的接近程度。
  • 四种组合：精密但不准（系统误差，可校正）；准但不精密（随机误差大）；既准又精密（最好）；都不行。
  • 判断句："精密"不能推出"准确"，"准确"也不能推出"精密"（后者在单次测量时尤其要注意）。

1.8 物质的分类与性质

  • 状态：solid / liquid / gas（固液气）。
  • 纯物质 pure substance：element（元素，如 Fe、O₂）或 compound（化合物，如 CO₂、NaHCO₃），有固定组成。
  • 混合物 mixture：homogeneous（均相，组成均匀，如盐水、空气）vs heterogeneous（非均相，如沙水、油水）。
  • 物理性质：不改变物质身份即可观察（颜色、密度、熔点、导电性）；化学性质：需发生化学变化才表现（可燃性、与酸反应）。
  • 广延性质 extensive：与物质的量有关（质量、体积、长度）；强度性质 intensive：与量无关（密度、温度、熔点、电导率）。
  • 分离手段：蒸馏（沸点差）、过滤（溶解度/粒径）、色谱、萃取——依据的是物理性质差异。

2第 2 章 原子结构、同位素与摩尔

2.1 电子的发现（Thomson 与 Millikan）

  • 阴极射线 cathode ray：加高压后从阴极发出的带负电粒子流 → 命名为 electron。
  • Thomson 的 e/m 实验（电场 + 磁场交叉）：
  • 电场力 F_E = qE；磁场力（洛伦兹力）F_B = quB（速度与 B 垂直）。
  • 电子直线通过 → qE = quB → u = E/B。
  • 撤去电场后电子做圆周运动 → quB = mu²/r → q/m = E/(B²r)。
  • 结果：e/m = −1.76×10⁸ C/g（负号表示带负电）。
  • Millikan 油滴实验：平衡时 qE = mg → 测出基本电荷 q = −1.6022×10⁻¹⁹ C。
  • 两式合并得电子质量 me = 9.10×10⁻²⁸ g = 9.109×10⁻³¹ kg。

2.2 放射性与卢瑟福核式模型

  • α 射线：带正电的氦核（He²⁺），偏向负极；β 射线：电子，偏向正极；γ 射线：高能光子，不带电，不被偏转。
  • α 粒子散射：绝大多数穿透（原子内部大部分是空的）；极少数大角度反弹（中心有体积小、质量大、集中正电荷的原子核 nucleus）。
  • 结论：Thomson 的"葡萄干布丁模型"被否证，进入 Rutherford 核式模型（核 + 核外电子）。

2.4 原子序数、质量数与同位素

  • 原子序数 Z = 质子数 = 中性原子的电子数（决定元素身份）。
  • 质量数 A = 质子数 + 中子数 → 中子数 = A − Z。
  • 同位素 isotope：Z 相同、A 不同（中子数不同）的原子。化学性质几乎相同，物理性质/质量不同。
  • 表示法：ᵃ_Z X，如 ¹²₆C、¹⁴₆C；离子还要看电荷：电子数 = Z − 电荷（Mg²⁺ 有 10 个电子）。
  • 离子/同位素比较题（HW2 第 2 题）：分别数电子数（Z−charge）、中子数（A−Z）、质量（∝A，用 amu 比较）。

2.5 平均原子质量

公式

平均原子质量 = Σ（同位素质量 × 天然丰度）

丰度用小数或百分数代入均可（百分比要除以 100）。结果的有效数字由最不精确的丰度决定。

例（碳）：12.00000×0.9893 + 13.003355×0.0107 = 12.011 amu。

例（铷，HW2/L2 练习）：Rb 平均原子质量 85.4678 amu，⁸⁵Rb（丰度 72.17%）为 84.911794 amu，求 ⁸⁷Rb 质量：

85.4678 = 84.911794×0.7217 + x×0.2783 → x ≈ 86.910 amu

反向题（给平均质量求丰度）设一个为 x、另一个为 (1−x) 解一次方程即可。

2.6 摩尔与摩尔质量

  • 阿伏伽德罗常数 NA = 6.022×10²³ mol⁻¹（常数有单位；"阿伏伽德罗数"本身无单位）。
  • 摩尔质量 M：1 mol 物质的质量，单位 g/mol；数值上等于该物质的原子质量/分子质量（amu）。
  • 三条互换算，考试必用：
n = m / M　　N = n × NA　　m = n × M
  • 单位链：质量(g) → ÷M → 摩尔(mol) → ×NA → 粒子数；反向乘除互换。
  • 摩尔质量越大，单个粒子越重；同质量下粒子数越少。
  • 由密度求原子半径（HW2 第 3 题套路）：d = m/V → 一个原子的体积 Vatom = M/(d·NA) → 球体积 4/3πr³ → r（注意"26% 是空腔"要乘以 0.74 的堆积因子/或按题意扣除空隙）。

3第 3 章 量子理论、原子轨道与电子排布

3.1 光：波与粒子

  • 波参数：波长 λ（m）、频率 ν（Hz = s⁻¹）、波数 ν̃ = 1/λ（cm⁻¹）；c = λν，c = 2.998×10⁸ m/s。
  • 电磁波谱按波长从短到长：γ 射线 < X 射线 < 紫外 UV < 可见（400–700 nm）< 红外 IR < 微波 < 无线电。频率与能量顺序相反。
  • 可见光中紫光波长最短、能量最高；红光波长最长、能量最低。
  • 干涉：同相位 → 相长（constructive）；反相位 → 相消（destructive）。
  • 双缝实验说明光有波动性。

3.2 光电效应（光有粒子性）

实验事实：① 低于某一阈值频率 ν₀，再强的光也打不出电子；② 高于阈值时，打出电子的数目与光强成正比；③ 打出电子的动能只与频率有关、与光强无关。

爱因斯坦方程

Ephoton = hν = KEmax + W　　（W = 功函数 work function = hν₀）
  • h = 6.626×10⁻³⁴ J·s
  • 阈值频率 ν₀ = W/h；阈值波长 λ₀ = hc/W
  • 每秒打出的电子数 ∝ 光强（每秒入射光子数）；每个光子的能量只由 ν 决定。
  • 推论：若 hν < W，无论光多强都无电子逸出（经典波动论无法解释，故必须引入光子）。

变式（HW4 第 5 题，光电子能谱 PES）：用已知波长/频率的 UV 打电子，测其动能反推电离能：

IE = hν − KE

3.3 Bohr 氢原子模型

三条假设：① 电子只在特定圆轨道（定态）上运动，不辐射能量；② 轨道半径与能量由量子数 n 决定，n = 1, 2, 3…；③ 电子在能级间跃迁时才吸收/放出光子，光子能量 = 能级差。

能级公式（氢及类氢离子，Z = 核电荷）

En = −(2.18×10⁻¹⁸ J) × Z²/n² = −13.6 × Z²/n² (eV) = −1312 × Z²/n² (kJ/mol)
  • n = 1 为基态 ground state（最稳定、能量最低、半径最小）；n > 1 为激发态 excited state。
  • 能量为负表示电子被核束缚；n → ∞ 时 E → 0（自由电子）。束缚态能量 < 自由电子能量。
  • 半径 r ∝ n²/Z（Z 越大、n 越小，电子被拉得越紧）。

跃迁与光谱

ΔE = E_高 − E_低 = hν = hc/λ
  • 发射 emission：高 → 低，放出光子；吸收 absorption：低 → 高，吸收光子（同一条谱线位置相同）。
  • Rydberg 方程（经验式，与 Bohr 结果一致）：
1/λ = RH × Z² × (1/n₁² − 1/n₂²)，　RH = 1.09737316×10⁷ m⁻¹，n₂ > n₁
  • 系列：n₁ = 1 Lyman（UV）；n₁ = 2 Balmer（可见光，Hα 656 nm、Hβ 486 nm、Hγ 434 nm）；n₁ = 3 Paschen（IR）。
  • 判断"哪次跃迁放出能量更大"：看 |ΔE| ∝ |1/n₁² − 1/n₂²|，能级间隔随 n 增大而变密（n=2→1 最大）。

例：Balmer 系 n = 5 → 2 的波长：1/λ = 1.097×10⁷ × (1/4 − 1/25) = 2.304×10⁶ m⁻¹ → λ = 434 nm。

3.4 de Broglie 波粒二象性

λ = h / (mu) = h / p　（m 单位 kg，u 单位 m/s）
  • 电子等微观粒子也有波动性；宏观物体波长小到不可观测（棒球 0.142 kg、42 m/s → λ ≈ 1.1×10⁻³⁴ m）。
  • 电子（9.1×10⁻³¹ kg、4×10⁶ m/s）→ λ ≈ 2×10⁻¹⁰ m = 0.2 nm，与原子的尺度（0.5–4 Å）相当 → 可观测。
  • 电子衍射实验（与 X 射线衍射图样类似）直接证明电子有波动性。
  • 电子经电压 V 加速（HW3 第 4 题）：KE = eV → u = √(2eV/m) → λ = h/(mu)。V = 5.00×10³ V 时 λ ≈ 17 pm。

3.5 不确定原理

Δx · Δp ≥ h/(4π)，　Δp = m·Δu
  • 位置与动量（速度）不能同时精确确定；这不是仪器问题，是原理性限制。
  • 电子：Δu 为 20% × 5×10⁶ m/s 时，Δx ≈ 5.8×10⁻¹¹ m，与原子半径同量级 → 原子内电子的位置无法精确定义，Bohr 的"确定轨道"不成立。
  • 棒球：Δp 极小 → Δx ≈ 10⁻²⁹ m → 宏观物体位置可精确确定（量子效应可忽略）。

3.6 驻波与一维势箱（particle in a box）

  • 电子在原子中稳定存在 ↔ 形成驻波：轨道周长必须是波长的整数倍，2πr = nλ（n = 1, 2, 3…）→ 能量只能取分立值 → 能量量子化。
  • 一维势箱（长度 L，电子只能在 0 ≤ x ≤ L 内）：
En = n²h² / (8mL²)，　n = 1, 2, 3…
ψn(x) = √(2/L) · sin(nπx/L)
概率 P = ∫ ψ² dx（在某区间找到电子的概率）
  • 节点 nodes = n − 1；n 越大能量越高、节面越多。
  • 基态 n=1 时概率密度最大在箱子中央（x = L/2）。
  • 跃迁：ΔE = E_2 − E_1 = 3h²/(8mL²)，对应光子 λ = hc/ΔE。
  • 例：L = 1.00×10² pm → ΔE ≈ 1.81×10⁻¹⁷ J，λ ≈ 11.0 nm（X 射线区）。
  • 题目给"0 到 30 pm 之间的概率百分比"：算 ∫₀^30 ψ²dx ÷ ∫₀^150 ψ²dx（或直接对归一化波函数积分）。

3.7 Schrödinger 方程与"轨道"

  • 解 Schrödinger 方程得到波函数 ψ（wavefunction）；ψ 本身没有直接物理意义，ψ² 表示电子出现的概率密度（electron density）。
  • 描述一个原子轨道只需要 3 个量子数（n, l, ml）；第 4 个 ms 描述电子自旋。
  • orbital（轨道）≠ orbit（玻尔轨道）：orbital 是概率分布的"云"，不是固定路径。

4第 4 章 有效核电荷与周期趋势

4.1 周期表的结构（英文术语要认得）

  • 周期 period（行）＝ 电子层 n；族 group（列）。
  • 主族 main group / representative elements：1A–8A（s 区 + p 区）。
  • 具体族名：1A 碱金属 alkali metals；2A 碱土金属 alkaline earth metals；6A 氧族 chalcogens；7A 卤素 halogens；8A 稀有气体 noble gases。
  • 过渡金属 transition metals：3B–2B（d 区，第 3–12 族）；2B（Zn 族）d 亚层全满，有时称 post-transition。
  • 镧系 lanthanides / 锕系 actinides：f 区。
  • 按价电子所在亚层分区：s 区（1、2 族 + He）、p 区（13–18 族）、d 区（3–12 族）、f 区。
  • 价电子 valence electrons = 最外层 ns + np（主族）；核心电子 core electrons = 内层。

4.2 有效核电荷 Zeff

  • 多电子原子中，电子同时受核吸引与其他电子排斥 → 内层电子屏蔽 shielding 掉一部分核电荷。
  • 定义：
Zeff = Z − σ　（Z = 质子数，σ = 屏蔽常数）
  • 趋势：同周期从左到右 Zeff 增大（核电荷增加、屏蔽不变）；同族从上到下 Zeff 变化很小（Z 与 σ 同步增加）。
  • 例（第二周期）：Li 1.28 → Be 1.91 → B 2.42 → C 3.14 → N 3.83 → O 4.45 → F 5.10。

Slater 规则（求 σ）

  1. 排成组：(1s)(2s,2p)(3s,3p)(3d)(4s,4p)(4d)(4f)…
  2. 右边（更高 n）的电子贡献 0。
  3. 同组电子每个贡献 0.35（1s 组为 0.30）。
  4. 对 ns/np 电子：n−1 层每个 0.85；n−2 及更内层每个 1.00。
  5. 对 nd/nf 电子：所有在它左边的电子组每个 1.00。

例：Br 的 3d 电子（[Ar]3d¹⁰4s²4p⁵）

σ = 1.00×(18) + 0.35×(9) = 21.15 → Zeff = 35 − 21.15 = 13.85

（18 = 1s²2s²2p⁶3s²3p⁶；9 = 3d 上另外 9 个电子）

4.3 原子半径

  • 定义：金属半径 = 相邻同种金属原子核间距的一半；共价半径 = 相邻同种原子成键核间距的一半。
  • 趋势：同周期从左到右减小（Zeff 增大，把电子拉得更紧）；同族从上到下增大（n 增大，层数增加）。
  • 离子比较：同周期阳离子半径 < 原子半径；阴离子半径 > 原子半径。

4.4 电离能 IE

  • 定义：气态原子失去一个电子所需的最小能量（kJ/mol）。Na(g) → Na⁺(g) + e⁻，IE₁ = 495.8 kJ/mol。
  • 趋势：同周期从左到右增大（Zeff↑、半径↓）；同族从上到下减小（半径↑、屏蔽↑）。
  • 反常（必考）：
  • Be > B、Mg > Al：Be/Mg 是 ns² 全满，B/Al 要失去 np 电子（能量更高、更易失）。
  • N > O、P > S：N/P 是半满 p³，O/S 多一个成对电子，电子间排斥使其更易失去。
  • 逐级电离能：IE₁ < IE₂ < IE₃…；当内层开始被剥离时出现巨大跳跃。
  • 例：Na IE₁ = 496、IE₂ = 4562 kJ/mol → 跳跃在 IE₁/IE₂ 之间 → Na 只有 1 个价电子。
  • 判断价电子数：找最大跳跃出现在 IE_k 与 IE_{k+1} 之间 → 有 k 个价电子（据此定位族）。
  • 例（Na vs Mg）：IE₁：Na < Mg（Mg Zeff 大）；IE₂：Na > Mg（Na⁺ 已是 [Ne] 全满，再失去要破坏内层）。

4.5 电子亲和能 EA

  • 定义：气态原子接受一个电子时放出的能量的相反数（即 EA = −ΔE）。Cl(g) + e⁻ → Cl⁻(g)，EA = 349 kJ/mol。
  • 符号约定要小心：放出能量 → EA 为正；需要吸收能量 → EA 为负。
  • 趋势：同周期从左到右 EA 一般增大（Zeff↑，更容易接受电子）；同族从上到下一般减小。
  • 反常：Be、N（2s² 全满、2p³ 半满，加电子要破坏稳定性，EA 很小甚至为负）；EA₂ 总是负（第二个电子要克服负离子排斥）：
  • O(g) + e⁻ → O⁻(g)，EA₁ = +141 kJ/mol
  • O⁻(g) + e⁻ → O²⁻(g)，EA₂ = −741 kJ/mol
  • 比较时注意：EA 越大 = 越容易得电子 = 非金属性越强（Cl > F 在某些数据里，因为 F 半径太小、电子排斥大）。

4.6 金属性与离子半径

  • 金属性 metallic character：同周期从左到右减弱，同族从上到下增强（越易失电子）。金属 → 类金属 metalloids（B、Si、Ge、As、Sb、Te）→ 非金属。
  • 离子半径：阳离子 < 其原子（失去电子、电子排斥减小、有时整层消失）；阴离子 > 其原子（电子增多、排斥增大）。
  • 等电子系列 isoelectronic series：电子数相同、核电荷不同 → Z 越大，半径越小。
  • 例：N³⁻ > O²⁻ > F⁻ > Na⁺ > Mg²⁺（都是 10 电子，Z 从 7 到 12）。
  • 主族常见离子电荷：1A +1；2A +2；3A +3（Al³⁺）；5A −3；6A −2；7A −1；Ag⁺、Zn²⁺、Cd²⁺ 固定。

5.1 离子化合物与晶格能

5.3 分子式、经验式与两条定律

  • 分子式 molecular formula：一个分子中各元素原子的确切数目（C₆H₁₂O₆）。
  • 经验式 empirical formula：最简整数比（CH₂O）。
  • 结构式 structural formula：还给出连接方式。
  • 定组成定律 law of definite proportions：同一化合物无论来源，元素质量比固定。
  • 倍比定律 law of multiple proportions：两元素形成多种化合物时，与固定质量的一种元素化合的另一种元素的质量成小整数比（CO 与 CO₂ 中 O 的质量比 1:2）。

5.4 摩尔质量、百分组成、经验式

  • 摩尔质量 M = 各原子相对原子质量之和（g/mol）。
  • 百分组成：%X = (n × MX) / M化合物 × 100%。
  • 由百分组成求经验式（四步）：
  1. 取 100 g → 各元素质量即为其百分数（g）；
  2. 各除以原子量 → 摩尔数；
  3. 全部除以最小的摩尔数；
  4. 若得分数，整体乘以最小整数使其变整数。
  • 求分子式：n = M(实验测得) / M(经验式) → 分子式 = (经验式)×n。
  • 由燃烧分析（CO₂、H₂O 质量反推 C、H，O 用差减法）也是同一套路。

要点

  • 色散力依赖"电子有多容易被扰动"（极化率）：分子越大、电子越多，瞬时偶极越大，沸点越高。卤素常温下的状态（F₂、Cl₂ 气体 → Br₂ 液体 → I₂ 固体）就是这个规律。
  • 氢键的判据是结构，不是"有没有 H"：CH₄、H₂S、HCl 都没有氢键。
  • 强度顺序：离子–偶极 > 氢键 > 偶极–偶极 > 色散力；但所有分子都有色散力，答题时别漏。

7第 7 章 价键理论与杂化

Lecture 7 的 7.4–7.6 与 Lecture 8 的开头。核心：键 = 轨道重叠；杂化 = 为了让重叠更有效、键角更合理。

7.1 价键理论（VB）三条

  1. 键在两个单占据原子轨道的重叠中形成。
  2. 重叠区共享的两个电子必须自旋相反（Pauli）。
  3. 成键使体系势能降低（所以键能 > 0）。
  • HF：H 的 1s 与 F 的 2p 重叠。
  • F₂：两个 F 的 2p 重叠。

7.2 VB 的两个不足（为什么会需要杂化）

  • H₂S：实验键角 92°，接近 90°（纯 p 轨道夹角）；但 VSEPR 按 4 个电子域预测 ~109.5° → VB 无法解释，需要杂化。
  • BeCl₂：基态 Be 是 2s²，没有未成对电子，按 VB 一个键都形成不了，但实测有两个等价 Be–Cl 键、180° → 必须先激发再杂化。

7.3 杂化的图像与"六步法"

核心等式：杂化轨道数 = 中心原子的电子域数 = 参与杂化的原子轨道数。

步骤（以 BF₃ 为例）：

  1. 画 Lewis 结构；
  2. 数中心原子的电子域 → 3；
  3. 画基态轨道图（B：2s²2p¹）；
  4. 激发使未成对电子数最大（2s¹2px¹2py¹）；
  5. 混合 3 个原子轨道 → 3 个 sp² 杂化轨道；
  6. 填电子（先单占再加对），再与配体轨道重叠成键。
激发的能量消耗由成键释放的能量补偿 —— 这也是"为什么能杂化"的答案。

7.6 多重键的杂化

  • 每个 C 有 3 个电子域：2 个 C–H + 1 个 C=C → sp²。
  • 5 个 σ 键：1 个 C–C（sp²–sp²）+ 4 个 C–H（sp²–1s）。
  • 每个 C 剩 1 个未杂化 2p，垂直于分子平面，侧面重叠成 1 个 π 键。
  • 全部原子共平面，C=C 不能旋转。

乙炔 C₂H₂（sp）

  • 每个 C 有 2 个电子域 → sp，直线形。
  • 3 个 σ 键：1 个 C–C（sp–sp）+ 2 个 C–H（sp–1s）。
  • 每个 C 剩 2 个未杂化 2p → 2 个 π 键，互相垂直。

苯 C₆H₆：每个 C 为 sp²，3 个 σ（2 个 C–C + 1 个 C–H），每个 C 剩 1 个 2p；6 个 2p 共同形成离域 π 体系（见 8.6）。

8第 8 章 分子轨道理论

Lecture 8 的 7.7–7.8。为什么需要它：Lewis 结构无法解释 O₂ 的顺磁性。Lewis 说 O₂ 没有未成对电子，但实验测到 O₂ 有 2 个未成对电子。

8.1 MO 的基本规则

  • 原子轨道组合成属于整个分子的分子轨道（MO）；
  • 轨道数守恒：n 个原子轨道 → n 个 MO；
  • 每个 MO 最多 2 个电子，按 Pauli、Aufbau、Hund 填充；
  • 成键 MO（σ、π）能量低于原子轨道，反键 MO（σ∗、π∗）更高，并带 ∗。

8.2 键级

键级 bond order = (成键电子数 − 反键电子数) / 2
  • 键级越大 → 键越短、越强、越稳定；键级为 0 → 分子不存在（He₂）。
  • H₂：2 个电子都在 σ1s → BO = 1；He₂：σ1s²σ∗1s² → BO = 0，不存在。

8.3 第二周期双原子分子的能级顺序（两种，取决于 2s–2p 混合）

  • Li₂ ~ N₂（原子序数小，2s 与 2p 能量接近 → 有混合）：
σ2s < σ∗2s < π2p < σ2p < π∗2p < σ∗2p
  • O₂、F₂、Ne₂（核电荷大，几乎不混合）：
σ2s < σ∗2s < σ2p < π2p < π∗2p < σ∗2p

记法："左边 π 低、右边 σ 低"，分界在 N₂ / O₂ 之间。

9第 8–9 章 化学计量与水溶液中的反应

Lecture 8 末尾（8.3–8.4）与 Lecture 9 全部（9.1–9.6）。这一章是"算"的主战场：配平 → 找限量试剂 → 算产率 → 换算浓度 → 判断反应类型 → 写净离子方程。

9.1 化学方程式与配平

  • 系数代表摩尔比，不是质量比；配平后两边原子数与电荷数都要守恒。
  • 常见反应类型：combination（化合）、decomposition（分解）、combustion（燃烧）、displacement（置换）、metathesis / double replacement（复分解）、disproportionation（歧化）。

9.2 限量试剂与产率

  • 限量试剂 limiting reactant：最先被消耗完的反应物，决定产量。
  • 判断方法：把每种反应物的 n 都除以它的系数，商最小的是限量试剂。
  • 过量试剂剩余量 = 初始量 − 已反应量。
  • 理论产量按限量试剂算；实际产量由实验给出。
百分产率 %yield = (实际产量 / 理论产量) × 100%

例（Worked Example 8.7，Alka-Seltzer）：3NaHCO₃ + H₃C₆H₅O₇ → 3CO₂ + 3H₂O + Na₃C₆H₅O₇；1.700 g NaHCO₃（84.01）与 1.000 g 柠檬酸（192.12）。n(NaHCO₃) = 0.02023 mol，n(酸) = 0.005205 mol；按系数比 NaHCO₃ 需要 3×0.005205 = 0.01562 mol < 0.02023 → 柠檬酸是限量试剂，NaHCO₃ 过量 0.00461 mol ≈ 0.387 g，CO₂ 产量 3×0.005205×44.01 ≈ 0.687 g。

9.3 溶液的浓度

M = n(溶质) / V(溶液，L)　　（mol/L，注意分母是溶液体积不是溶剂体积）
稀释：M₁V₁ = M₂V₂（稀释前后溶质的物质的量不变）
  • 用 mL 时可直接写 M_c × mL_c = M_d × mL_d。
  • 系列稀释 serial dilution：多次等倍数稀释，浓度按倍率连乘。
  • 溶液化学计量：V × M → mol → 用系数比 → 目标物的 mol → 再转回 V 或 m。

9.4 电解质与沉淀反应

  • 溶液 = 溶剂（量最多）+ 溶质；电解质溶后导电（解离或电离），非电解质不导电（如蔗糖）。
  • 强电解质：可溶离子化合物、强酸、强碱（完全解离）；弱电解质：弱酸弱碱（部分电离，以分子为主）。
  • 必背 7 个强酸：HCl、HBr、HI、HNO₃、H₂SO₄、HClO₄、HClO₃。
  • 常见强碱：LiOH、NaOH、KOH、RbOH、CsOH、Ca(OH)₂、Sr(OH)₂、Ba(OH)₂。

  1. 分子方程：全部写化学式。
  2. 完全离子方程：强电解质拆成离子，沉淀/弱电解质/气体保留分子式。

9.5 酸碱反应

  • Arrhenius：酸在水中产生 H⁺，碱产生 OH⁻。
  • Brønsted：酸 = 质子给体，碱 = 质子受体；H⁺ 与 H₃O⁺ 指同一物种。
  • 一元酸 monoprotic / 多元酸 polyprotic：H₂SO₄ 第一步强、第二步很弱（逐级电离）。
  • 中和：酸 + 碱 → 水 + 盐；绝大多数净离子式就是
H⁺(aq) + OH⁻(aq) → H₂O(l)

9.6 氧化还原反应

  • 氧化 = 失电子（氧化数升高）；还原 = 得电子（氧化数降低）；两者同时发生。
  • 还原剂被氧化，氧化剂被还原（口诀：升失氧、降得还）。

氧化数规则

  1. 单质的氧化数 = 0。
  2. 同种物种各原子氧化数之和 = 该物种的电荷。
  3. 单原子离子的氧化数 = 离子电荷。
  4. 常见固定值：F = −1；O = −2（过氧化物中 −1）；H = +1（金属氢化物中 −1）；1A = +1、2A = +2。

活性顺序 activity series：按"越靠上越易被氧化"排列（Li > K > Ba > Ca > Na > Mg > Al > Zn > Fe > Ni > Sn > Pb > H₂ > Cu > Hg > Ag > Au）。上面的金属能把下面金属的离子置换出来；反方向不反应。

半反应法配平

  1. 拆成氧化、还原两个半反应；
  2. 各自配平原子（O 用 H₂O、H 用 H⁺）；
  3. 各自配平电荷（加 e⁻）；
  4. 两边乘系数使电子数相等；
  5. 相加，约去电子，检查原子与电荷。

例：Cr + Ni²⁺ → Cr³⁺ + Ni → 2×{Cr → Cr³⁺ + 3e⁻} + 3×{Ni²⁺ + 2e⁻ → Ni} → 2Cr + 3Ni²⁺ → 2Cr³⁺ + 3Ni。

其他 redox 类型：化合（N₂ + 3H₂ → 2NH₃）、分解（2NaH → 2Na + H₂）、置换、歧化（同一元素既升又降，如 H₂O₂ 中 O 为 −1）、燃烧。

9.7 pH

pH = −log[H₃O⁺]，　[H₃O⁺] = 10^(−pH)
  • 25 ℃ 纯水：[H₃O⁺] = 1.0×10⁻⁷ M → pH = 7.00（中性）；pH 无量纲。
  • 例：3.5×10⁻⁴ M → pH = 3.46；2×10⁻⁷ M → pH = 6.70。

9.8 重量分析与滴定

  • 重量分析 gravimetric analysis：靠称沉淀质量反推被测组分（要求反应完全、接近 100% 产率）。例：AgCl 沉淀 → %Cl = (m(AgCl)/M(AgCl) × M(Cl)) / m(样品) × 100%。
  • 滴定 titration：用已知浓度的标准溶液（buret）滴定待测液，当量点 equivalence point 由指示剂变色（endpoint）指示。
  • NaOH 溶液需用 KHP（邻苯二甲酸氢钾，一元酸）标定，因为 NaOH 会吸收 CO₂ 变质。
  • 计算骨架：n(酸) × 系数比 = n(碱) → 由 M、V 互算。

11高频易错点（30 条，按失分概率排序）

  1. 加减看小数位、乘除看有效数字，混算时中间不提前舍入。
  2. 精确数（1 kg = 1000 g、计数、定义值）不限制结果的有效数字。
  3. 温度换算中 273.15 与 5/9 是精确数，不要用它去定结果位数。
  4. 200、1000 这类整数末尾 0 有歧义 → 用科学计数法或加点。
  5. 平均原子质量必须按丰度加权，不是算术平均。
  6. 离子电子数 = Z − 电荷（Mg²⁺ 是 10 个电子，不是 12）。
  7. 中子数 = A − Z，与电荷无关。
  8. 光电效应中光强只影响电子数目，不影响单个电子动能；动能只由 ν 决定。
  9. 阈值频率以下，再强的光也不出电子。
  10. En 是负值：n 越大能量越高（越接近 0），不要被"负号"骗。
  11. Rydberg 公式中 n₁ 是终态（较小），n₂ 是初态（较大）；算发射时 ΔE > 0。
  12. 1/λ 的单位是 m⁻¹ 时 RH 用 1.097×10⁷；用 nm 时要换算。
  13. de Broglie 计算 m 必须用 kg，u 用 m/s；宏观物体 λ 小到无意义。
  14. 不确定原理是 ≥，不是 =；Δp 要先由 Δu 乘 m 得到。
  15. 一维势箱中"箱外概率为零"，基态最可几位置在中央，不是两端。
  16. 4s 先填 3d 后填，但过渡金属失电子先失 4s；Cr/Cu 是例外。
  17. 电子数为偶数不一定反磁（O₂ 顺磁）。
  18. 逐级电离能的巨大跳跃位置决定价电子数，进而定族。
  19. 电子亲和能符号：放能为正；EA₂ 一定为负。
  20. 命名：第一个元素前不加 mono-；变价金属必须写罗马数字；含氧酸 per/…/hypo 的顺序别弄反。
  21. 有极性键 ≠ 极性分子：BF₃、CCl₄、PCl₅ 都是非极性（键矩抵消）。
  22. 判断极性要画完几何再看矢量和；有孤对几乎一定极性。
  23. 氢键要求 H 直接连 N/O/F：H₂S、HCl、CH₃COCH₃ 都没有氢键。
  24. 色散力所有分子都有，答题时不能只说偶极作用。
  25. 杂化轨道数 = 电子域数；数错域数（把双键当两个域）是常见错。
  26. σ 键可旋转、π 键不能旋转，所以存在顺反异构。
  27. MO 中 O₂ 的 2 个未成对电子在 π∗ 上；键级 2 却顺磁——这是必考反差。
  28. Li₂~N₂ 与 O₂~Ne₂ 的能级顺序不同（σ2p 与 π2p 谁在前）。
  29. 净离子方程里：强电解质要拆、沉淀/弱电解质/气体/水不拆。
  30. 浓度 M 的分母是溶液体积，不是溶剂体积；稀释用 M₁V₁ = M₂V₂。

12十类题型模板

模板 1：有效数字与单位换算

写"给定值 → 换算因子 → 结果"，每步标单位，最后一次性定有效数字。

模板 2：同位素丰度反解

设丰度 x 与 1−x，列 Σ(m_i·x_i) = 平均质量，解一次方程；检验 x ∈ (0,1)。

模板 3：光子能量 / 光电效应 / 光谱

先算 E = hc/λ，再用 ΔE = E_光子 与能级差联立；注意 J 与 kJ/mol 的换算。

模板 4：量子数合法性 / 容量

逐项检查 n ≥ 1、0 ≤ l ≤ n−1、|ml| ≤ l、ms = ±½；容量用 2(2l+1) 与 2n²。

模板 5：电子排布 + 磁性

Aufbau 填 → noble-gas 简式 → 画轨道图 → 数未成对 → 判顺/反磁；离子先失最外层。

模板 6：趋势排序（半径/IE/EA/离子半径）

定位周期表 → 同周期用 Zeff、同族用 n → 检查反常（2A/3A、5A/6A、全满/半满）→ 等电子系列按 Z 排。

模板 7：结构四连（Lewis → VSEPR → 杂化 → 极性）

画 Lewis → 数电子域 → 定几何与键角 → 定杂化（sp/sp²/sp³/…）→ 看对称性判极性 → 注明 σ/π 数目。

模板 8：MO 键级与磁性

写出价电子数 → 按正确能级顺序填 → 数成键/反键 → BO = (N_b − N_a)/2 → 看未成对电子判磁性。

模板 9：水溶液计算（限量试剂 / 浓度 / 滴定）

配平 → 全部换算成 mol → 除以系数比找限量 → 目标物 mol → 转质量或体积；浓度题用 M = n/V 与 M₁V₁ = M₂V₂。

模板 10：氧化还原配平

拆半反应 → 配原子（H₂O/H⁺）→ 配电荷（e⁻）→ 电子数通分 → 相加 → 查原子与电荷。
