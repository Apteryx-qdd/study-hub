7第 7 章 价键理论与杂化

Lecture 7 的 7.4–7.6 与 Lecture 8 的开头。核心：键 = 轨道重叠；杂化 = 为了让重叠更有效、键角更合理。

7.1 价键理论（VB）三条

  1. 键在两个单占据原子轨道的重叠中形成。
  2. 重叠区共享的两个电子必须自旋相反（Pauli）。
  3. 成键使体系势能降低（所以键能 > 0）。
  • HF：H 的 1s 与 F 的 2p 重叠。
  • F₂：两个 F 的 2p 重叠。

7.2 VB 的两个不足（为什么会需要杂化）

  • H₂S：实验键角 92°，接近 90°（纯 p 轨道夹角）；但 VSEPR 按 4 个电子域预测 ~109.5° → VB 无法解释，需要杂化。
  • BeCl₂：基态 Be 是 2s²，没有未成对电子，按 VB 一个键都形成不了，但实测有两个等价 Be–Cl 键、180° → 必须先激发再杂化。

7.3 杂化的图像与"六步法"

核心等式：杂化轨道数 = 中心原子的电子域数 = 参与杂化的原子轨道数。

步骤（以 BF₃ 为例）：

  1. 画 Lewis 结构；
  2. 数中心原子的电子域 → 3；
  3. 画基态轨道图（B：2s²2p¹）；
  4. 激发使未成对电子数最大（2s¹2px¹2py¹）；
  5. 混合 3 个原子轨道 → 3 个 sp² 杂化轨道；
  6. 填电子（先单占再加对），再与配体轨道重叠成键。
激发的能量消耗由成键释放的能量补偿 —— 这也是"为什么能杂化"的答案。

7.4 杂化类型一览表

域数杂化键角几何典型分子
2sp180°直线BeCl₂、CO₂、C₂H₂（每个 C）
3sp²120°平面三角BF₃、SO₃、C₂H₄（每个 C）
4sp³109.5°四面体CH₄、NH₃、H₂O
5sp³d90°/120°三角双锥PCl₅
6sp³d²90°八面体SF₆
  • NH₃：sp³，但一对孤对占据一个杂化轨道 → 三角锥、107°；H₂O：sp³、两对孤对 → 弯曲、104.5°。
  • 孤对越占位，键角越小：CH₄ 109.5° > NH₃ 107° > H₂O 104.5°。

7.5 σ 键与 π 键

σ 键π 键
重叠方式头碰头（沿核间轴）肩并肩（侧面）
电子云位置沿轴集中轴上下两瓣
能否旋转可以自由旋转不能旋转
出现每个键都有且只有一个 σ双键 1 个、三键 2 个
  • 单键 = 1σ；双键 = 1σ + 1π；三键 = 1σ + 2π。
  • π 键不能旋转 → 顺反异构：1,2-二氯乙烯的 cis/trans 就是这么来的。

7.6 多重键的杂化

乙烯 C₂H₄（sp²）

  • 每个 C 有 3 个电子域：2 个 C–H + 1 个 C=C → sp²。
  • 5 个 σ 键：1 个 C–C（sp²–sp²）+ 4 个 C–H（sp²–1s）。
  • 每个 C 剩 1 个未杂化 2p，垂直于分子平面，侧面重叠成 1 个 π 键。
  • 全部原子共平面，C=C 不能旋转。

乙炔 C₂H₂（sp）

  • 每个 C 有 2 个电子域 → sp，直线形。
  • 3 个 σ 键：1 个 C–C（sp–sp）+ 2 个 C–H（sp–1s）。
  • 每个 C 剩 2 个未杂化 2p → 2 个 π 键，互相垂直。

苯 C₆H₆：每个 C 为 sp²，3 个 σ（2 个 C–C + 1 个 C–H），每个 C 剩 1 个 2p；6 个 2p 共同形成离域 π 体系（见 8.6）。

7.7 轨道重叠判断 σ / π / 不成键

以 x 轴为核间轴：

组合结果理由
1s + 1sσ头碰头，轴对称
1s + 2sσ头碰头
1s + 2pxσ沿轴头碰头
