6§3.3 逆矩阵（大题高发区）

定义可逆与唯一性

设 A 为 n×n 方阵。若存在 B 使 AB = BA = I，则称 A 可逆，B 记作 A−1。
逆唯一：若 B、C 都是逆，则 B = BI = B(AC) = (BA)C = IC = C。

注意：只有方阵才谈逆；而且方阵也不一定有逆（见“奇异”判定）。

公式2×2 的逆（最快，必背）

[[a, b], [c, d]]⁻¹ = 1/(ad − bc) · [[d, −b], [−c, a]]，要求 ad − bc ≠ 0

口诀：主对角互换、副对角变号、除以 ad − bc。ad − bc 叫行列式 det A。

例：[[2,1],[5,3]]，det = 6 − 5 = 1 ⇒ 逆 = [[3,−1],[−5,2]]。

算法通用方法：[A | I] → [I | A⁻¹]（Gauss–Jordan）

把单位阵拼在右边，只用行变换把左边化成 I，右边自动变成 A−1。

例：A = [[1,2,3],[0,1,4],[5,6,0]]（det = 1，所以结果都是整数）

  [ 1   2   3 |  1   0   0 ]                    [ 1   0   0 | −24  18   5 ]
  [ 0   1   4 |  0   1   0 ]  ──行变换──→       [ 0   1   0 |  20 −15  −4 ]
  [ 5   6   0 |  0   0   1 ]                    [ 0   0   1 |  −5   4   1 ]

所以 A−1 = [[−24,18,5],[20,−15,−4],[−5,4,1]]。验算：1(−24) + 2(20) + 3(−5) = 1 ✓

三个禁忌：① 只能用行变换（不能做列变换）；② 必须化到左边 = I（不是阶梯形就停）；③ 非方阵不要谈逆。

定理可逆的等价条件（基本定理）

对 n×n 矩阵 A，下列命题全部等价：
(a) A 可逆；　(b) Ax = b 对每个 b 都有唯一解；　(c) Ax = 0 只有零解；
(d) A 的 RREF 是 In；　(e) A 是若干初等矩阵的乘积；　(f) A 的 n 列线性无关（无自由变量）。

初等矩阵：对 I 做一次初等行变换得到的矩阵。关键定理：对 A 做某行变换 = 左乘相应的初等矩阵 E；每个初等矩阵都可逆，且逆是同类型的初等矩阵。

证明“可逆”的实用手法：只要找到 B 使 AB = I 或 BA = I（一侧即可），就能断言 A 可逆且 B = A−1。做证明题时这句话非常好用。

性质逆的运算法则

(A−1)−1 = A　　(Aᵀ)−1 = (A−1)ᵀ　　(AB)−1 = B−1A−1（反序）
(cA)−1 = (1/c)A−1（c ≠ 0）　　(An)−1 = (A−1)n

验证 (AB)⁻¹ = B⁻¹A⁻¹：只需算 (AB)(B⁻¹A⁻¹) = A(BB⁻¹)A⁻¹ = AIA⁻¹ = I，由基本定理即得。

错得最多的一条：(A + B)−1 ≠ A−1 + B−1（加法没有逆的公式）。

应用用逆矩阵解方程组 / 判断奇异

若 A 可逆，则 Ax = b 的唯一解是 x = A−1b。

例：2x + y = 3，5x + 3y = 1。[[2,1],[5,3]]−1 = [[3,−1],[−5,2]]，故

x = [[3,−1],[−5,2]]·[3; 1] = [9 − 1; −15 + 2] = [8; −13]

验证：2(8) + (−13) = 3 ✓，5(8) + 3(−13) = 1 ✓。

奇异（不可逆）的判定：化 [A|I] 时左边出现整行 0 ⇒ A 不可逆。
等价说法：det A = 0、RREF ≠ I、Ax = 0 有非零解、某列不是主元列、列线性相关。

例：[[1,2],[2,4]] → R2 − 2R1 得 [0 0 | −2 1]，左边 0 行而右边非 0 ⇒ 不可逆（第二列 = 2×第一列）。
