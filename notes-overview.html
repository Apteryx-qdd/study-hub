0一页看懂这门课的主线

这门课其实只有一条因果链，考试题几乎都落在这条链的某一环上：

  1. 怎么测量、怎么报数 → 有效数字、单位换算、误差（Ch.1）
  2. 物质由什么组成 → 亚原子粒子、Z 与 A、同位素、平均原子质量、摩尔（Ch.2）
  3. 电子在原子里的状态 → 光的波粒二象性、Bohr 能级、de Broglie、不确定原理、四个量子数、轨道、电子排布（Ch.3）
  4. 电子排布决定性质 → 有效核电荷 Zeff 决定原子半径、电离能、电子亲和能、离子半径（Ch.4）
  5. 怎么把物质写清楚、算清楚 → 命名、化学式、摩尔质量、百分组成、经验式（Ch.5）

一句话记忆：结构（电子排布）→ 有效核电荷 → 性质趋势。凡是问"为什么这个更大/更难失去电子/更稳定"，答案最终都要绕回 Zeff、屏蔽、半径、以及半满/全满稳定性。
