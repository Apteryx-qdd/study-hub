7作图题：把 f、f′、f″ 的信息排成一张表

P8. Present all required information about f, f′, and f″. Then sketch the curves.
(a) y = x√(5 − x)    (b) y = x tan x, −π/2 < x < π/2
作图的清单（照抄就行）：定义域 → 截距 → 对称性/周期性 → 垂直/水平渐近线 → f′ 符号与增减 → 极值点 → f″ 符号与凹凸 → 拐点 → 端点行为（含垂直切线）。

(a) y = x√(5 − x)

定义域5 − x ≥ 0 ⇒ x ≤ 5，即 (−∞, 5]
截距y = 0 ⇔ x = 0 或 x = 5
端点行为x → −∞ 时 y ≈ x√5 → −∞（因为 √(5−x) 为正、x 为负）
y′ = √(5 − x) − x/(2√(5 − x)) = [2(5 − x) − x] / (2√(5 − x)) = (10 − 3x)/(2√(5 − x))

y′ = 0 ⇔ x = 10/3；x = 5 处 y′ → −∞（垂直切线）。

区间(−∞, 10/3)(10/3, 5)
y′+ 增 ↗− 减 ↘
最大（也是绝对最大）：y(10/3) = (10/3)√(5/3) = 10√15/9 ≈ 4.30
y″ = (3x − 20) / [4(5 − x)3/2] < 0  （当 x < 5）

分母恒正，而 x < 5 时 3x − 20 < −5 < 0 ⇒ 全定义域凹向下，无拐点。

(a) 素描要点：从 (−∞, −∞) 上升，穿过原点 (0,0)，在 (3.33, 4.30) 达峰，再下降到 (5,0) 并以竖直切线收尾；整条曲线“拱”形，没有 S 弯。

(b) y = x tan x，−π/2 < x < π/2

定义域(−π/2, π/2)
对称性y(−x) = (−x)tan(−x) = x tan x ⇒ 偶函数，关于 y 轴对称，只需研究 [0, π/2)
截距(0, 0)
渐近线x → ±π/2 时 tan x → ±∞ 且 x 同号 ⇒ y → +∞，两条垂直渐近线 x = ±π/2
y′ = tan x + x sec²x = (sin x cos x + x)/cos²x = (x + ½sin 2x)/cos²x

记 h(x) = x + ½sin 2x，则 h′(x) = 1 + cos 2x ≥ 0，等号只在 x = ±π/2 成立 ⇒ h 严格递增；h(0) = 0，故 x < 0 时 h < 0，x > 0 时 h > 0。于是 y′ 与 h 同号：

区间(−π/2, 0)(0, π/2)
y′− 减 ↘+ 增 ↗

⇒ 在 (0,0) 取绝对最小 0，无局部最大。

y″ = sec²x + sec²x + 2x sec²x tan x = 2sec²x (1 + x tan x)

注意 (1 + x tan x)′ = tan x + x sec²x = y′，所以括号在 (−π/2, 0) 递减、在 (0, π/2) 递增，最小值是 x = 0 处的 1 ⇒ 括号 ≥ 1 > 0。故

y″ > 0  （整个 (−π/2, π/2) 上凹向上），无拐点
(b) 素描要点：关于 y 轴对称的“碗”，最低点 (0,0) 且该处 y′ = 0（水平切线），两侧升到 +∞，全程凹向上（越来越陡）。
