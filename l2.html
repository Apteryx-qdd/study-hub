3L2 · 张成集与线性无关

核心视角把 Ax = b 看成“列的组合”

把 A 按列拆开：A = [a₁ a₂ ⋯ an]，则

Ax = x₁a₁ + x₂a₂ + ⋯ + xnan = b

于是“解方程组”= 问：取什么系数，能让 A 的各列组合出 b？

定理（相容性的列形式）：以 [A | b] 为增广矩阵的方程组相容 ⇔ b 是 A 的列向量的线性组合 ⇔ b ∈ span{a₁,…,an}。

几何含义：唯一解 ⇒ b 落在 span 中且表示方式唯一；无穷多解 ⇒ b 在 span 中但表示方式不唯一；无解 ⇒ b 根本不在 span 中。

定义线性组合与张成

线性组合：给定 v₁,…,vk，形如 c₁v₁ + c₂v₂ + ⋯ + ckvk 的表达式（ci ∈ ℝ）。

张成 span(S) = 所有线性组合构成的集合：

span{v₁,…,vk} = { c₁v₁ + ⋯ + ckvk : c₁,…,ck ∈ ℝ }

若 span(S) = ℝⁿ，则称 S 是 ℝⁿ 的张成集（spanning set）：这些向量足够多，可以“搭出”空间中每个向量。

四种组合（同一个式子，不同的系数限制）：

类型形式系数限制得到
线性组合 linearΣ θixiθi ∈ ℝ子空间 span{xi}
锥组合 conicΣ θixiθi ≥ 0凸锥
仿射组合 affineΣ θixiΣθi = 1仿射空间
凸组合 convexΣ θixiθi ≥ 0 且 Σθi = 1凸集

几何span 长什么样

  • 一个非零向量 → 过原点的直线；零向量 → 只有 {0}。
  • 两个不平行的向量（ℝ² 中）→ 整个平面（ℝ²）；平行则退化为一条直线。
  • ℝ³ 中 u = (1,0,3), v = (−1,1,−3) 不平行 ⟹ span{u,v} 是过原点的平面；由 x = s−t, y = t, z = 3s−3t 消去 s,t 得 z = 3x。
  • 标准单位向量 e₁,…,en（第 i 个位置为 1，其余为 0）满足 x = x₁e₁ + ⋯ + xnen，故 span{e₁,…,en} = ℝⁿ。

定义线性相关 / 线性无关

线性相关（dependent）：存在不全为零的 c₁,…,ck 使 c₁v₁ + ⋯ + ckvk = 0。
线性无关（independent）：c₁v₁ + ⋯ + ckvk = 0 只有平凡解 c₁ = ⋯ = ck = 0。

两种说法等价：相关 ⇔ 至少有一个向量可以写成其余向量的线性组合（“有多余信息”）。

证明思路：若 v₁ = c₂v₂ + ⋯ + cmvm，则 v₁ − c₂v₂ − ⋯ − cmvm = 0 是非平凡组合；反之若有 c₁ ≠ 0，两边除以 c₁ 解出 v₁。

两个向量的速判：相关 ⇔ 一个是另一个的标量倍（如 v = −2u ⟹ 2u + v = 0）。

判定矩阵视角：Ac = 0

把 v₁,…,vm 放进矩阵的列：A = [v₁ v₂ ⋯ vm]，则

c₁v₁ + ⋯ + cmvm = 0　⟺　Ac = 0（齐次方程组）
判定定理：v₁,…,vm 线性无关 ⇔ Ac = 0 只有零解 ⇔ A 化成阶梯形后每一列都是主元列（没有自由变量）。

操作四步：① 把向量按列排成 A；② 解齐次方程组 Ac = 0；③ 对 A 做行化简；④ 看有没有自由变量——无自由变量 ⇒ 无关；有自由变量 ⇒ 相关。

例：v₁ = (1,1,0), v₂ = (0,1,1), v₃ = (1,0,1)。解 c₁ + c₃ = 0, c₁ + c₂ = 0, c₂ + c₃ = 0，行化简后得 c₃ = c₂ = c₁ = 0 ⇒ 线性无关。

数量上限：ℝⁿ 中超过 n 个向量一定线性相关（如 ℝ² 中不可能有 3 个无关向量，因为 (1,1) = (1,0) + (0,1)）。

联系span 与无关：一对互补的问题

  • span 问：这些向量够不够生成整个空间？（“能不能覆盖”）
  • 线性无关 问：这些向量里有没有多余的？（“能不能精简”）
  • 既 span ℝ³ 又线性无关的例子：{e₁, e₂, e₃} —— 这正是标准基特别重要的原因，也直接引出下一讲的“基”。
