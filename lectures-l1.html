2L1 · 线性方程组与高斯消元

定义线性方程与线性方程组

线性方程（n 个未知量）指可以写成

a₁x₁ + a₂x₂ + ⋯ + anxn = b，其中 a₁,…,an, b 都是常数

关键特征：每个变量只出现一次幂，并且只被常数相乘。所以下列都不是线性的：

xy（变量相乘）x²（幂次≠1）1/x（倒数）sin x（非线性函数）√x

线性方程组：m 个方程、n 个未知量；解是一个有序数组 (s₁,…,sn)，它同时满足每一个方程；所有解构成解集。

核心三种解的情形与“相容”

任何线性方程组只有三种可能：

  1. 唯一解（unique）：R² 中两直线交于一点；
  2. 无穷多解（infinitely many）：两直线重合；
  3. 无解（no solution）：两直线平行且不重合。

相容 consistent = 至少有一个解；不相容 inconsistent = 无解。

R² 中：相交 ⇒ 唯一解　|　重合 ⇒ 无穷多解　|　平行不重合 ⇒ 无解

方法等价方程组与三种方程运算

两个方程组等价（equivalent）⇔ 解集完全相同。我们不必直接解原方程组，而是把它变成更简单但等价的方程组。允许的三种运算：

  1. 交换两个方程；
  2. 用一个非零常数乘某个方程；
  3. 把一个方程的倍数加到另一个方程上。
为什么可以这样做？三种运算都是可逆的（能原路退回去），所以既不会丢解，也不会增解——解集不变。
注意：这里的“可逆”指运算本身可逆，跟“求矩阵的逆 A−1”是两件事（求逆见文末附录 A）。

例（L1 幻灯片）：x − y = 1, x + y = 3 ⟺ x − y = 1, y = 1。后者容易，直接回代得 x = 2, y = 1。

方法回代 back substitution

当方程组呈三角形（最后一个方程只含最后的变量）时，从下往上逐个解出：

  1. 先解最后一个方程，得到最后一个变量；
  2. 把已知值代回上一个方程；
  3. 重复，直到所有变量都求出。
例：x − y + z = 2，y + 3z = 5，5z = 10 ⟹ z = 2 → y = −1 → x = −1

对象增广矩阵、矩阵、向量

反复抄写变量太麻烦，于是只记录系数与常数项（竖线左边是系数矩阵 A，右边是 b）：

  x − y − z = 2            [ 1  −1  −1 |  2 ]
  3x − 3y + 2z = 16   ⟹    [ 3  −3   2 | 16 ]
  2x −  y +  z = 9         [ 2  −1   1 |  9 ]
  • 矩阵：数的矩形排列；m 行 n 列 ⟹ m×n 矩阵；第 i 行第 j 列的元素记 aij。
  • 向量：有序数组（n×1 为列向量，1×n 为行向量）。
  • 矩阵记号不是新问题，只是一种更紧凑的存储方式；最终可以写成 Ax = b。

方法初等行变换与行阶梯形（REF）

三种方程运算翻译成矩阵语言，就是三种初等行变换：

方程运算矩阵记号备注
交换两式Ri ↔ Rj可逆
乘非零常数Ri ← k Ri要求 k ≠ 0
加另一式的倍数Ri ← Ri + k Rj可逆（再减回去）
行阶梯形（row echelon form, REF）满足：
① 全零行必须放在最下面；
② 每个非零行的第一个非零元，必须严格位于上一行第一个非零元的右侧。
（阶梯形不要求主元是 1，也不要求主元上方为 0；这些是 RREF 的额外要求。）

主元 pivot：用来消去其下方元素的那个首非零元。策略是：找主元 → 用它把下面清成 0 → 换到下一列 → 重复。

算法高斯消元四步 + 完整例题

  1. 写出增广矩阵 [A | b]；
  2. 用初等行变换化成行阶梯形；
  3. 把阶梯形翻译回方程组；
  4. 回代求解。

例：解 2y + 3z = 8，2x + 3y + z = 5，x − y − 2z = −5。（逐步竖写，箭头右边是这一步执行的行变换。）

  [ 0   2   3 |   8 ]                            第 1 列全是 0 开头，先换个"好主元"
  [ 2   3   1 |   5 ]        R₁ ↔ R₃
  [ 1  −1  −2 |  −5 ]

  [ 1  −1  −2 |  −5 ]        R₂ ← R₂ − 2R₁     用主元 1 把下面清 0
  [ 0   5   5 |  15 ]        R₃ 已经是 0，不用动
  [ 0   2   3 |   8 ]

  [ 1  −1  −2 |  −5 ]        R₂ ← (1/5)·R₂     主元化成 1，方便计算
  [ 0   1   1 |   3 ]
  [ 0   2   3 |   8 ]

  [ 1  −1  −2 |  −5 ]        R₃ ← R₃ − 2R₂     第二列也清 0 → 行阶梯形
  [ 0   1   1 |   3 ]
  [ 0   0   1 |   2 ]

回代：z = 2 → y + 2 = 3 ⇒ y = 1 → x − 1 − 4 = −5 ⇒ x = 0。所以解是 (x, y, z) = (0, 1, 2)。

小结本讲必须会做的事

  • 判断一个方程是不是线性的；
  • 说出“解一个方程组”是什么意思，以及三种解的个数情形；
  • 写出增广矩阵，做初等行变换，化成 REF，再回代；
  • 理解“等价变换不改变解集”是整章的方法论地基。
