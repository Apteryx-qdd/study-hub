8第 8 章 分子轨道理论

Lecture 8 的 7.7–7.8。为什么需要它：Lewis 结构无法解释 O₂ 的顺磁性。Lewis 说 O₂ 没有未成对电子，但实验测到 O₂ 有 2 个未成对电子。

8.1 MO 的基本规则

  • 原子轨道组合成属于整个分子的分子轨道（MO）；
  • 轨道数守恒：n 个原子轨道 → n 个 MO；
  • 每个 MO 最多 2 个电子，按 Pauli、Aufbau、Hund 填充；
  • 成键 MO（σ、π）能量低于原子轨道，反键 MO（σ∗、π∗）更高，并带 ∗。

8.2 键级

键级 bond order = (成键电子数 − 反键电子数) / 2
  • 键级越大 → 键越短、越强、越稳定；键级为 0 → 分子不存在（He₂）。
  • H₂：2 个电子都在 σ1s → BO = 1；He₂：σ1s²σ∗1s² → BO = 0，不存在。

8.3 第二周期双原子分子的能级顺序（两种，取决于 2s–2p 混合）

  • Li₂ ~ N₂（原子序数小，2s 与 2p 能量接近 → 有混合）：
σ2s < σ∗2s < π2p < σ2p < π∗2p < σ∗2p
  • O₂、F₂、Ne₂（核电荷大，几乎不混合）：
σ2s < σ∗2s < σ2p < π2p < π∗2p < σ∗2p

记法："左边 π 低、右边 σ 低"，分界在 N₂ / O₂ 之间。

8.5 四种键理论的分工（考"用哪个理论解释"时用）

理论强项弱点
Lewis快速给出连接方式、定性键强/键长2D、不解释键为何形成
VSEPR预测形状与键角不解释成键本质

8.6 离域键（delocalized bonding）

  • 苯：6 个 C 都是 sp² → 6 个 σ（C–C）+ 6 个 σ（C–H）；6 个未杂化 2p 组合成 6 个 π MO（3 成键 + 3 反键），6 个 π 电子全填在成键轨道 → 三个 C=C 等价、键级 1.5。
  • CO₃²⁻：24 个价电子；C 为 sp²；3 个 σ 键；6 个 π 电子由 4 个原子的 2p 组成离域体系（三个 C–O 键等价）。
  • NO₃⁻：24 个价电子；N 为 sp²；3 个 σ；6 个 π 电子，来自 4 个 2p 轨道（N 的 1 个 + 每个 O 各 1 个）。
