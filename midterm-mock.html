1160 分钟模拟卷（10 题，100 分）

建议计时完成，不要看答案。考完后按分数定位：≥85 稳；70–84 补 T2/T7；<70 先回到 §2.2 与 §3.3。

1.（10 分）解方程组 x + 2y + z = 7，2x + y − z = 2，x − y + 2z = 7。

2.（8 分）讨论 k：x + 2y = 3，2x + 4y = k 何时无解、何时有无穷多解。

3.（8 分）判断 (2, 3, 4) 是否为 (1,0,3) 与 (1,−1,−3) 的线性组合，说明理由。

4.（8 分）判断 v₁ = (1,1,0)、v₂ = (0,1,1)、v₃ = (1,0,1) 是否线性无关。

5.（10 分）设 A = [[1,3,2],[0,−1,1]]，B = [[4,−1],[1,2],[3,0]]。求 AB，并说明 BA 的维数（不必算出）。

6.（8 分）证明：对任意矩阵 A，AAᵀ 是对称矩阵。

7.（12 分）求 A = [[1,2,3],[0,1,4],[5,6,0]] 的逆矩阵。

8.（8 分）用逆矩阵解方程组 2x + y = 3，5x + 3y = 1。

9.（12 分）判断下列集合是否为子空间，说明理由：
(a) S₁ = {(x,y,z) : 2x − y + z = 0}　(b) S₂ = {(x,y) : y = x + 1}
(c) S₃ = {2×2 上三角矩阵}　(d) S₄ = {(x,y,z) : xyz = 0}

10.（16 分）判断真假并说明理由：
(a) 若 AB = O（零矩阵），则 A = O 或 B = O。
(b) 若 A 可逆且 A 对称，则 A⁻¹ 也对称。
(c) 若 A² = I，则 A = I 或 A = −I。
(d) 未知数个数多于方程个数的方程组一定有解。
(e) 若 A、B 都可逆，则 (AB)⁻¹ = A⁻¹B⁻¹。
(f) 每个对称矩阵都可逆。

参考答案与评分点

1. 增广矩阵 → R2−2R1：[0,−3,−3|−12]；R3−R1：[0,−3,1|0]；再 R3−R2：[0,0,4|12] ⇒ z = 3，代回 y = 1，x = 2。解 (2, 1, 3)。（6 分消元 + 2 分回代 + 2 分验证）

2. R2−2R1 得 [0,0 | k−6]：k ≠ 6 无解（0 = k−6 ≠ 0）；k = 6 无穷多解（x = 3 − 2t, y = t）。本题不可能唯一解（两直线平行或重合）。（各 3 分 + 2 分说明）

3. 解 x(1,0,3) + y(1,−1,−3) = (2,3,4)：x + y = 2，−y = 3，3x − 3y = 4。由前两式 y = −3、x = 5，但 3(5) − 3(−3) = 24 ≠ 4 ⇒ 不相容 ⇒ 不是线性组合。（方程 4 分 + 矛盾 2 分 + 结论 2 分）

4. 按列堆成 A = [[1,0,1],[1,1,0],[0,1,1]]，R2−R1、R3−R2 得 [[1,0,1],[0,1,−1],[0,0,2]]，三个主元、无自由变量 ⇒ 线性无关。（也可用 det = 2 ≠ 0。）

5. A 是 2×3、B 是 3×2 ⇒ AB 是 2×2：AB = [[13, 5], [2, −2]]；BA 是 3×3（因为 B 是 3×2、A 是 2×3）。

6. (AAᵀ)ᵀ = (Aᵀ)ᵀAᵀ = AAᵀ，故对称（用了转置反序法则）。同理 AᵀA 也对称。

7. [A|I] 行变换至左边为 I，得 A⁻¹ = [[−24,18,5],[20,−15,−4],[−5,4,1]]；验算 1(−24) + 2(20) + 3(−5) = 1。

8. [[2,1],[5,3]]⁻¹ = [[3,−1],[−5,2]] ⇒ x = [3·3 − 1·1; −5·3 + 2·1] = (8, −13)。验证：2·8 − 13 = 3，5·8 − 39 = 1。

9. (a) 是：0 满足；两解之和、解的倍数仍满足（过原点平面）。(b) 不是：(0,0) 不满足 0 = 0 + 1。(c) 是：零矩阵属之，加法与数乘保持右上角之外的 0。(d) 不是：(1,0,1) 与 (0,1,0) 都在 S₄ 中，但和 (1,1,1) 的乘积为 1 ≠ 0。

10. (a) 假：A = [[1,0],[0,0]]，B = [[0,0],[1,0]]，AB = O 但两者都非零。(b) 真：(A⁻¹)ᵀ = (Aᵀ)⁻¹ = A⁻¹。(c) 假：A = [[1,0],[0,−1]] 满足 A² = I 却不等于 ±I。(d) 假：x + y = 1，x + y = 2 有两个未知数一个“矛盾”；更简单：x + y + z = 1 与 x + y + z = 2 无解。(e) 假：应为 (AB)⁻¹ = B⁻¹A⁻¹（反序）。(f) 假：[[1,1],[1,1]] 对称但不可逆。

最后 30 分钟只看：第 9 节表 1（判定）、第 10 节十二个易错点、§3.3 的 (AB)⁻¹ = B⁻¹A⁻¹ 与 [A|I] 流程、§3.5 的三条件 + 反例库。
