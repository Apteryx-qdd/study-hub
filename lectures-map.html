0四讲主线：一条线串起来

这四讲不是四块独立内容，而是同一件事不断“升维”：解方程 → 把方程写成矩阵 → 用消元读出结构。

线性方程组→ 等价变形（不改变解集）→ 增广矩阵 [A|b]→ 初等行变换 / 行阶梯形→ Ax = b（列的组合）→ span / 线性无关→ 行空间·基·维数·秩→ 子空间 + 秩定理→ 矩阵代数（乘法·转置）

一句话概括每一讲

  • L1：高斯消元 = 用三种可逆的方程运算，把方程组变形成三角形，再从下往上回代。
  • L2：解 Ax=b 等价于问「b 能不能写成 A 的列向量的线性组合」，系数 (x₁,…,xₙ) 就是答案；而线性无关问的是「有没有多余的向量」。
  • L3：把向量按行堆成矩阵 → 行空间；行变换不改变行空间 → 于是阶梯形的非零行就是一组基，其个数 = 维数 = 秩。
  • L4：行空间、列空间、零空间都是子空间；rank(A) + nullity(A) = n；最后把矩阵当成一种“数”，研究它的加法、乘法、转置。
