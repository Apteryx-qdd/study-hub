8自测题（先遮住答案）

建议：先独立做，再展开核对；做错的题在旁边标上对应讲次，最后回到第 2–5 节重看。

A. L1：方程组与消元

1. 下列哪些是线性方程？(a) 3x − 4y = 7　(b) xy + z = 1　(c) x² + y = 3　(d) 2x + 3y = 7　(e) sin x + y = 0
答案
只有 (a)、(d)。(b) 变量相乘，(c) 二次，(e) 非线性函数。
2. 解方程组 2x − y = 3，x + 3y = 5。
答案
由第二式 x = 5 − 3y，代入第一式：2(5−3y) − y = 3 ⇒ 10 − 7y = 3 ⇒ y = 1，x = 2。验证：4−1=3 ✓，2+3=5 ✓。解 (x,y) = (2,1)，是两直线交点，唯一解。
3. 增广矩阵化为 [1 2 3 | 4; 0 0 1 | 2; 0 0 0 | 0]。问：相容吗？有唯一解吗？
答案
相容（没有 [0 0 0 | c≠0] 行）。主元在第 1、3 列，第 2 列是自由变量列 ⇒ 有无穷多解。
4. 判断相容性：x + 2y = 3，2x + 4y = 7。
答案
第二行减 2 倍第一行得 [0 0 | 1]，即 0 = 1 ⇒ 不相容（无解）。几何上两条平行直线。

B. L2：张成与线性无关

5. (5, −2, 3) 是否是 (1,0,3) 与 (1,−1,−3) 的线性组合？
答案
要解 x(1,0,3) + y(1,−1,−3) = (5,−2,3)：x + y = 5，−y = −2，3x − 3y = 3 ⇒ y = 2，x = 3，第三式 9 − 6 = 3 ✓。是，且 (5,−2,3) = 3(1,0,3) + 2(1,−1,−3)。
6. (2, 3, 4) 是否是 (1,0,3) 与 (1,−1,−3) 的线性组合？
答案
x + y = 2，−y = 3，3x − 3y = 4 ⇒ y = −3，x = 5，但 3·5 − 3·(−3) = 24 ≠ 4。不是（方程组不相容）。
7. 判断 u = (1,2), v = (−2,−4) 是否线性无关。
答案
v = −2u ⇒ 2u + v = 0 是非平凡组合 ⇒ 线性相关。两个向量相关 ⇔ 互为标量倍。
8. 判断 (1,1,0), (0,1,1), (1,0,1) 是否线性无关。
答案
设 c₁(1,1,0) + c₂(0,1,1) + c₃(1,0,1) = 0，得 c₁ + c₃ = 0，c₁ + c₂ = 0，c₂ + c₃ = 0。解得 c₁ = c₂ = c₃ = 0 ⇒ 线性无关（也可看行列式 = 2 ≠ 0）。
9. ℝ³ 中能否有 4 个线性无关的向量？为什么？
答案
不能。ℝⁿ 中任意 > n 个向量必线性相关：把 4 个向量按列堆成 3×4 矩阵，齐次方程组有 4 个未知数、rank ≤ 3，必有自由变量 ⇒ 存在非零解。

C. L3：基、维数、秩

10. 求 A = [1 2; 3 4] 的 rank，并给出 row(A) 的一组基。
答案
化成 [1 2; 0 −2]（R2 − 3R1），两个非零行 ⇒ rank(A) = 2。row(A) 的基可取 {(1,2), (3,4)}，或阶梯形的 {(1,2), (0,−2)}。
11. 求 A = 4×5 矩阵（RREF 主元在第 1、2、4 列）的 rank、dim row、dim col、nullity。
答案
rank = 3，dim row(A) = 3，dim col(A) = 3，自由变量 = 2（第 3、5 列）⇒ nullity = 2。检验 3 + 2 = 5 ✓。
12. 求 null(A) 的一组基，其中 A = [1 2 3; 2 4 6]。
答案
RREF = [1 2 3; 0 0 0]，rank = 1，nullity = 3 − 1 = 2。x₁ = −2s − 3t，x₂ = s，x₃ = t ⇒ 基 {(−2,1,0), (−3,0,1)}。
13. 若 A 是 3×3 且 Ax = 0 只有零解，求 rank(A) 与 nullity(A)。
答案
nullity = 0（只有零解，零空间只有 {0}）⇒ rank = 3 − 0 = 3，即 A 满秩、三列都线性无关。
14. span{(1,0,3), (−1,1,−3)} 是 ℝ³ 中的什么？写出它的方程。
答案
两向量不平行 ⇒ 过原点的平面。由 (x,y,z) = s(1,0,3) + t(−1,1,−3) 得 y = t，x = s − t，z = 3s − 3t = 3(s−t) = 3x，即平面 z = 3x（或 3x − z = 0）。

D. L4：子空间与矩阵运算

15. S = {(x,y) : y = x²} 是 ℝ² 的子空间吗？
答案
不是。虽然 (0,0) ∈ S，但 (1,1) + (2,4) = (3,5)，而 5 ≠ 3²，对加法不封闭。
16. S = {(x,y,z) : x + y + z = 0} 是子空间吗？维数是多少？
答案
是。它是齐次方程的解集（一个过原点的平面）：0 满足；两个解之和、解的倍数仍满足。维数 2，基如 {(1,−1,0), (1,0,−1)}。
17. 计算 AB 与 BA，其中 A = [1 2; 3 4]，B = [0 1; 1 0]。
答案
AB = [1·0+2·1, 1·1+2·0; 3·0+4·1, 3·1+4·0] = [2 1; 4 3]；BA = [0·1+1·3, 0·2+1·4; 1·1+0·3, 1·2+0·4] = [3 4; 1 2]。AB ≠ BA。
18. A 是 2×3，B 是 4×3。AB、BA 分别能否定义？
答案
AB 需 3 = 4，不行；BA 需 3 = 2，也不行。两者都无定义。
19. 举一个 A ≠ O 但 A² = O 的 2×2 矩阵，并说明它推翻了哪条“常识”。
答案
A = [2 4; −1 −2]，则 A² = [4−4, 8−8; −2+2, −4+4] = O。它说明矩阵里 A² = O 推不出 A = O（也不能“约去” A）。
20. 设 A 为 3×4，证明 AAT 是对称矩阵，并说出它的维数。
答案
(AAT)T = (AT)TAT = AAT，故对称。A 是 3×4 ⇒ AT 是 4×3 ⇒ AAT 是 3×3。
21. 若 rank(A) = rank([A|b]) = 2，A 是 3×4 的矩阵，问方程组 Ax = b 解的情况。
答案
相容（rank 未因加入 b 而增大）。n = 4，自由变量 = 4 − 2 = 2 > 0 ⇒ 无穷多解。
22. 设 v₁, v₂, v₃ 线性无关，判断 w₁ = v₁ + v₂, w₂ = v₂ + v₃, w₃ = v₁ + v₃ 是否线性无关。
答案
无关。设 c₁w₁ + c₂w₂ + c₃w₃ = 0，整理得 (c₁+c₃)v₁ + (c₁+c₂)v₂ + (c₂+c₃)v₃ = 0。由 v 无关得 c₁+c₃ = c₁+c₂ = c₂+c₃ = 0，解得 c₁ = c₂ = c₃ = 0。
