2第 2 章 原子结构、同位素与摩尔

2.1 电子的发现（Thomson 与 Millikan）

  • 阴极射线 cathode ray：加高压后从阴极发出的带负电粒子流 → 命名为 electron。
  • Thomson 的 e/m 实验（电场 + 磁场交叉）：
  • 电场力 F_E = qE；磁场力（洛伦兹力）F_B = quB（速度与 B 垂直）。
  • 电子直线通过 → qE = quB → u = E/B。
  • 撤去电场后电子做圆周运动 → quB = mu²/r → q/m = E/(B²r)。
  • 结果：e/m = −1.76×10⁸ C/g（负号表示带负电）。
  • Millikan 油滴实验：平衡时 qE = mg → 测出基本电荷 q = −1.6022×10⁻¹⁹ C。
  • 两式合并得电子质量 me = 9.10×10⁻²⁸ g = 9.109×10⁻³¹ kg。

2.2 放射性与卢瑟福核式模型

  • α 射线：带正电的氦核（He²⁺），偏向负极；β 射线：电子，偏向正极；γ 射线：高能光子，不带电，不被偏转。
  • α 粒子散射：绝大多数穿透（原子内部大部分是空的）；极少数大角度反弹（中心有体积小、质量大、集中正电荷的原子核 nucleus）。
  • 结论：Thomson 的"葡萄干布丁模型"被否证，进入 Rutherford 核式模型（核 + 核外电子）。

2.4 原子序数、质量数与同位素

  • 原子序数 Z = 质子数 = 中性原子的电子数（决定元素身份）。
  • 质量数 A = 质子数 + 中子数 → 中子数 = A − Z。
  • 同位素 isotope：Z 相同、A 不同（中子数不同）的原子。化学性质几乎相同，物理性质/质量不同。
  • 表示法：ᵃ_Z X，如 ¹²₆C、¹⁴₆C；离子还要看电荷：电子数 = Z − 电荷（Mg²⁺ 有 10 个电子）。
  • 离子/同位素比较题（HW2 第 2 题）：分别数电子数（Z−charge）、中子数（A−Z）、质量（∝A，用 amu 比较）。

2.5 平均原子质量

公式

平均原子质量 = Σ（同位素质量 × 天然丰度）

丰度用小数或百分数代入均可（百分比要除以 100）。结果的有效数字由最不精确的丰度决定。

例（碳）：12.00000×0.9893 + 13.003355×0.0107 = 12.011 amu。

例（铷，HW2/L2 练习）：Rb 平均原子质量 85.4678 amu，⁸⁵Rb（丰度 72.17%）为 84.911794 amu，求 ⁸⁷Rb 质量：

85.4678 = 84.911794×0.7217 + x×0.2783 → x ≈ 86.910 amu

反向题（给平均质量求丰度）设一个为 x、另一个为 (1−x) 解一次方程即可。

2.6 摩尔与摩尔质量

  • 阿伏伽德罗常数 NA = 6.022×10²³ mol⁻¹（常数有单位；"阿伏伽德罗数"本身无单位）。
  • 摩尔质量 M：1 mol 物质的质量，单位 g/mol；数值上等于该物质的原子质量/分子质量（amu）。
  • 三条互换算，考试必用：
n = m / M　　N = n × NA　　m = n × M
  • 单位链：质量(g) → ÷M → 摩尔(mol) → ×NA → 粒子数；反向乘除互换。
  • 摩尔质量越大，单个粒子越重；同质量下粒子数越少。
  • 由密度求原子半径（HW2 第 3 题套路）：d = m/V → 一个原子的体积 Vatom = M/(d·NA) → 球体积 4/3πr³ → r（注意"26% 是空腔"要乘以 0.74 的堆积因子/或按题意扣除空隙）。
